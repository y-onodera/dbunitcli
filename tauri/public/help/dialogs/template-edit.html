Template File Edit

Generate などで使用するテンプレートファイル（StringTemplate 4）を作成・編集するダイアログです。

シンプルな使い方

テンプレートのテキストボックス横の編集ボタンで開き、テンプレートを書いて保存します。

例: Generate（generateType=txt、unit=table）で、テーブルごとにカラム名の一覧を出力するテンプレートを作ります。

本文:
  -- $param.tableName$ : $param.columns:{c | $c.columnName$}; separator=", "$

指定:
  name = columns.txt
  → Save

結果:
  template に columns.txt を設定する
  テーブル USERS（カラム ID / NAME）で実行すると:
  -- USERS : ID, NAME
  • $param.〜$ で使える値は unit によって変わる（generateType: txt）
  • 繰り返し・条件分岐・書式の書き方は StringTemplate 4 書式リファレンス を参照

開き方

テンプレートのテキストボックス横の編集ボタンから開きます。テキストボックスに Workspace のテンプレートとして存在するファイル名が入力されている場合はその内容が読み込まれ、空または存在しない名前の場合は空のエディタが開きます。

記述内容

StringTemplate 4 のテンプレートを書きます。参照できる変数は generateType: txt、書き方は StringTemplate 4 書式リファレンス を参照してください。

保存

ダイアログ下部の name に保存先のファイル名を指定して Save を押すと、内容がファイルとして書き出され、元のテキストボックスにそのファイル名が設定されます。存在しない名前を指定すると新規ファイルとして作成され、既存のファイル名を指定すると上書きされます。

ファイルの読み込み・保存には、コマンド実行時と同じく、適用先の template option に入力中の encoding の文字コードを使います（未入力ならシステムデフォルト）。Dataset Load Form の templateGroup から開いたときは、そのフォームの encoding です。
