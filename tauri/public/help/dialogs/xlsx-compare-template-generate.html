Generate Compare Template

1 つのデータセットに含まれる 2 つ（または 1 つ）のテーブルのカラム構成から、データを流し込むシート 2 枚と、その 2 枚を複合キーで突合して値を比べるシート 1 枚からなる jxls 用の Excel テンプレート（.xlsx）を生成し、template リソースへ保存します。generateType が xlsx / xls のとき、template の ⋮ メニューの generate compare template から開きます。

シンプルな使い方

データセットを指定し、その中から比較する 2 つのテーブルを選んでカラムを読み込み、突合のキーと比較するカラムの組を選んで Execute を押すと、比較用のテンプレートが保存されます。

入力:
  テーブル OLD_USERS（カラム ID / NAME）
  テーブル NEW_USERS（カラム USER_ID / NAME）

指定:
  fileName         = users_compare
  src セクション   = （OLD_USERS・NEW_USERS の 2 テーブルだけを読むデータセット）
  old table        = OLD_USERS → Load Columns
  new table        = NEW_USERS → Load Columns
  keys             = old: ID / new: USER_ID
  compares         = old: NAME / new: NAME
  → Execute

結果:
  template リソースに users_compare.xlsx を保存し、template に users_compare.xlsx を設定する
  シート OLD_USERS・NEW_USERS: A 列に複合キー、B 列以降にカラムの値
  シート compare: OLD_USERS の行ごとに、NEW_USERS の同じキーの行の NAME と比べた結果
  • このテンプレートは unit=dataset で使う。データシートには、シート名と同じ名前のテーブルの全行が流し込まれる
  • シート名は、選んだテーブル名がデフォルト
  • generate の src に指定できるデータセットは 1 つなので、src セクションには generate で使うのと同じデータセットを指定する。2 テーブルが別のディレクトリにあるときは、共通の親ディレクトリを src にして traversal・テーブル名の絞り込み（正規表現のグループ等）・setting で 2 テーブルに絞る

できること

  • データシートを 2 枚作る。A 列は選んだキーのカラムを | でつないだ複合キーの数式、B 列以降はデータセットの全カラム
  • 比較シートを 1 枚作る。old のシートの行ごとに、複合キーで new のシートの行を探し、比較するカラムの組ごとに 2 つの値と判定を並べる
  • Use second table を OFF にした場合は、同じカラム構成のデータシートを 2 枚作り、キー以外の全カラムを同じ名前どうしで比べる
  • 生成したファイルを template リソースに保存し、template テキストボックスへ設定する

比較シートは Excel の関数で突合するため、生成した Excel のデータシートを書き換えたり、別のデータを貼り付けたりすると、比較結果も更新されます。

keys・compares の行は + で追加、− で削除します。old・new のどちらかが空の行は無視します。

操作の流れ

  1. fileName を入力します。1 つのテーブルを複製して比べるなら Use second table を OFF にします。
  2. src セクションでデータセットを指定し、old（と new）の table を選んでそれぞれ Load Columns を押します。
  3. 必要ならシート名を変え、keys と compares を選びます。
  4. Execute を押すと、テンプレートが template リソースへ保存されます。ダイアログが閉じ、保存したファイル名が template テキストボックスに設定されます。

生成例

「シンプルな使い方」の指定では、次のシートが作られます（数式は概要）。

シート: OLD_USERSABC
1KEYIDNAME
2この行の B 列（キーが複数なら | でつなぐ）${row.get('ID')}${row.get('NAME')}
シート: compareABCDEF
1NEW_USERS onlyNEW_USERS にだけあるキーの件数
2KEYNEW_USERS rowSTATUSNAME(OLD_USERS)NAME(NEW_USERS)NAME diff
3OLD_USERS の同じ順番の行の KEYNEW_USERS で同じ KEY がある行の番号判定OLD_USERS の値NEW_USERS の値値が違えば ×

generate コマンドの generateType=xlsx、unit=dataset で、OLD_USERS・NEW_USERS の 2 テーブルを含むデータセットを src にしてこのテンプレートを指定すると、各データシートに全行が展開され、比較シートは OLD_USERS の行数だけ展開されます。

生成ルール

値説明
STATUS が空new に同じキーの行があり、比べたカラムの値がすべて同じ
STATUS が diffnew に同じキーの行があり、値の違うカラムがある
STATUS が missingnew に同じキーの行がない
diff 列が ×2 つの値が違う。値は文字列として、大文字・小文字も区別して比べる
  • 比較シートの行は old のシートの行に対応する。new にだけあるキーの行は比較シートに出ず、1 行目に件数だけを出す
  • missing の行は new の値が空になり、old の値が空でないカラムの diff 列は × になる
  • 数式は、列全体に付けた名前（FIRST_B = old のシートの B 列、SECOND_A、COMPARE_C など）と ROW() で同じ行の値を取る。比較シートの n 行目のデータは old のシートの n 行目のデータに対応するため、どちらかのシートだけに行を挿入・削除すると対応がずれる

注意

  • キーは、それぞれのシートの中で重複しない組み合わせを選んでください。重複していると、new では最初に見つかった行と比べ、1 行目の件数も正しく数えられません。
  • シート名に ' は使えません。3 つのシート名は互いに違う名前にしてください（大文字・小文字は区別しません）。
  • テンプレートの生成にはデータ本体を読み込まず、カラム情報のみを使用します。
  • Execute が失敗した場合は、ダイアログ内にエラーメッセージと実行中に出ていたログが表示されます。入力内容を見直して再度実行してください。
