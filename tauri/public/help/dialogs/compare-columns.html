Select Compare Columns

compare セクションの keys / compares に入れるカラムを、oldTable のカラムの一覧から選び、それぞれに対応する newTable のカラムを指定するダイアログです。keys / compares の横の編集ボタンから開きます（タイトルは Select keys / Select compares）。

シンプルな使い方

指定:
  oldTable = USERS_OLD（カラム ID, SUB, NAME, AMT）
  keys の横の編集ボタン → SUB、ID の順にチェック → Apply

結果:
  keys = SUB,ID
指定:
  oldTable = USERS_OLD（カラム ID, NAME, AMT）
  newTable = USERS_NEW（カラム ID, name, CODE）
  keys の横の編集ボタン → ID、NAME、AMT をチェック
    → new のカラムは ID・name が初期値で入り、AMT は未選択
  AMT の new のカラムで CODE を選ぶ → Apply

結果:
  keys = ID,NAME:name,AMT:CODE

設定項目

項目説明
カラムの一覧開いたときの oldTable の入力値のテーブルのカラム。src セクションの入力値で読み込み、setting を適用した後のテーブルから読む。チェックした順に並べ、その順が複合キー・比較シートの列の順になる
new のカラム開いたときの newTable の入力値のテーブルのカラムから、チェックした old のカラムに対応させるカラムを選ぶ。チェックしたときに同じ名前のカラム（無ければ大文字小文字だけ違うカラム）を初期値にする。該当が無ければ未選択のままで、old と同じ名前として入る。old と同じ名前なら ID、違えば NAME:name の形で入る
選択中の値Apply で入る値（カンマ区切り）

操作

操作説明
Apply選んだカラムをカンマ区切りにして keys / compares に設定して閉じる
Close値を変えずに閉じる

注意

  • 開く前に oldTable を入力してください。空のときは一覧が出ません。
  • newTable が空のときや、そのカラムを読めないときは new のカラムの列は出ず、old と new で同じ名前のカラムとして入ります（書き方は compare の「keys / compares の書き方」）。
  • すでに ID:CODE のように書いた対応は、old 側のカラム（ID）をチェックしている間はそのまま残ります。一覧に無いカラム名を書いていた場合も消えません。
