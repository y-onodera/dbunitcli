Select Compare Columns

compare セクションの keys / compares に入れるカラムを、oldTable のカラムの一覧から選ぶダイアログです。keys / compares の横の編集ボタンから開きます（タイトルは Select keys / Select compares）。

シンプルな使い方

指定:
  oldTable = USERS_OLD（カラム ID, SUB, NAME, AMT）
  keys の横の編集ボタン → SUB、ID の順にチェック → Apply

結果:
  keys = SUB,ID

設定項目

項目説明
カラムの一覧開いたときの oldTable の入力値のテーブルのカラム。src セクションの入力値で読み込み、setting を適用した後のテーブルから読む。チェックした順に並べ、その順が複合キー・比較シートの列の順になる
選択中の値Apply で入る値（カンマ区切り）

操作

操作説明
Apply選んだカラムをカンマ区切りにして keys / compares に設定して閉じる
Close値を変えずに閉じる

注意

  • 開く前に oldTable を入力してください。空のときは一覧が出ません。
  • 選べるのは oldTable のカラムだけで、old と new で同じ名前のカラムとして入ります。new のカラム名が違う場合は、Apply の後に old のカラム:new のカラム の形に書き直してください（compare の「keys / compares の書き方」）。
  • すでに ID:CODE のように書いた対応は、old 側のカラム（ID）をチェックしている間はそのまま残ります。一覧に無いカラム名を書いていた場合も消えません。
