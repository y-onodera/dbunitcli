Xlsx Schema

Excel ファイルをデータセットとして読み込む際のマッピング定義を編集するダイアログです。1 つの Excel ファイルから複数の論理テーブルを抽出するための設定を、2 種類のマッピング形式で記述します。

全体構造

スキーマは次の 2 種類の定義を持ちます。どちらも 1 行が 1 つの論理テーブルの定義です。

Rows Mapping Tables

シート上に行方向に整列したデータ（ヘッダ行 + 連続するデータ行）をテーブルとして抽出します。通常の表形式データはこちらで定義します。

1 行が 1 レコードとなるテーブルを定義します。各行の編集ダイアログの詳細は Xlsx Row Setting を参照してください。

Random Cell Mapping Tables

シート上の任意のセル位置から値を拾い集めてテーブルを構成します。帳票やフォーマット化された Excel など、行方向に整列していないデータの抽出に利用します。

指定したセルアドレスごとに 1 レコードを生成します。各行の編集ダイアログの詳細は Xlsx Cell Setting を参照してください。

共通の項目

項目説明
sheetName抽出対象となる Excel のシート名
tableName抽出結果に付与する論理テーブル名。DatasetSetting 等から参照する名前になる。
headerカラム名の並び。1 行 1 カラム定義で、Excel 上のカラム並びと対応させる。
addFileInfo抽出結果に元ファイル情報のカラムを追加するかどうか

雛型の生成

xlsxSchema の横のメニューの generate ボタンから、既存データセットのカラム構成をもとにスキーマの雛型を生成できます。

  1. データセット指定ダイアログで元にするデータセット（CSV / Excel / DB など）を指定し、Execute を押します。
  2. テーブルごとのカラム構成から Rows Mapping / Random Cell Mapping の設定が生成され、このダイアログに反映された状態で開きます。
  3. 内容を確認・編集し、ファイル名を指定して保存すると、その名前が xlsxSchema に設定されます（Xlsx Schema Generate）。

保存とプレビュー

ダイアログ下部のファイル名を指定して保存すると、設定内容が JSON ファイルとして書き出されます。sheetName と tableName が共に入力されている行のみが保存対象です。

Save and Preview を押すと、同じように保存したうえで、保存したファイルを xlsxSchema に適用して読み込まれるテーブルの一覧を表示します（Dataset Load Form の Preview Apply Settings と同じ表示です）。一覧の preview ボタンを押すと、そのテーブルのデータを表示します。

  • xlsxSchema 以外の項目（src・setting など）はフォームに入力した値を使う
  • Save and Preview では Xlsx Schema は閉じず、xlsxSchema のファイル名も変わらない。ファイル名を反映するには Save を押す。
  • Save and Preview はフォームで srcType を指定しているときだけ表示される

1 行分の定義だけを保存せずに確かめるには、Xlsx Row Setting / Xlsx Cell Setting の Preview を使います。

関連

  • srcType: xls / xlsx — スキーマを使って Excel を読み込む
  • generateType: xlsxSchema — Generate で雛型を作る
