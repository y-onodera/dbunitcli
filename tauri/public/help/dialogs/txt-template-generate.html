Scaffold

固定成果物タイプ（ddl / javaBean / xlsxSchema / fixedColumnDef）の組み込みテンプレートを、カスタマイズ生成の出発点としてワークスペースへ書き出し、その結果を generate フォームへ反映します。generateType が txt のとき、template テキストボックスの前にある Scaffold ボタンから開きます（scaffold コマンドを実行します）。

できること

  • 組み込みテンプレート（.stg / .txt）と、サンプルの unitSetting をワークスペースへ書き出す。
  • データソースから、テーブルごとの記述子データセット（1 カラム = 1 行）を書き出す。
  • 書き出した雛型で駆動する設定を generate フォームへ反映する。そのまま Exec で生成できます。

入力

項目説明デフォルト
target雛型の生成対象（ddl / javaBean / xlsxSchema / fixedColumnDef）ddl
template書き出すテンプレートのファイル名（必須。resources/template/{名前}.stg と {名前}.txt をワークスペースへ出力）—
unitSetting書き出すサンプル unitSetting のファイル名（省略可。resources/setting/{名前}.json をワークスペースへ出力）—
datasetType記述子データセットの出力形式（csv / xls / xlsx / table / fixed）csv
datasetEncoding記述子データセットの出力文字コード（csv / fixed のみ）UTF-8
fixedLength / defaultLength / aligntarget が fixedColumnDef の場合のみ表示。記述子データセットに書き出す桁数・デフォルト桁数・寄せ方向— / 10 / left
dataset記述子データセットの元になるデータソース。ダイアログを開いた時点の src セクションの内容が初期値として引き継がれます。指定するとテーブルごとの記述子データセット（1 カラム = 1 行）をワークスペースの src へ出力します—

target に parameter は選択できません。

generate section

ダイアログ上部の generate section のチェックボックスで、unitSetting と src を生成対象にするかを選べます（初期状態は両方選択）。template は常に生成・反映されるため選択できません。

  • チェックを外したセクションの入力欄はダイアログから非表示になり、そのファイルは生成されません。
  • unitSetting を外すと unitSetting の入力欄、src を外すと datasetType・datasetEncoding・fixedLength / defaultLength / align・dataset の入力欄が非表示になります。
  • scaffold コマンドの result は、生成した分だけ generate フォームへ反映されます。
generate sectionダイアログの入力result（generate フォームへ反映される項目）
templatetemplatetemplate（{名前}.txt）、template.templateGroup（{名前}.stg）。resources/template 配下を基準に検索されるため、接頭辞は省略した名前が入ります
unitSettingunitSettingunitSetting（{名前}.json。resources/setting 配下を基準に検索されるため接頭辞は省略した名前が入ります）
srcdatasetsrc.src（書き出した記述子データセットのディレクトリ。入力した dataset のパスではありません）
srcdatasetTypesrc.srcType
srcdatasetEncodingsrc.encoding（csv / fixed のみ）

チェックを外した unitSetting / src に対応する result は生成されないため反映されません。上記以外の result（generateType / unit / resultPath など）は generate フォームへ反映されません。

操作の流れ

  1. target と、書き出すテンプレートのファイル名（必須）を指定します。必要に応じて unitSetting・記述子データセットの形式・データソースを指定します。
  2. Execute を押すと雛型ファイルがワークスペースへ生成されます。
  3. 選択した generate section に対応する result（上表）が generate フォームへ反映され、ダイアログが閉じます。
  4. 書き出された記述子データセットを編集してから Exec で生成します。反映内容の保存は通常どおり Save ボタンで行ってください。

注意

  • Execute が失敗した場合は、ダイアログ内にエラーメッセージが表示されます。入力内容を見直して再度実行してください。
  • Close を押すと、何も書き出さずにダイアログを閉じます（generate フォームは変更されません）。
