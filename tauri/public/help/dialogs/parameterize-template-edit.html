Edit Parameterize Template

Parameterize の template に指定する、コマンドのオプションを書いたテンプレートを作成・編集するダイアログです。

シンプルな使い方

template 横のメニューの編集ボタンで開き、繰り返し実行するコマンドのオプションを書いて保存します。

本文:
  -srcData.src=data/$param.MONTH$
  -convertResult.resultType=xlsx
  -convertResult.result=out/$param.MONTH$

指定:
  name = convert_monthly.txt
  → Save

結果:
  template に convert_monthly.txt を設定する
  パラメータデータの MONTH 列が 202609 の行では、src = data/202609、result = out/202609 で実行される
  • オプションは 1 行に 1 つ、-オプション名=値 の形で書く
  • パラメータデータやコマンドの指定を含めた全体の例は Parameterize を参照

開き方

template のテキストボックス横のメニューにある編集ボタンから開きます。テキストボックスの値のファイル名が option/parameterize/template にあればその内容が読み込まれ、それ以外の場合は空のエディタが開きます。同じメニューの削除ボタンでは、候補にあるテンプレートファイルを削除できます。

記述内容

対象のコマンド（cmd）のオプションを 1 行に 1 つずつ、-オプション名=値 の形で書きます。値には $param.列名$ でパラメータデータの値を埋め込めます。記述例は Parameterize の「使用例」を参照してください。

保存

ダイアログ下部の name に保存先のファイル名を指定して Save を押すと、内容がファイルとして書き出され、元のテキストボックスにそのファイル名が設定されます。存在しない名前を指定すると新規ファイルとして作成され、既存のファイル名を指定すると上書きされます。ファイルの読み込み・保存には、フォームの template option に入力中の encoding の文字コードを使います（未入力ならシステムデフォルト）。
