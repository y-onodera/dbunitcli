Result Path Template

Generate の resultPath にテンプレート変数を埋め込むダイアログです。resultPath の横の編集ボタンから開きます。主な使い方は、unit=table のときにテーブルごとに別のファイルへ出力するための、テーブル名の埋め込みです。

シンプルな使い方

指定:
  generateType = txt、unit = table
  resultPath の横の編集ボタン → resultPath の欄の末尾にカーソルを置く
  → Variable = tableName のまま Insert → 続けて .sql と入力 → Apply

結果:
  resultPath = $param.tableName$.sql

出力されるファイル（テーブルが ORDERS / ITEMS のとき）:
  ORDERS.sql
  ITEMS.sql

設定項目

項目説明デフォルト
resultPath編集中の resultPath。Insert はこの欄のカーソル位置に式を入れる（文字を選んでいれば置き換える）。直接入力もできる開いたときの resultPath の値
Variable（必須）埋め込む変数名。候補から tableName / rowNumber を選ぶか、row.ID（unit=record の行の値）・inputParam.xxx（-P 値）などを直接入力する。使える変数は generateType: txt の「テンプレート変数」を参照tableName
Format値の書き方の変換。snakeToCamel（ORDER_ITEMS → orderItems）・camelToUpperSnake など。文字列の変数にだけ効く(none)＝変換しない
ExpressionInsert で入る式。template option の templateParameterAttribute / templateVarStart / templateVarStop（generateType が xlsx / xls なら jxls option の templateParameterAttribute）の入力中の値で組み立てる—

操作

操作説明
InsertExpression の式を resultPath の欄のカーソル位置に入れる。何度でも押せる
Apply編集した値を resultPath に設定して閉じる
CloseresultPath を変えずに閉じる

注意

  • ボタンは generateType や unit によらず表示されますが、使える変数は unit によって変わります。unit=dataset では tableName は使えません。
  • テーブル単位の固定成果物タイプ（sql など）では resultPath はディレクトリとして扱われ、その下にテーブルごとのファイルが作られます。
