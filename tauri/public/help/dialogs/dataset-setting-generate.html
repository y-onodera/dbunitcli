Dataset Setting Generate

既存データセット（CSV / Excel / DB など）のテーブル・カラム構成から、Dataset Settings ファイルの雛型を自動生成します。setting テキストボックス横のメニューの generate ボタンから開きます。

できること

  • データセット内のテーブルごとに、対象テーブル名（name）と主キー（keys）を持つ設定エントリを一括で作成する。
  • JDBC 接続先では、テーブルの主キー定義を keys に引き継ぐ。
  • 生成結果を編集ダイアログで確認し、exclude / order / filter などを書き足して名前を付けて保存する。

テーブルが多いデータセットでも、手入力せずに設定ファイルの骨組みを用意できます。生成後は、実際に必要な設定（除外カラム・ソート・行フィルタなど）を追記する使い方を想定しています。

入力

雛型の元にするデータセットを、共通の Dataset Load Form で指定します。srcType の選択に応じて入力項目が切り替わります。データ行は読み込まず、テーブル名・カラム名・主キーのメタデータのみを利用します。

項目説明
srcData雛型の元にするデータセット。srcType・パス・文字コード・ヘッダ指定などを Dataset Load Form と同じ要領で指定します。

操作の流れ

  1. 元にするデータセットを指定します。
  2. Execute を押すと、テーブルごとの設定エントリが生成されます。
  3. 生成結果は Dataset Settings の編集ダイアログに反映された状態で開きます。内容を確認・編集してください。
  4. ファイル名を指定して保存すると、その名前が setting テキストボックスに設定されます。

生成例

たとえば、主キー ID を持つ USERS テーブルと、主キーを持たない ORDERS テーブル（カラム ORDER_ID / USER_ID / AMOUNT）を含むデータセットを指定して Execute すると、次のような設定が生成されます。

{
  "settings": [
    {
      "name": "USERS",
      "keys": ["ID"]
    },
    {
      "name": "ORDERS",
      "keys": ["ORDER_ID", "USER_ID", "AMOUNT"]
    }
  ]
}

生成ルール

項目生成される値
name元データセットのテーブル名。テーブルごとに 1 エントリ生成されます。
keys主キーが取得できるテーブルは主キーのカラム名。主キーが無いテーブルは全カラム名になります。CSV など主キー情報を持たないソースでは、すべてのテーブルが全カラム名になります。

生成直後は name と keys のみです。exclude・order・filter・追加カラムなどの各項目は、編集ダイアログで必要に応じて追加してください（項目の一覧は Dataset Settings、操作方法は Dataset Setting を参照）。

注意

  • 主キーが無いテーブルの keys が全カラムになるため、実際の主キーに合わせて keys を修正してください。
  • Execute が失敗した場合は、ダイアログ内にエラーメッセージが表示されます。入力内容を見直して再度実行してください。
  • Close を押すと、生成せずにダイアログを閉じます（setting テキストボックスは変更されません）。
