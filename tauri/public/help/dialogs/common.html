ダイアログ共通の操作

各ダイアログに共通するボタンと表示の動きをまとめたページです。個々のダイアログの項目は、それぞれのページを参照してください。

シンプルな使い方

テキストエリアのあるダイアログでは、タイトル右端の最大化ボタンで編集領域を広げられます。

例: 長い SQL を広い画面で編集します。

指定:
  SQL Editor を開く
  → タイトル右端の最大化ボタン
  → SQL を編集
  → Save

結果:
  ダイアログがウィンドウいっぱいに広がり、テキストエリアが残りの高さを埋める
  • ウィンドウ自体を大きくすると、編集領域もさらに広がる

ボタン行

ダイアログ下部のボタン（Save / Execute / Apply / Close など）は、内容が長くてダイアログがスクロールするときも、下端に表示されたままです。

Help ボタン

タイトル横に Help ボタンがあるダイアログでは、押すとそのダイアログのヘルプを別ウィンドウで開きます。同じヘルプのウィンドウが開いている場合は、そのウィンドウを前面に出します。

最大化

タイトル右端の最大化ボタンを押すと、ダイアログがウィンドウいっぱいに広がり、テキストエリアが残りの高さを埋めます。もう一度押すと元の大きさに戻ります。ウィンドウが小さく収まらない場合は、ダイアログがスクロールします（テキストエリアは最大化前の高さより低くなりません）。

最大化ボタンがあるダイアログ:

ダイアログ開き方
SQL EditorsrcType が sql / table / csvq のとき、src 横のメニューの編集ボタン
Template File Editテンプレートのテキストボックス横の編集ボタン
Edit Parameterize TemplateParameterize の template 横のメニューの編集ボタン
式の編集（Dataset Setting）Additional Columns・filter の行の edit ボタン
