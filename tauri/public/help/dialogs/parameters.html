Parameters (-P)

フッターの Edit Parameters (-P) ボタンで、SQL やテンプレート、スクリプトに渡す値をキーと値の組で入力します。入力した値はコマンドの引数に -Pキー=値 として追加されます。日付や対象 ID など、実行のたびに変える値を渡すのに使います。

使い方

  1. フッターの Edit Parameters (-P) ボタンを押してダイアログを開く
  2. キーと値を入力する。キーを空にした行は削除される
  3. Apply で反映する。設定した数がボタンの右に — N parameter(s) set と表示される
  4. Exec で実行する

影響範囲

対象影響
Exec入力した値が -Pキー=値 として渡される
フォームの設定ダイアログDataset Setting やカラム定義などのダイアログで、テーブル名・プレビュー・カラム名を読み込むときにも渡される（SQL でデータを読み込む場合に、Exec と同じ値で確認できる）
Save保存されない。保存されるのはフォームの内容だけ
Save Shell.bat に含まれない（.bat は保存済みのパラメータを実行するため）
パラメータの切り替えサイドバーで別のパラメータを開くと、入力した値は消える

-P の値は、そのとき開いているパラメータで試すための一時的な値です。保存して繰り返し使う値や .bat でも使う値は、フォームのオプションか Workspace の Env（${env.変数名}）で指定してください。CLI から実行する場合は、引数に -Pキー=値 を付けて渡します。

値の参照方法

参照する場所によって書き方が変わります。テンプレートの区切り文字は既定の $、変数をまとめる属性名（templateParameterAttribute）は既定の param の場合の例です。

使う場所書き方
SQL ファイル（srcType=sql / csvq、Run の sql）$param.キー$（templateParameterAttribute を空にした場合は $キー$）
Generate のテンプレート$param.inputParam.キー$（templateParameterAttribute を空にした場合は $inputParam.キー$）
Parameterize のテンプレート / cmdParam$param.inputParam.キー$
Run の cmd / bat環境変数として渡される（例：%キー%）
Run の antAnt のプロパティとして渡される（例：${キー}）

例：SQL の条件を実行時に変える

-- select.sql
SELECT * FROM ORDERS
$if(param.orderDate)$WHERE ORDER_DATE = '$param.orderDate$'$endif$

Edit Parameters (-P) でキー orderDate、値 2026-10-01 を入力して Exec すると、-PorderDate=2026-10-01 が渡され、その日付で絞り込まれます。値を入力しなければ条件なしで実行されます。

テンプレートの書き方は StringTemplate 4 を参照してください。
