Parameters (-P)

フッターの Edit Parameters (-P) ボタンで、SQL やテンプレート、スクリプトに渡す値をキーと値の組で入力します。入力した値はコマンドの引数に -Pキー=値 として追加されます。日付や対象 ID など、実行のたびに変える値を渡すのに使います。

使い方

  1. フッターの Edit Parameters (-P) ボタンを押してダイアログを開く
  2. キーと値を入力する。キーを空にした行は削除される
  3. Apply で反映する。設定がある場合はボタンに件数のバッジが付き、右に — N parameter(s) set と表示される。設定がない場合は — No parameters と表示される。保存済みオプションを開いたときも、保存された -P の件数が表示される
  4. Exec で実行する。値を残す場合は Save で保存する

影響範囲

対象影響
Exec入力した値が -Pキー=値 として渡される
フォームの設定ダイアログDataset Setting やカラム定義などのダイアログで、テーブル名・プレビュー・カラム名を読み込むときにも渡される（SQL でデータを読み込む場合に、Exec と同じ値で確認できる）
Saveフォームの内容と一緒に option/<command>/<name>.txt に -Pキー=値 の行として保存される
Save Shell保存済みの値が .bat の実行でも使われる（Apply しただけで Save していない値は使われない）
保存済みオプションを開くサイドバーで保存済みオプションを開くと、そこに保存された -P 値に置き換わる（保存された値がなければ空になる）。Save していない入力は失われる

-P 値は保存済みオプションごとに保存されます。同じ値を複数の保存済みオプションや環境で切り替えたい場合は Env を使います（Env との使い分け を参照）。CLI から実行する場合は、引数に -Pキー=値 を付けて渡します。

値の参照方法

参照する場所によって書き方が変わります。テンプレートの区切り文字はデフォルトの $、変数をまとめる属性名（templateParameterAttribute）はデフォルトの param の場合の例です。

使う場所書き方
SQL ファイル（srcType=sql / csvq、Run の sql）$param.キー$（templateParameterAttribute を空にした場合は $キー$）
Generate のテンプレート$param.inputParam.キー$（templateParameterAttribute を空にした場合は $inputParam.キー$）
Parameterize のテンプレート / cmdParam$param.inputParam.キー$
Run の cmd / bat環境変数として渡される（例：%キー%）
Run の antAnt のプロパティとして渡される（例：${キー}）

例: SQL の条件を実行時に変える

-- select.sql
SELECT * FROM ORDERS
$if(param.orderDate)$WHERE ORDER_DATE = '$param.orderDate$'$endif$

Edit Parameters (-P) でキー orderDate、値 2026-10-01 を入力して Exec すると、-PorderDate=2026-10-01 が渡され、その日付で絞り込まれます。値を入力しなければ条件なしで実行されます。

テンプレートの書き方は StringTemplate 4 を参照してください。

Env との使い分け

Env（Workspace の ChangeWorkspace で選ぶ環境変数ファイル）と -P は、どちらも値を外から渡す仕組みですが、適用範囲と効く場所が違います。

観点Env（${env.変数名}）Parameters（-Pキー=値）
定義する場所Workspace 内の .properties ファイル（デフォルトは env.properties）Edit Parameters (-P) ダイアログ。Save で option/<command>/<name>.txt に保存
適用範囲Workspace 全体。選んだ Env ファイルが、その Workspace のすべての保存済みオプションの実行に使われるその保存済みオプションだけ
切り替え方ChangeWorkspace で Env ファイルを選び直す。保存済みオプションは書き換えない保存済みオプションごとに値を編集して Save する
オプションの置換する。どのオプションの値でも、${env.変数名} を実行前に置き換えるしない。例外は Generate の resultPath と、Parameterize の cmd / cmdParam / テンプレート（テンプレートとして処理されるため）
テンプレート処理の変数使えない。SQL ファイルや Generate のテンプレートの中身は置き換えない使える。値の参照方法 の書き方で参照する。Run の cmd / bat / ant にも渡される
未定義のときエラーになる空として扱われる（$if(param.キー)$ で分岐できる）
Save Shell の .bat選んでいる Env ファイルの指定が .bat に書き込まれる保存済みオプションに含まれるので、.bat の実行でも使われる

どちらを使うか

  • 環境ごとに違う値（接続先・ユーザ・スキーマ・出力先のディレクトリなど）で、オプションに直接書く値 → Env
  • その保存済みオプションの実行条件（対象日・ID・テーブル名など）で、SQL やテンプレートの中で使う値 → -P
  • 環境ごとに違う値を SQL やテンプレートの中で使いたい → 両方を組み合わせて、-P の値に Env を書く（例：-PorderDate=${env.orderDate}）。-P の値も引数の一部なので、実行前に Env の値に置き換わってから SQL やテンプレートに渡される
