Fixed Column Def

固定長ファイルに出力するときの、カラムごとの幅・寄せ方向・埋める文字の定義（Fixed Column Def）を編集するダイアログです。resultType: fixed のときに表示される fixedColumnDef の ⋮ メニューの edit から開きます。

シンプルな使い方

出力するカラムを上から順に追加し、カラムごとの幅を指定して保存します。

例: ID を 5 桁の右寄せ・0 埋め、NAME を 10 桁の左寄せで出力します。

指定 (Column Definitions):
  1 行目: name = ID,   length = 5,  align = right, pad = 0
  2 行目: name = NAME, length = 10, align = left,  pad = （半角スペース）
  name = members.json
  → Save

保存される内容 (members.json):
  {"columns": [
    {"name": "ID", "length": 5, "align": "right", "pad": "0"},
    {"name": "NAME", "length": 10, "align": "left", "pad": " "}
  ]}

結果 (ID=1、NAME=Alice の行):
  00001Alice
  • 値が幅より長い場合は、幅の位置で切り捨てられる
  • 定義に無いカラムは出力されない
  • 既存のデータセットからカラムの一覧を作りたいときは、⋮ メニューの generate で雛型を作れる（Generate Fixed Column Def）

開き方

fixedColumnDef の ⋮ メニューの edit から開きます。テキストボックスの値のファイル名が <workspace>/resources/fixed-column-def にあればその内容が読み込まれ、空の場合は空の定義が 1 行ある状態で開きます。

同じメニューの generate からは、既存データセットのカラム構成をもとに雛型を作れます（Generate Fixed Column Def）。生成結果はこのダイアログに反映された状態で開きます。

設定項目

Column Definitions の表の 1 行が、出力ファイルの 1 カラムです。表の上から順に、固定長ファイルの左からカラムが並びます。行の edit で開く Column Def Setting で、次の項目を設定します。

項目説明デフォルト
name出力するカラム名。データセットがロード済みの場合、候補からカラム名を選べる（空）
lengthカラムの幅。文字数で数えるかバイト数で数えるかは、Result Form の fixedLengthType で決まる。数値以外を入力すると 0 になる。0
align値が幅に満たないときの寄せ方向: left（左寄せ）/ right（右寄せ）left
pad値が幅に満たない部分を埋める 1 文字。2 文字目以降は入力できない。空にすると半角スペースに戻る。半角スペース

表の各行の Target には name (length) の形で表示されます。

操作

Column Definitions の表の add / edit / delete / copy で行を編集します。各ボタンの動きと、行を並び替えられないことは 画面共通の操作 の「設定一覧表」を参照してください。表の順がそのまま出力のカラム順になるため、途中にカラムを入れたい場合は、後ろの行を delete してから add で追加し直してください。

保存

保存先は <workspace>/resources/fixed-column-def です。name 欄と Save の動きは 画面共通の操作 を参照してください。

注意

  • name が空の行は保存されません。

関連

  • resultType: fixed — この定義を使って固定長で出力する
  • Generate Fixed Column Def — 既存データセットから雛型を生成する
  • generateType: fixedColumnDef — Generate で雛型を作る
