Fixed Column Def

固定長ファイルに出力するときの、カラムごとの幅・寄せ方向・埋める文字の定義（Fixed Column Def）を編集するダイアログです。resultType: fixed のときに表示される fixedColumnDef テキストボックス横のメニューの編集ボタンから開きます。

開き方

fixedColumnDef テキストボックス横のメニューにある編集ボタンから開きます。テキストボックスの値のファイル名が <workspace>/resources/fixed-column-def にあればその内容が読み込まれ、空の場合は空の定義が 1 行ある状態で開きます。同じメニューの削除ボタンでは、候補にある定義ファイルを削除できます。

同じメニューの generate ボタンからは、既存データセットのカラム構成をもとに雛型を作れます（Fixed Column Def Generate）。生成結果はこのダイアログに反映された状態で開きます。

設定項目

Column Definitions の表の 1 行が、出力ファイルの 1 カラムです。表の上から順に、固定長ファイルの左からカラムが並びます。行の編集ボタンで開く Column Def Setting で、次の項目を設定します。

項目説明デフォルト
name出力するカラム名。データセットがロード済みの場合、候補からカラム名を選べる（空）
lengthカラムの幅。文字数で数えるかバイト数で数えるかは、Result Form の fixedLengthType で決まる。数値以外を入力すると 0 になる。0
align値が幅に満たないときの寄せ方向: left（左寄せ）/ right（右寄せ）left
pad値が幅に満たない部分を埋める 1 文字。2 文字目以降は入力できない。空にすると半角スペースに戻る。半角スペース

表の各行の Target には name (length) の形で表示されます。

記述例

保存されるファイルは次の形式の JSON です。

{
  "columns": [
    {"name": "ID", "length": 5, "align": "right", "pad": "0"},
    {"name": "NAME", "length": 10, "align": "left", "pad": " "}
  ]
}

この定義で ID=1、NAME=Alice の行を出力すると、次のようになります。

00001Alice
  • 値が幅より長い場合は、幅の位置で切り捨てられる
  • 定義に無いカラムは出力されない

操作

ボタン動作
追加表の最後の行の下にあるボタン。空の Column Def Setting を開き、Save で表の末尾に追加する
編集その行の Column Def Setting を開き、Save で内容を置き換える
削除その行を表から取り除く
コピーその行の内容を初期値にして Column Def Setting を開き、Save で表の末尾に追加する

行の並び替えはできません。途中にカラムを入れたい場合は、後ろの行を削除してから追加し直してください。

保存

ダイアログ下部の name に保存先のファイル名を指定して Save を押すと、内容が <workspace>/resources/fixed-column-def にファイルとして書き出され、fixedColumnDef テキストボックスにそのファイル名が設定されます。存在しない名前を指定すると新規ファイルとして作成され、既存のファイル名を指定すると上書きされます。

注意

  • name が空の行は保存されません。
  • Close を押すと、保存せずにダイアログを閉じます（fixedColumnDef テキストボックスは変更されません）。

関連

  • resultType: fixed — この定義を使って固定長で出力する
  • Fixed Column Def Generate — 既存データセットから雛型を生成する
  • generateType: fixedColumnDef — Generate で雛型を作る
