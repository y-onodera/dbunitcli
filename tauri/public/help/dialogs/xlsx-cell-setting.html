Xlsx Cell Setting

Excel シート上の任意のセル位置から値を拾い集めてテーブルを構成するための設定を編集するダイアログです。帳票・フォーマット化された Excel など、行方向に整列していないデータの抽出に利用します。全体構成は Xlsx Schema を参照してください。

シンプルな使い方

値のあるセルの位置を並べて、帳票などから 1 レコードを読み込みます。

例: 請求書の見出しのセルから、請求番号・発行日・顧客名・合計を読み込みます。

入力 (シート Invoice):
  B2: INV-001   B3: 2026-04-01   B4: Alice   F10: 12000

指定:
  sheetName = Invoice
  tableName = invoice_header
  header    = invoice_no,issue_date,customer_name,total
  rows      = B2,B3,B4,F10

結果 (テーブル invoice_header):
  invoice_no | issue_date | customer_name | total
  INV-001    | 2026-04-01 | Alice         | 12000
  • header と rows のセルアドレスは同じ順に対応させる
  • 複数の帳票が 1 シートに並ぶ場合は、rows に行を追加してそれぞれのセルアドレスを書く。1 行が 1 レコードになる

開き方

Xlsx Schema の Random Cell Mapping Tables で、行の編集ボタンから開きます。

設定項目

項目説明
sheet抽出対象のシートの指定方法。name はシート名で、pattern はシート名のパターンで指定する。切り替えると入力中のシート名と string を引き継ぐ。
sheetName（sheet が name のとき）抽出対象の Excel シート名。データセットがロード済みの場合、候補がデータリストから選択できる。
string（sheet が pattern のとき）この文字列を含むシートを対象にする。* はすべてのシートに一致する。
regex（sheet が pattern のとき）シート名全体に一致する正規表現。string と両方あれば regex を使う。
exclude（sheet が pattern のとき）パターンに一致しても対象から除くシート名（完全一致）。データセットがロード済みの場合、候補がデータリストから選択できる。
tableName抽出結果に付与する論理テーブル名
headerカラム名の並び。カンマ区切りで指定する。各レコードのセルアドレスと同じ順序で対応させる。
rows1 レコード分のセルアドレスをカンマ区切りで指定する。行を追加することで複数レコードを定義できる。
addFileInfo元ファイル名などのファイル情報カラムを結果に追加するかどうか

Preview

ダイアログ下部の Preview を押すと、編集中のこの定義で読み込まれるテーブルの一覧を表示します（Dataset Load Form の Preview Apply Settings と同じ表示です）。一覧の preview ボタンを押すと、そのテーブルのデータを表示します。

  • 適用するのはこのダイアログで編集中の定義 1 件だけです。Xlsx Schema のほかの行や、フォームの xlsxSchema・setting に指定したファイルは適用しません。
  • Save を押す前の内容でも確認でき、プレビューしてもスキーマファイルは保存されません。
  • Preview はフォームで srcType を指定しているときだけ表示されます。

注意

  1. sheetName（sheet が pattern のときは string か regex）と tableName の両方が入力されていない行は保存対象から除外されます。
  2. header と各 rows のセルアドレス数は一致させてください。
  3. セルアドレスは Excel の A1 形式で指定します。
