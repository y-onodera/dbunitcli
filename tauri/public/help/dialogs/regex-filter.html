Select from Table List

読み込まれるテーブルの一覧からチェックした行で、絞り込みの正規表現を組み立てるダイアログです。traversal の regInclude / regExclude、data load の regTableInclude / regTableExclude の横の編集ボタンから開きます。

シンプルな使い方

正規表現を書かずに、読み込むファイルやテーブルを一覧から選んで絞り込みます。

入力 (src = C:\data):
  old\users.csv
  new\users.csv
  other.csv

指定:
  regInclude の横の編集ボタン → old\users.csv と new\users.csv をチェック → Apply

結果:
  regInclude = (?:^|[\\/])(?:old[\\/]users\.csv|new[\\/]users\.csv)$
  • 一覧は、編集している項目だけを空にして、ほかの項目（traversal・テーブル名の絞り込み・setting など）は今の値のまま読み込む
  • 開いたときは、編集している項目の今の値に一致する行にチェックが付いている

開き方

各項目は optional の項目のため、traversal option / data load option を開いてから、項目の横の編集ボタンを押します。src を指定していないとき（JDBC 系の srcType では接続テストに成功していないとき）は一覧を読み込めません。Run の traversal にはこのボタンはありません。

設定項目

一覧の列は、開いた項目によって変わります。どの項目でも、その行から読み込まれる最終的なテーブル名（setting 適用後）を table 列に並べます。

項目一覧の行（チェックする値）組み立てる正規表現
regInclude / regExcludefile: 読み込むファイル。src がディレクトリなら src からの相対パスチェックしたパスのどれかでパスが終わる条件。区切りは \ と / の両方に一致する
regTableInclude / regTableExcludesource table: setting を適用する前のテーブル名チェックしたテーブル名のどれかに完全に一致する条件（^(?:A|B)$）
  • 正規表現で意味を持つ文字（. など）は \ を付けて文字そのものとして扱う
  • include の項目ではチェックした行が読み込む対象に、exclude の項目ではチェックした行が外す対象になる
  • 1 つの最終テーブルが複数のファイル・テーブルから読み込まれる場合は、読込元ごとに行が分かれる

操作

操作説明
Filter入力した文字を含む行だけを表示する（チェックしたままの行も、表示されていなければそのまま残る）
見出しのチェックボックス表示している行をまとめてチェック・解除する
Apply一覧の下に表示している正規表現を項目に設定して閉じる。何もチェックしていなければ項目を空にする
Cancel項目を変えずに閉じる

注意

  • 開いたときのチェックは、今の値をブラウザの正規表現として解釈して判定します。Java だけが解釈できる書き方（所有量指定子など）では、一致する行があってもチェックが付かないことがあります。
  • Apply すると項目の値は組み立てた正規表現で置き換わります。手で書いた条件と組み合わせたいときは、Apply の後に編集してください。
