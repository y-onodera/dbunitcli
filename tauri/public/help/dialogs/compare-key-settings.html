Compare Key Settings

Compare の setting（比較の設定ファイル）のうち、テーブルごとの比較キー（主キー）だけを編集するダイアログです。targetType が data のとき、setting 横のメニューの編集ボタンから開きます。

シンプルな使い方

Key Settings の表の追加ボタンで Compare Key Setting を開き、対象のテーブルと keys を指定します。

指定:
  setting 横のメニューの編集ボタン → Key Settings の追加ボタン
  Target の name = users
  Keys の keys   = id
  → Save（Compare Key Setting）
  ファイル名     = compare-keys.json
  → Save（Compare Key Settings）

結果:
  setting = compare-keys.json
  users は id が同じ行どうしを突き合わせて比較する
  • テーブル名とカラム名の候補（Load Columns）は、old に指定したデータセットから取得する
  • 表の行には対象テーブルと比較キーを users [id] の形で表示する

開き方

ボタン説明
編集ボタンsetting に指定したファイルを開く。空欄なら新しく作る
generate ボタンDataset Setting Generate で既存データセットから雛型を生成し、このダイアログで確認・保存する
削除ボタンsetting に指定したファイルを削除する。候補に表示されるファイルのときだけ表示

targetType が image / pdf のときは setting を使わないため、編集ボタンと generate ボタンは表示されません。

記述内容

項目説明
Key Settingsテーブルごとの比較キー。ファイルの settings に保存する
Common Key Settings複数テーブルに共通で適用する比較キー。ファイルの commonSettings に保存する。Key Settings と重なったときの扱いは Dataset Settings の commonSettings と同じ

行の編集ボタン（新しく作るときは追加ボタン）で開く Compare Key Setting では、次の項目だけを編集します。

項目説明
Target対象のテーブルの指定方法（name / pattern / 結合）。書き方は Dataset Setting と同じ
Keys比較キーにするカラム。Load Columns で old のデータセットからカラム名の候補を読み込める

保存

Compare Key Settings の Save で、ファイル名に指定したファイルへ書き出し、そのファイルを setting に設定します。Compare Key Setting の Save は表に反映するだけで、ファイルには書き出しません。

注意

  • ファイルにある keys 以外の設定（exclude・filter・order・outputFilter・import など）は、このダイアログでは表示しないが、保存しても消えずにそのまま残る
  • それらを編集する場合は、ファイルを直接編集するか、同じ書式の Dataset Settings を参照してください
