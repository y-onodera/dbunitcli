Compare Key Settings

Compare の setting（比較の設定ファイル）のうち、テーブルごとの比較キー（主キー）だけを編集するダイアログです。targetType が data のとき、setting の ⋮ メニューの edit から開きます。

シンプルな使い方

Key Settings の表の add で Compare Key Setting を開き、対象のテーブルと keys を指定します。

指定:
  setting の ⋮ メニューの edit → Key Settings の add
  Target の name = users
  Keys の keys   = id
  → Save（Compare Key Setting）
  ファイル名     = compare-keys.json
  → Save（Compare Key Settings）

結果:
  setting = compare-keys.json
  users は id が同じ行どうしを突き合わせて比較する
  • テーブル名とカラム名の候補（Load Columns）は、old に指定したデータセットから取得する
  • 表の行には対象テーブルと比較キーを users [id] の形で表示する

開き方

setting の ⋮ メニューの edit で開きます。generate では、Generate Dataset Setting で既存データセットから作った雛型をこのダイアログで確認・保存します。⋮ メニューのボタンの動きは 画面共通の操作 を参照してください。

targetType が image / pdf のときは setting を使わないため、edit と generate は表示されません。

記述内容

項目説明
Key Settingsテーブルごとの比較キー。ファイルの settings に保存する
Common Key Settings複数テーブルに共通で適用する比較キー。ファイルの commonSettings に保存する。Key Settings と重なったときの扱いは Dataset Settings の commonSettings と同じ

行の edit（新しく作るときは表の add）で開く Compare Key Setting では、次の項目だけを編集します。

項目説明
Target対象のテーブルの指定方法（name / pattern / 結合）。書き方は Dataset Setting と同じ
Keys比較キーにするカラム。Load Columns で old のデータセットからカラム名の候補を読み込める

保存

保存先は Workspace の option/compare/setting です（name 欄と Save の動きは 画面共通の操作 を参照）。setting の候補と delete も option/compare/setting のファイルが対象です（resources/setting のファイルはファイル名だけでは見つかりません）。ファイルの読み込み・保存には、Compare に入力中の settingEncoding の文字コードを使います（未入力ならシステムデフォルト）。

注意

  • ファイルにある keys 以外の設定（exclude・filter・order・outputFilter・import など）は、このダイアログでは表示しないが、保存しても消えずにそのまま残る
  • それらを編集する場合は、ファイルを直接編集するか、同じ書式の Dataset Settings を参照してください
