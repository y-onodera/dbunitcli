Fixed Column Def Generate

既存データセット（CSV / Excel / DB など）のカラム構成から、固定長ファイル出力用のカラム幅定義（Fixed Column Def）の雛型を自動生成します。fixedColumnDef テキストボックス横のメニューの generate ボタンから開きます。

できること

  • 元データセットのカラム名を並び順どおりに取り込み、カラムごとの幅・寄せ方向・パディング文字の定義を一括で作成する
  • 生成結果を編集ダイアログで確認し、カラムごとの幅などを修正して名前を付けて保存する

生成直後は全カラムが同じデフォルト値（幅 10・左寄せ・空白パディング）になるため、実際の固定長レイアウトに合わせて各カラムの幅を手直しする使い方を想定しています。

入力

雛型の元にするデータセットを、共通の Dataset Load Form で指定します。srcType の選択に応じて入力項目が切り替わります。データ行は読み込まず、カラム名のみを利用します。

項目説明
srcData雛型の元にするデータセット。srcType・パス・文字コード・ヘッダ指定などを Dataset Load Form と同じ要領で指定する。

操作の流れ

  1. 元にするデータセットを指定します。
  2. Execute を押すと、カラム構成から固定長の幅定義が生成されます。
  3. 生成結果は編集ダイアログに反映された状態で開きます。各カラムの内容を確認・修正してください。
  4. ファイル名を指定して保存すると、その名前が fixedColumnDef テキストボックスに設定されます。

生成例

たとえば USERS テーブル（カラム ID / NAME / EMAIL）を含むデータセットを指定して Execute すると、次のような定義が生成されます。

{
  "columns": [
{"name": "ID", "length": 10, "align": "left", "pad": " "},{"name": "NAME", "length": 10, "align": "left", "pad": " "},{"name": "EMAIL", "length": 10, "align": "left", "pad": " "}
  ]
}

生成ルール

項目生成される値
name元データセットのカラム名。並び順がそのまま固定長ファイル上のカラム順になる。
length常に 10。実際のレイアウトに合わせて編集する。
align常に left（左寄せ）。数値などを右寄せにしたいカラムは right に変更する。
pad常に半角スペース。値が幅に満たない部分を埋める文字。

データセットに複数のテーブルがある場合、全テーブルのカラムが 1 つの定義に連結されます。テーブルごとに別の定義が必要な場合は、テーブルを 1 つずつ指定して生成してください。

この定義で出力される固定長ファイルのイメージ

この定義を固定長出力の fixedColumnDef に指定すると、各行は定義したカラムの順に、幅ぴったりに揃えて出力されます。上の生成例（全カラム幅 10・左寄せ）で、次の 2 行を出力した場合の例です。

IDNAMEEMAIL
1Alicealice@example.com
2Bobbob@example.com
1         Alice     alice@exam
2         Bob       bob@exampl
  • 値が幅より短い場合は、align に従って pad で埋められます（左寄せなら右側が空白になります）。
  • 値が幅より長い場合は、幅の位置で切り捨てられます。上の EMAIL のように値が欠けるカラムは、生成後に length を広げてください。
  • 定義に無いカラムは出力されません。

注意

  • Execute が失敗した場合は、ダイアログ内にエラーメッセージが表示されます。入力内容を見直して再度実行してください。
  • Close を押すと、生成せずにダイアログを閉じます（fixedColumnDef テキストボックスは変更されません）。

関連

  • resultType: fixed — 定義ファイルを使って固定長で出力する
  • generateType: fixedColumnDef — Generate で雛型を作る
