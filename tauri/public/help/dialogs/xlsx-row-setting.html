Xlsx Row Setting

Excel シートから行方向に整列したデータをテーブルとして抽出するための設定を編集するダイアログです。全体構成は Xlsx Schema を参照してください。

開き方

Xlsx Schema の Rows Mapping Tables で、行の編集ボタンから開きます。

設定項目

項目説明
sheetName抽出対象の Excel シート名。データセットがロード済みの場合、候補がデータリストから選択できる。
tableName抽出結果に付与する論理テーブル名
headerカラム名の並び。カンマ区切りで指定し、columnIndex で指定した列の順序と対応させる。
dataStart最初のレコードがある行の番号。1 行目を 0 として数える（例: 2 行目なら 1）。
columnIndex各カラムが格納されている列の番号をカンマ区切りで指定する。A 列を 0 として数える（例: A・B・D 列なら 0,1,3）。header と同じ並びで対応させる。
breakKeyレコードとして読む行を判定するカラム名をカンマ区切りで指定する。dataStart 以降で、指定したカラムのどれかに値がある行だけをレコードにする。
addFileInfo元ファイル名などのファイル情報カラムを結果に追加するかどうか

記述例

A 列〜D 列に並んだ注文明細表の抽出

項目値
sheetNameOrders
tableNameorders
headerorder_id,customer,item,amount
dataStart1
columnIndex0,1,2,3
breakKeyorder_id

1 行目が見出し、2 行目以降が明細の表です。order_id が空の行（合計行・空行など）はレコードになりません。

Preview

ダイアログ下部の Preview を押すと、編集中のこの定義で読み込まれるテーブルの一覧を表示します（Dataset Load Form の Preview Apply Settings と同じ表示です）。一覧の preview ボタンを押すと、そのテーブルのデータを表示します。

  • 適用するのはこのダイアログで編集中の定義 1 件だけです。Xlsx Schema のほかの行や、フォームの xlsxSchema・setting に指定したファイルは適用しません。
  • Save を押す前の内容でも確認でき、プレビューしてもスキーマファイルは保存されません。
  • Preview はフォームで srcType を指定しているときだけ表示されます。

注意

  1. sheetName と tableName の両方が入力されていない行は保存対象から除外されます。
  2. header と columnIndex は要素数を一致させてください。
  3. dataStart と columnIndex は 0 から数えた番号で指定します（Excel の行番号・列名ではありません）。
  4. breakKey が空のときはレコードを読みません（テーブルは作られますが、行は 0 件になります）。
