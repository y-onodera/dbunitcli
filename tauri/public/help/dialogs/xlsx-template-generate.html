Xlsx Template Generate

既存データセット（CSV / Excel / DB など）のテーブル・カラム構成から、jxls 用の Excel テンプレート（.xlsx）を自動生成して template リソースへ保存します。generateType が xlsx / xls のとき、template テキストボックス横のメニューの generate ボタンから開きます。

できること

  • テーブルごとに 1 シートを作成し、1 行目にカラム名、2 行目に ${row.get('カラム名')} 形式の埋め込み式を持つテンプレートを作る
  • jxls のコマンド（jx:area / jx:each）をセルコメントとして自動設定する。jx:each はテーブルの全行（param.dataSet.get('テーブル名').rows）を繰り返す。
  • 生成したファイルを template リソースに保存し、template テキストボックスへ設定する

一から手入力する代わりに、生成したテンプレートへ書式・計算式・見出しなどを加えて仕上げる使い方を想定しています。テンプレートの利用方法は Jxls を参照してください。

入力

項目説明
fileName（必須）保存するテンプレートのファイル名。拡張子が .xlsx でなければ .xlsx が付与される（generateType=xls を選択していても出力は常に .xlsx 形式）。ディレクトリ区切り（/ \）や .. は使えない。同名のファイルがある場合は上書きされる。
srcDataテンプレートの元にするデータセット。srcType・パス・文字コード・ヘッダ指定などを Dataset Load Form と同じ要領で指定する。

操作の流れ

  1. 保存するファイル名と、元にするデータセットを指定します。
  2. Execute を押すと、テーブルごとのシートを持つテンプレートが生成され、template リソースへ保存されます。
  3. ダイアログが閉じ、保存したファイル名が template テキストボックスに設定されます。
  4. 必要に応じて、保存されたファイルを Excel で開き、書式などを加えます。

生成例

たとえば USERS テーブル（カラム ID / NAME / EMAIL）を含むデータセットを指定すると、シート USERS が次の内容で作られます。

シート: USERSABC
1IDNAMEEMAIL
2${row.get('ID')}${row.get('NAME')}${row.get('EMAIL')}
セルコメント（jxls コマンド）
A1jx:area(lastCell="C2")
A2jx:each(items="param.dataSet.get('USERS').rows" var="row" varIndex="index" lastCell="C2")

generate コマンドの generateType=xlsx（または xls）、unit=dataset でこのテンプレートを指定すると、各テーブルのデータが対応するシートに展開された Excel が出力されます。

注意

  • テンプレートの生成にはデータ本体を読み込まず、カラム情報のみを使用します。
  • Execute が失敗した場合は、ダイアログ内にエラーメッセージと実行中に出ていたログが表示されます。入力内容を見直して再度実行してください。
  • Close を押すと、生成せずにダイアログを閉じます（template テキストボックスは変更されません）。
