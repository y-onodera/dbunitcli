SQL Editor

srcType が sql / table / csvq のときに、SQL ファイル・テーブル名の一覧ファイルを編集するダイアログです。

シンプルな使い方

src 横のメニューの編集ボタンで開き、SQL を書いて保存します。

例: srcType が sql のとき、有効なユーザだけを読み込む SQL を作ります。

本文:
  select * from USERS where STATUS = 'ACTIVE'

指定:
  name = active_users.sql
  → Save

結果:
  resources/sql/active_users.sql に保存し、src に active_users.sql を設定する
  実行すると、SQL の結果がテーブル active_users として読み込まれる
  • テーブル名は SQL ファイル名（拡張子を除く）になる
  • JDBC の接続テストが成功していれば、Select Tables でテーブル名・カラム名を挿入できる
  • srcType が csvq なら、Select CSV で CSV ファイルを選んで CSVREAD() を挿入できる
  • Save and Preview で、保存したうえで読み込まれる内容を確認できる

開き方

Dataset Load Form の src の横のメニューにある編集ボタンから開きます。src の候補には、保存先のディレクトリにあるファイルが表示されます。同じメニューの削除ボタンでは、候補にあるファイルを削除できます。

記述内容

srcTypeダイアログ名記述内容

tableEdit Table Definition読み込み対象のテーブル名（1 行 1 テーブル）

Select Tables

JDBC 接続が確認済み（JDBC セクションの接続テスト成功）のときのみ、Select Tables ボタンが表示されます。

  1. Select Tables を押し、Load Tables でデータベースのテーブル一覧を取得します。
  2. 挿入したいテーブルにチェックを入れ、Insert を押すと、本文のカーソル位置に挿入され、Select Tables が閉じます。本文で範囲を選択していた場合は、その範囲を置き換えます。
  3. テーブル名の横の Select columns アイコンを押すと、そのテーブルのカラム選択ダイアログ（Select Columns）が開きます。カラムにチェックを入れて Insert Columns を押すと、カーソル位置に 1 行 1 カラムで挿入されます。All Columns を押すと、チェックに関わらずすべてのカラムを 1 行ずつ書き出して挿入します（* は使いません）。Select Tables は開いたままなので、続けて別のテーブルを選べます。

srcType が table の場合は、テーブルを複数選べ、テーブル名・カラム名だけを 1 行ずつ挿入します。以降の項目は表示されません。

srcType が sql / csvq の場合は、使い道（Usage）を選ぶと、それに合った形で挿入します。挿入される内容は Insert の上に表示されます。

挿入する SQL は次の形に揃えます。キーワードは大文字で行頭に置き、句の中身は 4 文字下げ、2 行目以降は , または AND で始めます。テーブル名・カラム名は取得した表記のままです。

SELECT
    T.COLUMNA AS COLUMNA
  , T.COLUMNB AS COLUMNB
FROM
    TABLE T
    INNER JOIN
        TABLE2 T2
          ON  T2.COLUMNA = 
          AND T2.COLUMNB = 
WHERE
    T.COLUMNA = 
AND T.COLUMNB =

テーブル（Select Tables）

選べるテーブルは 1 つです。別のテーブルを選ぶと置き換わります。

Usage が Select / Insert / Update / Left join / Inner join のときは、Insert ボタンが Next に変わります。Next を押すと Select Columns が開き、選んだカラム（All Columns なら全カラム）と合わせた文全体を挿入して、Select Tables が閉じます。このとき Select Columns の Usage はテーブル側に合わせて固定され、Keyword line と Separator on first line は表示されません。

Source が Subquery のときは、Next を押すと次の順に選びます。

  1. Subquery Columns で、SELECT columns にサブクエリで SELECT するカラム（複数可）を、WHERE columns にサブクエリの条件にするカラムを選びます。All Columns を押すと、すべてのカラムを SELECT します。
  2. Usage が Select / Left join / Inner join のときは Next を押すと Select Columns が開き、サブクエリで SELECT したカラムから外側の SELECT のカラム、または ON の条件を選びます。カラムはサブクエリの別名で修飾されます（Prefix table alias は最初から ON）。
  3. Cross join のときは、Subquery Columns の Insert で挿入します。
SELECT
    S.ID
FROM (
    SELECT
        UA.ID
    FROM
        USER_ACCOUNT UA
    WHERE
        UA.NAME = 
) S

join では、 INNER JOIN ( のように JOIN の行末で括弧を開き、 ) S の下に ON の条件を続けます。

        UA.ID IS NOT NULL

IN の Subquery と EXISTS では、Next を押すと次の順に選びます。

  1. Subquery Table でサブクエリのテーブルを 1 つ選び、Table alias を確認して Next を押します。別名のデフォルトは Table alias と同じ規則で、外側の別名と同じになる場合は数字を付けます（例: UA → UA2）。
  2. Subquery Columns で、IN なら SELECT column に SELECT するカラムを 1 つ選びます。EXISTS では SELECT 1 になります。
  3. WHERE columns にサブクエリの条件にするカラムを選びます（カラム = の形。右辺は空）。選ばなければ WHERE は付けません。条件のつなぎは Join conditions with で、別名を付けるかは Prefix table alias で選べます。
  4. Insert を押すと、サブクエリを含む条件を挿入します。
WHERE
    UA.ID NOT IN (
        SELECT
            O.USER_ID
        FROM
            ORDERS O
        WHERE
            O.STATUS = 
    )

テーブル一覧やカラムの取得に失敗したときは、ダイアログ内にエラーメッセージと読込中に出ていたログを表示します。

Select CSV

srcType が csvq のときだけ、Select CSV ボタンが表示されます。CSV ファイルを選び、CSVREAD() でそのファイルを読む文を本文のカーソル位置に挿入します。

  1. Select CSV を押し、Insert CSVREAD で CSV file・Charset・Usage・Table alias を指定します。
  2. Next を押すと、CSV ファイルの先頭行からカラムを読み込み、Select Columns が開きます。
  3. カラムを選んで Insert Columns（All Columns なら全カラム）を押すと、文全体を挿入して Insert CSVREAD が閉じます。Select Columns の Usage は Insert CSVREAD の Usage に合わせて固定されます。

Usage が Cross join のときは、カラムを読み込まずに Insert ですぐ挿入します。

Usage が Left join / Inner join のときに Select Columns の Operator で IN（IN source が Subquery）または EXISTS を選ぶと、Subquery Table ではテーブル一覧の代わりに CSV file と Charset を指定して CSV ファイルを 1 つ選びます。Charset のデフォルトは Insert CSVREAD の Charset、Table alias のデフォルトはファイル選択ボタンで選んだファイル名から作ります。

項目説明デフォルト
CSV file（必須）読み込む CSV ファイル。ファイル選択ボタンで選ぶと、Dataset Base 配下なら Dataset Base から、それ以外の Workspace 配下なら Workspace からの相対パスになる（どちらでもなければ絶対パス）。実行時の相対パスの探し方は csvq を参照。パスの区切りは / にして挿入する（空）
Charset（必須）CSV ファイルの文字コード。CSVREAD() の charset に入れ、カラムの読込にも使うDataset Load Form の encoding。未指定なら UTF-8
UsageSelect / Left join / Inner join / Cross join。挿入する文の形は Select Tables の同じ値と同じSelect
Table aliasCSV ファイルを読んだテーブルの別名。Select Columns でカラムに付ける別名にも使う。Usage が join のときは必須ファイル選択ボタンで選んだファイル名（拡張子を除く）から、Select Tables の Table alias と同じ規則で作る
SELECT
    UA.ID
  , UA.NAME
FROM
    CSVREAD('dataset/user_account.csv',null,'charset=UTF-8') UA

CSVREAD() の書き方は csvq を参照してください。

保存

ダイアログ下部の name に保存先のファイル名を指定して Save を押すと、内容がファイルとして書き出され、元のテキストボックスにそのファイル名が設定されます。保存先は srcType ごとに Workspace の resources/sql / resources/table / resources/csvq です。

Save and Preview を押すと、同じように保存したうえで、保存したファイルを src として読み込まれるテーブルの一覧を表示します（Dataset Load Form の Preview Before Settings と同じ表示です）。setting は指定していても適用しません。一覧の preview ボタンを押すと、そのテーブルのデータを表示します。

Save and Preview では SQL Editor は閉じず、元のテキストボックスのファイル名も変わりません。続けて編集でき、ファイル名を反映するには Save を押してください。
