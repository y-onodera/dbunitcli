Generate Table Definition Template

テーブル定義書（テーブル名・コメントと、カラムの一覧）を出す jxls 用の Excel テンプレート（.xlsx）を生成して template リソースへ保存します。generateType が xlsx / xls のとき、template の ⋮ メニューの generate table definition template から開きます。

シンプルな使い方

指定:
  fileName = tableDef
  → Execute

結果:
  template リソースに tableDef.xlsx を保存し、template に tableDef.xlsx を設定する

続けて generate フォームで:
  unit              = table
  src の loadData     = OFF
  src の loadMetaData = ON
  resultPath        = $param.tableName$.xlsx
  → テーブルごとに 1 ファイルのテーブル定義書を出力する

入力

項目説明
fileName（必須）保存するテンプレートのファイル名。拡張子が .xlsx でなければ .xlsx が付与される。ディレクトリ区切り（/ \）や .. は使えない。同名のファイルがある場合は上書きされる。

テンプレートのレイアウトは固定のため、元にするデータセットは指定しません。

生成されるテンプレート

シート: テーブル定義ABCDEFGH
1テーブル名${param.tableName}
2コメント${row.get('TABLE_REMARKS')}
3
4Noカラム名型桁小数NOT NULLPKコメント
5${index + 1}COLUMN_NAMETYPE_NAMECOLUMN_SIZEDECIMAL_DIGITSNULLABLE が false なら ○IS_PK が true なら ○REMARKS
セルコメント（jxls コマンド）
A1jx:area(lastCell="H5")
B2jx:each(items="param.rows" var="row" varIndex="index" select="index == 0" lastCell="B2")（テーブルのコメントを最初の 1 行から取る）
A5jx:each(items="param.rows" var="row" varIndex="index" lastCell="H5")

見出しや列の並び・書式は、保存されたファイルを Excel で開いて変更できます。5 行目の各セルが参照する項目は loadMetaData の詳細 を参照してください。

テンプレートの使い方

  • unit = table で使う（1 テーブルにつき 1 ファイルを出力する）。resultPath に $param.tableName$ を含めて、テーブルごとに出力先を分ける
  • src の loadData を OFF、loadMetaData を ON にして、テーブル定義を読み込む
  • 桁数・主キー・コメントまで出すには、srcType = table でデータベースを読み込む
