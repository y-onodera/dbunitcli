compare

Generate で比較用の Excel テンプレートを生成するときに、比べる 2 テーブルと突合に使うカラムを指定するセクションです。generate セクションで generateType = xlsxTemplate、templateType = compare を選ぶと表示されます。

シンプルな使い方

src から読み込んだテーブルのうち 2 つを名前で選び、キーで行を突き合わせて値を比べる Excel テンプレートを作ります。

入力 (src = data):
  data/USERS_OLD.csv   ID,NAME,AMT
  data/USERS_NEW.csv   ID,NAME,AMT

指定:
  generateType = xlsxTemplate
  templateType = compare
  oldTable     = USERS_OLD
  newTable     = USERS_NEW
  keys         = ID
  resultPath   = compare.xlsx

結果 (compare.xlsx):
  シート USERS_OLD / USERS_NEW / compare
  compare シートは USERS_OLD の行ごとに、ID が同じ USERS_NEW の行と NAME・AMT を並べて比べる
  • compares を省くと、キー以外で両方のテーブルにある同じ名前のカラム（上の例では NAME と AMT）を比べる
  • データのシート名はテーブル名と同じになる。生成したファイルを generateType: xlsx / xls（unit = dataset）の template に指定し、同じ src で実行すると、シート名と同じ名前のテーブルの行が流し込まれる
  • 比較シートの列と STATUS の意味は Generate Compare Template の「生成ルール」と同じ

設定項目

項目説明デフォルト
oldTable（必須）比べる基準にするテーブルの名前。src の setting を適用した後のテーブル名で、大文字・小文字も含めて完全に一致させる—
newTable（必須）oldTable と突き合わせるテーブルの名前。oldTable と同じ名前は指定できない—
keys（必須）行を突き合わせるキーのカラム。複数あれば複合キーにする（下記「keys / compares の書き方」）—
compares値を比べるカラム（下記「keys / compares の書き方」）（空）。キー以外で両方のテーブルにある同じ名前のカラム
compareSheetName比較シートの名前。テーブル名と同じ名前は指定できないcompare

keys / compares の書き方

カラムをカンマ区切りで並べます。old と new でカラム名が違う場合は old のカラム:new のカラム と書き、同じ名前なら 1 つだけ書きます。

keys     = ID:CODE,SUB      → old の ID と new の CODE、両方の SUB を複合キーにする
compares = NAME:NAME2,AMT   → old の NAME と new の NAME2、両方の AMT を比べる
  • 書いた順に複合キーを連結し、比較シートの列も書いた順に並ぶ
  • テーブルに無いカラムを書くと、実行時にエラーになる

比べるテーブルの用意

oldTable / newTable には、src の読み込みと setting の適用が終わった後のテーブル名を書きます。読み込んだファイルの名前が比べたい形になっていないときは、次のように使い分けてください。

状況使うもの
比べる 2 つのファイル（テーブル）の名前が違うテーブル名をそのまま oldTable / newTable に書く（シンプルな使い方）
1 つのテーブルの中に old と new の行があるsetting に同じ name を対象にした設定を 2 つ書き、tableName で別の名前を付ける。行は filter で分ける（例 1）
同じ名前のファイルが別のディレクトリにある（old/USERS.csv と new/USERS.csv）上の応用。setting の name に filePath を添えて、読み込み元のパスで設定を分ける（例 2）
recursive で探すと、比べないファイルまで読み込むtraversal の regInclude で、読み込むファイルを狙ったパスに絞る（例 3）

名前・パスを指定する箇所は 3 つあり、照合する相手と一致の仕方が違います。

項目照合する相手一致の仕方
compare セクションの oldTable / newTablesetting を適用した後のテーブル名完全一致（正規表現ではない）
setting の filePath読み込み元ファイルの絶対パス（区切りは /）正規表現がパス全体に一致する。先頭は .*/ から書く（例: .*/old/USERS\.csv）
traversal の regInclude読み込むファイルのパス（区切りは OS のもの。Windows では \）正規表現がパスの一部に一致すれば読み込む
  • setting の name は読み込んだときのテーブル名（CSV ならファイル名から拡張子を除いたもの）で、tableName が付け直した後の名前になる。oldTable / newTable に書くのは tableName の方
  • setting は読み込んだファイルを残したまま名前を付け分ける。regInclude はファイルを読み込むかどうかを決める。比べないファイルを読み込みたくないときは regInclude、読み込んだテーブルに別の名前を付けたいときは setting を使う
  • regInclude の横の編集ボタンを押すと、読み込まれるファイルの一覧（src からの相対パスと、setting を適用した後のテーブル名）からチェックして正規表現を組み立てられる。区切り文字の違いも吸収するため、手で書くよりこちらを使ってください（Select from Table List）

例

例 1: 1 つのテーブルを setting で 2 つの名前にする

同じ name を対象にした設定を 2 つ書くと、1 つのテーブルから別の名前のテーブルが 2 つできます。filter でそれぞれに入る行を分けます。

入力 (src = one):
  one/USERS.csv
    ID,KIND,NAME,AMT
    1,old,a,10
    2,old,b,20
    1,new,a,11
    3,new,c,30

setting:
  {
    "settings": [
      { "name": "USERS", "tableName": "OLD_USERS", "filter": ["KIND == 'old'"] },
      { "name": "USERS", "tableName": "NEW_USERS", "filter": ["KIND == 'new'"] }
    ]
  }

指定:
  oldTable = OLD_USERS
  newTable = NEW_USERS
  keys     = ID

結果:
  OLD_USERS: ID=1, 2 の行 / NEW_USERS: ID=1, 3 の行
  compares を省いたので KIND・NAME・AMT を比べる

例 2: 別のディレクトリにある同じ名前のファイルを名前で分ける

例 1 の応用です。対象を name と filePath で指定すると、同じテーブル名でも読み込み元のパスごとに別の設定を当てられます。

入力 (src = data、recursive = ON):
  data/old/USERS.csv
  data/new/USERS.csv
  data/old/backup/USERS.csv

setting:
  {
    "settings": [
      { "name": { "any": "USERS", "filePath": ".*/old/USERS\\.csv" }, "tableName": "OLD_USERS" },
      { "name": { "any": "USERS", "filePath": ".*/new/USERS\\.csv" }, "tableName": "NEW_USERS" }
    ]
  }

指定:
  oldTable = OLD_USERS
  newTable = NEW_USERS
  keys     = ID

結果:
  テーブル OLD_USERS（old/USERS.csv）/ NEW_USERS（new/USERS.csv）/ USERS（old/backup/USERS.csv）
  比較に使うのは OLD_USERS と NEW_USERS
  • filePath はパス全体と照合するため、old/backup/USERS.csv は .*/old/USERS\.csv に一致せず、名前は USERS のまま残る
  • JSON の中では \ を \\ と書く

例 3: recursive で探すファイルを regInclude で絞る

例 2 の old/backup/USERS.csv のように、比べないファイルを読み込まないようにします。

入力 (src = data、recursive = ON):
  data/old/USERS.csv
  data/new/USERS.csv
  data/old/backup/USERS.csv

指定:
  regInclude = [\\/](old|new)[\\/]USERS\.csv$
  setting    = 例 2 と同じ
  oldTable   = OLD_USERS
  newTable   = NEW_USERS
  keys       = ID

結果:
  テーブル OLD_USERS / NEW_USERS だけを読み込む（old/backup/USERS.csv は読み込まない）
  • [\\/] は \ と / のどちらにも一致する。Windows と Linux・macOS で同じ値を使える
  • regInclude は読み込むファイルを絞るだけで、名前は付け分けない。同じ名前のファイルが残るなら、例 2 の setting も必要
  • regInclude の編集ボタンから old/USERS.csv と new/USERS.csv をチェックして Apply しても、同じ絞り込みになる

注意

  • 同じ名前のファイルを setting なしで読み込むと、1 つのテーブルにまとまります。別々に比べるには例 2 のように名前を付け分けてください。
  • oldTable / newTable の名前のテーブルが無いと、実行時にエラーになります。エラーメッセージに、読み込んだテーブル名の一覧が出ます。
  • 生成したテンプレートで Excel を出力するときは、テンプレートを作ったときと同じ src・setting を指定してください。テーブル名が変わると、シートに行が流し込まれません。
