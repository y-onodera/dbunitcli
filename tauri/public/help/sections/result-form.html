Result Form

各コマンドで「出力先と出力形式」を指定するための共通フォームです。Convert の convertResult、Compare の出力設定などで使用されます。

フォームの構成は resultType により変わります。選択した形式ごとに表示される項目が異なります。各形式の固有オプションと出力例は、形式名のリンク先の個別ページを参照してください。

シンプルな使い方

出力の形式を resultType で選び、result に出力先のディレクトリを指定します。resultType のデフォルトは csv です。

例: テーブル ORDERS / ITEMS を CSV で出力します。

指定:
  result = out

結果:
  out/ORDERS.csv
  out/ITEMS.csv
  • テーブルごとに テーブル名.csv のファイルを作る
  • result の相対パスは Result Base からの相対。空なら Result Base に出力する（Workspace を参照）
  • 1 つの Excel ブックにまとめたいときは resultType を xlsx にする（xls / xlsx）

resultType 一覧

出力データの形式を選択します。以下の 6 種類から選択できます。

値説明
csvCSV（区切り文字付きテキスト）で出力。拡張子・文字コードを変更可能
xlsExcel 97-2003 形式（.xls）で出力
xlsxExcel 2007 以降の形式（.xlsx）で出力
tableJDBC 接続先の DB テーブルへ書き込む
formatString.format() 書式でテキストとして出力
fixed固定長テキストで出力

共通項目（table 以外）

resultType が table 以外の場合に表示される共通項目です。

項目説明デフォルト
result出力先ディレクトリのパス。相対パスは Result Base からの相対（空）＝ Result Base
resultPath全テーブルをまとめたブックのファイル名（拡張子なし）。xls / xlsx のときだけ表示し、excelTable=BOOK のときは表示しない（下記「result と resultPath の生成例」を参照）（空）
exportEmptyTableON にすると、データ行が 0 件のテーブルも出力するON
exportHeaderON にすると、出力ファイルにヘッダ行を含める。format / fixed ではヘッダ行を出力しないため表示しないON
appendON にすると、出力先に同名のファイル（xls / xlsx は同名のシート）が既にある場合、ヘッダ行が書かれているものとして中身を確かめずに末尾へデータ行を追記する（ヘッダ行は書かない）。無い場合は OFF と同じく新しく作る。OFF では既存のファイルを上書きするOFF
parallel入力ソースを並列に読み込むスレッド数。並列化できる組み合わせのときだけ表示（table でも表示）。1 で逐次。空欄なら並列化できる場合に CPU コア数で並列化する（Parameterize の並列実行の中では逐次）。詳細は下記「並列読込」を参照（空）

並列読込（parallel）

入力ソースが複数ある場合に、ソースごとに並列に読み込み・出力します。出力先のテーブルが同じになるソース同士は同じスレッドで元の順に処理するため、追記の順序は逐次処理と変わりません。

parallel は次の組み合わせのときだけ表示されます。

  • Convert: 入力の srcType が file / dir 以外で、出力形式が xls / xlsx 以外、または excelTable が SHEET 以外（excelTable は環境変数などで渡された値もありうるため、SHEET が選ばれているときだけ非表示にします。SHEET かどうかが変わるとフォームが再構成されます。実行時に値が SHEET になった場合は逐次処理です）
  • Compare: new / old のどちらかの srcType が file / dir 以外（出力形式は問わない）

表示されていても、次の場合は実行時に逐次処理になります。

  • 入力ソースが 1 つだけ、または全ソースが同じテーブルへ出力される
  • 設定ファイルで join または件数分割（split）を使っている

xls / xlsx 入力は、実行前に各ファイルのシート名だけを読み、xlsxSchema の定義も含めて出力テーブルを求めます。同じテーブル（同名シート、またはスキーマで同じテーブル名になるシート）を含むファイル同士は同じスレッドで順に処理します。

Compare では、new / old それぞれの読み込みに適用されます（比較結果の出力自体は並列化しません）。並び替え・重複除去を指定したテーブルは全行をメモリに保持するため、並列数を増やすとメモリ使用量も増えます。

入力の srcType が table / sql の場合と、出力形式が table の場合は、スレッドごとに DB 接続を張って読み込み・書き込みます（接続数は読み込み・書き込みそれぞれ最大で並列数。詳細は table を参照）。

result と resultPath の生成例

出力ファイルのパスは result（ディレクトリ）と resultPath（その中のファイル名・相対パス）を組み合わせて決まります。以下の例では Result Base（Workspace で設定。未設定なら Workspace）を C:/work、テーブルを ORDERS / ITEMS の 2 つとします。

result の解決ルール（全コマンド共通）

result の値出力先ディレクトリ
（空）C:/work（Result Base そのもの）
out/convert（相対パス）C:/work/out/convert
D:/export（絶対パス）D:/export（Result Base は使わない）
%USERPROFILE%/exportC:/Users/<ユーザ>/export（%USERPROFILE% / %HOME% は OS の環境変数に置き換わる）

出力先のディレクトリがなければ作成されます。

Convert / Compare（Result Form）

csv / format / fixed と、xls / xlsx の excelTable=BOOK は テーブルごとに テーブル名.拡張子 のファイルを作るため、resultPath は表示されません。resultPath を使うのは、全テーブルを 1 ブックにまとめる xls / xlsx の excelTable=SHEET だけです（excelTable に Env の変数を指定した場合も、BOOK と確定していないため表示されます）。

resultTyperesultresultPath出力されるファイル
csvout（表示されない）C:/work/out/ORDERS.csv
C:/work/out/ITEMS.csv
csv（outputExtension=tsv）out（表示されない）C:/work/out/ORDERS.tsv
C:/work/out/ITEMS.tsv
xlsx（excelTable=BOOK）out（表示されない）C:/work/out/ORDERS.xlsx
C:/work/out/ITEMS.xlsx

xlsx（excelTable=SHEET）outorders_all.xlsxC:/work/out/orders_all.xlsx.xlsx（拡張子は自動で付くため、resultPath には付けない）
xls（excelTable=SHEET）outorders_allC:/work/out/orders_all.xls

excelTable=SHEET で resultPath を省略したときのファイル名はコマンドによって違います。

コマンドresultPath 省略時のファイル名例（result=out/daily、保存名 orders_export）
ConvertGUI の Exec では保存済みオプションの名前。CLI では result（@オプションファイル で実行した場合はそのファイル名から拡張子を除いたもの）C:/work/out/daily/orders_export.xlsx

Compare で expectData を指定した場合、想定差分との比較結果は result の下の expectedDiff ディレクトリに出力されます。

Generate

Generate の resultPath は result からの相対パスで、サブディレクトリも書けます。テンプレートとして処理されるため、テーブル名や行の値を変数として使えます。変数の書き方は Template の設定に従います（以下はデフォルトの templateParameterAttribute=param、区切り文字 $ の場合。templateParameterAttribute を空にした場合は param. を付けずに $tableName$ と書きます）。

テンプレート指定タイプ（txt / xlsx / xls）

unitresultresultPath出力されるファイル
tablegen$param.tableName$.sqlC:/work/gen/ORDERS.sql
C:/work/gen/ITEMS.sql
tablegensql/$param.tableName$/insert.sqlC:/work/gen/sql/ORDERS/insert.sql
C:/work/gen/sql/ITEMS/insert.sql
table（空）$param.tableName$.xlsxC:/work/ORDERS.xlsx
C:/work/ITEMS.xlsx
tablegen$param.tableName; format="snakeToUpperCamel"$.java（テーブル order_detail の場合）C:/work/gen/OrderDetail.java
recordgen$param.tableName$_$param.rowNumber$.txtC:/work/gen/ORDERS_0.txt、C:/work/gen/ORDERS_1.txt、…（行番号はテーブルごとに 0 始まり）
recordgen$param.ORDER_ID$.txt（列 ORDER_ID の値が 1001, 1002 の場合）C:/work/gen/1001.txt、C:/work/gen/1002.txt。srcData の includeMetaData が ON のときは $param.row.ORDER_ID$ と書く
datasetgenall.txtC:/work/gen/all.txt
tablegenall.txt（変数なし）C:/work/gen/all.txt。全テーブルが同じファイルに出力され、最後のテーブルの内容だけが残る
（任意）gen（空）C:/work/gen/orders_export（保存済みオプションの名前。拡張子なし。CLI では result）

unit=table / record で resultPath を省略したり、変数を含めなかったりすると、全テーブル（全行）が同じファイルに上書きされます。テーブルや行ごとにファイルを分けたいときは、必ず tableName や列の値を含めてください。

固定成果物タイプ（sql / ddl / javaBean / xlsxSchema / fixedColumnDef）

テーブル単位の固定成果物タイプでは、resultPath はディレクトリとして扱われ、その下にテーブルごとのファイルが作られます（ファイル名は自動で決まります）。

generateTyperesultresultPath出力されるファイル
sqlgensqlC:/work/gen/sql/ORDERS.sql
C:/work/gen/sql/ITEMS.sql
sql（sqlFilePrefix=V1_、sqlFileSuffix=_insert）gensqlC:/work/gen/sql/V1_ORDERS_insert.sql
ddlgen（空）C:/work/gen/orders_export/ORDERS.sql（保存済みオプションの名前のディレクトリ）
javaBeangensrc/main/java/com/example（テーブル order_detail の場合）C:/work/gen/src/main/java/com/example/OrderDetail.java
xlsxSchema / fixedColumnDefgenschemaC:/work/gen/schema/ORDERS.json

settings / xlsxTemplate（unit=dataset 固定）は、resultPath がそのままファイル名になります（例：resultPath=settings/orders.json → C:/work/gen/settings/orders.json）。

環境変数（Env）と組み合わせる

result / resultPath にも ${env.変数名} を書けます。実行前に Env ファイル（Workspace で選択）の値に置き換わるため、同じ保存済みオプションを Env の切り替えだけで別の出力先に向けられます。Env に定義していない変数を書くとエラーになります。

Env ファイル (env.properties):
outDir=D:/export/dev
stage=dev

Convert（resultType=xlsx、excelTable=SHEET）:
  result     = ${env.outDir}/convert
  resultPath = orders_${env.stage}
  → D:/export/dev/convert/orders_dev.xlsx

Generate（generateType=txt、unit=table）:
  result     = ${env.outDir}
  resultPath = ${env.stage}/$param.tableName$.sql
  → D:/export/dev/dev/ORDERS.sql
    D:/export/dev/dev/ITEMS.sql

Env ファイルを outDir=D:/export/prod、stage=prod のものに切り替えると、オプションを変えずに D:/export/prod/... に出力されます。

パラメータ（-P）と組み合わせる

-P 値は result / resultPath の文字列には埋め込まれません（Convert / Compare ではどちらも使えません）。例外は Generate の resultPath で、テンプレートとして処理されるため $param.inputParam.キー$ で参照できます。

Parameters (-P):
  targetDate = 20261101

Generate（generateType=txt、unit=table）:
  result     = gen
  resultPath = $param.inputParam.targetDate$/$param.tableName$.csv
  → C:/work/gen/20261101/ORDERS.csv
    C:/work/gen/20261101/ITEMS.csv

-P の値に Env を書くこともできます（例：-PtargetDate=${env.targetDate}）。result のディレクトリ部分を実行ごとに変えたい場合は、resultPath 側に書くか、Env または次の Parameterize を使ってください。詳細は Parameters (-P) の「Env との使い分け」を参照してください。

Parameterize と組み合わせる

Parameterize のテンプレート / cmdParam に result / resultPath を書くと、パラメータデータの値を $param.列名$ で埋め込めるため、Convert / Compare でも行ごとに出力先を変えられます。

パラメータデータ (params/targets.csv):
TARGET,BOOK
orders,orders_all
items,items_all

テンプレート (convert_param.txt):
-src=data/$param.TARGET$
-srcType=csv
-resultType=xlsx
-excelTable=SHEET
-result=out/$param.TARGET$
-resultPath=$param.BOOK$

指定:
  unit            = record
  cmd             = convert
  template        = convert_param.txt
  paramData の src = params/targets.csv

→ C:/work/out/orders/orders_all.xlsx
  C:/work/out/items/items_all.xlsx

Generate の resultPath に Generate 側の変数（$param.tableName$ など）を書きたい場合は、そのまま書くと Parameterize のテンプレート処理で先に展開されてしまいます（パラメータデータに該当する列がなければ空になります）。Parameterize の Template 設定で区切り文字（templateVarStart / templateVarStop）を # などに変え、Parameterize の変数と Generate の変数を書き分けてください（@ は区切り文字に使えません）。

パラメータデータ (params/targets.csv):
TARGET
orders
items

テンプレート (generate_param.txt):
-generateType=txt
-unit=table
-template=insert.txt
-src=data/#param.TARGET#
-srcType=csv
-result=gen/#param.TARGET#
-resultPath=$param.tableName$.sql

指定:
  unit             = record
  cmd              = generate
  template         = generate_param.txt
  templateVarStart = #   (templateOption)
  templateVarStop  = #   (templateOption)
  paramData の src  = params/targets.csv

→ C:/work/gen/orders/ORDERS.sql
  C:/work/gen/items/ITEMS.sql
