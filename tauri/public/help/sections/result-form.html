Result Form

各コマンドで「出力先と出力形式」を指定するための共通フォームです。Convert の convertResult、Compare の出力設定などで使用されます。

フォームの構成は Result Type 選択により変わります。選択した形式ごとに表示される項目が異なります。各形式の固有オプションと出力例は、形式名のリンク先の個別ページを参照してください。

Result Type 選択

出力データの形式を選択します。以下の 6 種類から選択できます。

形式説明
csvCSV（区切り文字付きテキスト）で出力。拡張子・文字コードを変更可能
xlsExcel 97-2003 形式（.xls）で出力
xlsxExcel 2007 以降の形式（.xlsx）で出力
tableJDBC 接続先の DB テーブルへ書き込む
formatString.format() 書式でテキストとして出力
fixed固定長テキストで出力

共通項目（table 以外）

Result Type が table 以外の場合に表示される共通項目です。

項目説明
result出力先ディレクトリのパス
resultPath出力先パスのテンプレート文字列。テーブル名などを変数として使用可能
exportEmptyTableON にすると、データ行が 0 件のテーブルも出力する（デフォルト: ON）
exportHeaderON にすると、出力ファイルにヘッダ行を含める（デフォルト: ON）
parallel入力ソース（ファイル）を並列に読み込むスレッド数（並列化できる組み合わせのときだけ表示。table でも表示）。1 で逐次処理。空欄なら、並列化できる場合に CPU コア数で並列化する（デフォルト: 空欄）。詳細は下記「並列読込」を参照

並列読込（parallel）

入力ソースが複数ある場合に、ソースごとに別スレッドで読み込み・出力します。出力先のテーブルが同じになるソース同士は同じスレッドで元の順に処理するため、追記の順序は逐次処理と変わりません。

parallel は次の組み合わせのときだけ表示されます。

  • Convert: 入力の srcType が csv / fixed / reg / xls / xlsx で、出力形式が xls / xlsx 以外、または excelTable が BOOK（excelTable を SHEET / BOOK に切り替えるとフォームが再構成されます）
  • Compare: new / old のどちらかの srcType が csv / fixed / reg / xls / xlsx（出力形式は問わない）

表示されていても、次の場合は実行時に逐次処理になります。

  • 入力ソースが 1 つだけ、または全ソースが同じテーブルへ出力される
  • 設定ファイルで join または件数分割（split）を使っている

xls / xlsx 入力は、実行前に各ファイルのシート名だけを読み、xlsxSchema の定義も含めて出力テーブルを求めます。同じテーブル（同名シート、またはスキーマで同じテーブル名になるシート）を含むファイル同士は同じスレッドで順に処理します。

Compare では、new / old それぞれの読み込みに適用されます（比較結果の出力自体は並列化しません）。並び替え・重複除去を指定したテーブルは全行をメモリに保持するため、並列数を増やすとメモリ使用量も増えます。

出力形式が table の場合は、スレッドごとに DB 接続を張って書き込みます（詳細は table を参照）。
