Dataset Load Form

各コマンドで入力データセットを指定する共通のフォームです。Compare の oldData / newData / expectData、Convert / Generate / Run の srcData、Parameterize の paramData がこのフォームで構成されます。

フォームは次の 5 つの領域でできています。

  • srcType — 入力の形式（下記「srcType 一覧」を参照）
  • Source — 入力元のファイル・SQL と文字コード
  • Traversal — ディレクトリを読み込むときの走査条件（Traversal）
  • Data Load — ヘッダ行・開始行など、読み込み時の挙動（Data Load）
  • Setting — テーブルごとの主キー・フィルタなどの設定ファイル

srcType 一覧

選んだ形式に応じて、固有の項目がフォームに表示されます。src に指定するもの・テーブル名の決まり方・固有オプションは、各値のページを参照してください。

値説明
none入力なし。テンプレートだけで出力する Generate など、入力が不要な場合に使う
csvCSV / TSV など区切り文字付きのテキスト
fixed固定長テキスト。カラムの幅を指定して列に分ける
reg正規表現で行を列に分けるテキスト
xls / xlsxExcel ファイル。シートごとに 1 テーブル
table接続先データベースのテーブル。読み込むテーブル名は一覧ファイルで指定する
sql接続先データベースで SQL を実行した結果
csvqCSV ファイルに対して SQL を実行した結果。複数の CSV の JOIN などに使う
fileディレクトリ配下のファイルの一覧（パス・サイズ・更新日時など）
dirディレクトリ配下のサブディレクトリの一覧

Source

項目説明
src入力元のパス。srcType によって指すものが異なる（ファイル・ディレクトリ、SQL ファイル、テーブル名の一覧ファイル）
encodingテキストの入力ファイルの文字コード
jdbcPropertiessrcType が table / sql のときの接続先（JDBC）
templateGroupSQL をテンプレートとして処理するときの共通マクロ（Template）

Setting

項目説明
settingテーブルごとの主キー・並び順・フィルタなどを書いた設定ファイル（Dataset Settings）
settingEncodingsetting の文字コード

setting の横の編集ボタンから、テーブルごとの設定を画面で編集できます（Dataset Setting）。generate ボタンからは、既存のデータセットのテーブル・カラム構成をもとに雛型を作れます（Dataset Setting Generate）。
