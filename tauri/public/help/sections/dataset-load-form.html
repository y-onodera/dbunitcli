Dataset Load Form

各コマンドで入力データセットを指定する共通のフォームです。Compare の oldData / newData / expectData、Convert / Generate / Run の srcData、Parameterize の paramData がこのフォームで構成されます。

フォームは次の 5 つの領域でできています。

  • srcType — 入力の形式（下記「srcType 一覧」を参照）
  • Source — 入力元のファイル・SQL と文字コード
  • Traversal — ディレクトリを読み込むときの走査条件（Traversal）
  • Data Load — ヘッダ行・開始行など、読み込み時の挙動（Data Load）
  • Setting — テーブルごとの主キー・フィルタなどの設定ファイル

srcType 一覧

選んだ形式に応じて、固有の項目がフォームに表示されます。src に指定するもの・テーブル名の決まり方・固有オプションは、各値のページを参照してください。

Setting

項目説明
settingテーブルごとの主キー・並び順・フィルタなどを書いた設定ファイル（Dataset Settings）
settingEncodingsetting の文字コード
settingTargetOnlyON にすると、setting の対象のテーブルだけを読み込む。デフォルトは OFF

settingTargetOnly を ON にしたときの対象は次のとおりです。対象外のテーブルは読み込まず、出力もしません。

  • settings の name / pattern に該当するテーブル（name / pattern の無い設定は全テーブルが対象）
  • join の left / right のテーブル（出力は join した結果だけ）
  • 中身のある commonSettings の対象のテーブル。name / pattern の無い commonSettings があれば全テーブルが対象

テーブル名は設定を適用した後の名前で出力します。setting を指定していなければ何も読み込みません。

setting の横の編集ボタンから、テーブルごとの設定を画面で編集できます（Dataset Setting）。generate ボタンからは、既存のデータセットのテーブル・カラム構成をもとに雛型を作れます（Dataset Setting Generate）。

Preview Before Settings（設定を適用する前）と Preview Apply Settings（setting を適用した後）では、読み込まれるテーブルの一覧を確認できます。一覧の preview ボタンを押すと、そのテーブルのデータを表示します。

  • 読み込むのは選んだテーブルだけのため、テーブルが多いデータセットでも早く表示されます。ただし、setting で join したテーブルは、元のテーブルもすべて読み込みます
  • 表示するのは先頭 100 行までです。全体の行数が多いときは、表の上に「Showing first 100 of 全行数 rows (partial preview)」と表示されます

データ表示の Export ボタンを押すと、そのテーブルだけを convert と同じ形式で出力できます。

  1. Export を押すと、出力先の指定（Result Form）を入力するダイアログが開きます。入力欄の初期値は convert のデフォルトです。
  2. Execute を押すと、プレビューと同じ読込条件（setting の適用有無を含む）で読み込み、選んだテーブルだけを出力します。
  3. 完了すると Export completed. と表示されます。ファイルへ出力した場合は Open Directory で出力先を開けます。
