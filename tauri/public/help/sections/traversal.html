Traversal

src にディレクトリを指定したときに、どのファイルを読み込むかの条件です。Dataset Load Form の traversal option から設定します。

シンプルな使い方

ディレクトリの中から、読み込むファイルを絞り込みます。何も指定しなければ、src のディレクトリの直下にあるファイルを読み込みます。

例: サブディレクトリも含めて読み込み、old ディレクトリの中のファイルだけを外します。

入力:
  data/orders/ORDERS.csv
  data/orders/ITEMS.csv
  data/orders/2026/ORDERS_2026.csv
  data/orders/old/ORDERS_2025.csv

指定:
  src        = data/orders
  recursive  = ON
  regExclude = old

結果:
  テーブル ORDERS / ITEMS / ORDERS_2026
  • recursive が OFF なら、2026 ディレクトリの中も読み込まない
  • regInclude / regExclude はファイルのパス全体と照合し、一部に一致すれば条件に当てはまる。上の例では、パスに old を含む ORDERS_2025.csv が外れる

設定項目

項目説明
extension対象にするファイルの拡張子。. を付けずに書く（例: txt）
recursiveON にすると、サブディレクトリの中も読み込む
regInclude対象にするファイルの条件（正規表現）。ファイルのパス全体と照合し、一部に一致すれば対象にする
regExclude対象から外すファイルの条件（正規表現）。ファイルのパス全体と照合し、一部に一致すれば外す
