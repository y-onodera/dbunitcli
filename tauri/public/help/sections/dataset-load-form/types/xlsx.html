srcType: xls / xlsx

Excel ファイルを読み込みます。デフォルトでは、シートごとに 1 行目をヘッダ、2 行目以降をデータとして読み込みます。

読み込み対象

項目内容
srcExcel ファイル（.xls / .xlsx）、またはファイルを置いたディレクトリ
テーブル名シート名（シートごとに 1 テーブル）

固有オプション

項目説明デフォルト
xlsxSchemaシートの列の位置や、任意のセルから値を拾う定義を書いたファイル（Xlsx Schema）。横のメニューの generate ボタンから雛型を作れる（空）

入出力例

2 シートのブックを読み込む例:

入力 (book.xlsx):
  Sheet "Users":   id,name / 1,Alice / 2,Bob
  Sheet "Orders":  id,amount / 10,500 / 11,800

テーブル "Users":
  カラム:   [id, name]
  データ行: [1, Alice] / [2, Bob]
テーブル "Orders":
  カラム:   [id, amount]
  データ行: [10, 500] / [11, 800]
