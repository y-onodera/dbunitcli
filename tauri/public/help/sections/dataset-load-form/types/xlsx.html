srcType: xls / xlsx

src の意味: Excel ファイル（.xls / .xlsx）、または複数 Excel を含むディレクトリ。

テーブル名: 各シート名（ブック内の各シートが 1 テーブル）。

固有オプション:

  • xlsxSchema — シートごとの列定義や任意セルの抽出定義を記述したスキーマファイル。書式の詳細は Xlsx Schema を参照してください。テキストボックス横のメニューの generate ボタンから、既存データセットのカラム構成をもとにスキーマの雛型を生成できます。

データイメージ例: 先頭行がヘッダ、以降がデータ（デフォルト）。

入力 (book.xlsx):
  Sheet "Users":   id,name / 1,Alice / 2,Bob
  Sheet "Orders":  id,amount / 10,500 / 11,800

テーブル "Users":
  カラム:   [id, name]
  データ行: [1, Alice] / [2, Bob]
テーブル "Orders":
  カラム:   [id, amount]
  データ行: [10, 500] / [11, 800]
