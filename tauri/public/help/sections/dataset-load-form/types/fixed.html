Source Type: fixed

src の意味: 固定長テキストファイル、または複数ファイルを含むディレクトリ。

テーブル名: 拡張子を除いたファイル名。

固有オプション:

  • fixedLength — （必須）各カラムの幅をカンマ区切りで指定（例: 4,10）。幅の単位は fixedLengthType に従います。headerName による列名指定との併用が必須です。
  • fixedLengthType — 幅の計算方法: char（文字数基準、デフォルト）/ byte（バイト数基準）。マルチバイト文字を含むファイルを byte で処理する場合は文字化けに注意してください。

データイメージ例: 指定した幅でカラム分割（fixedLengthType=char の場合）。

入力 (members.txt):
0001Alice
0002Bob

指定:
  fixedLength     = 4,10
  fixedLengthType = char   (デフォルト)
  headerName      = id,name

カラム:     [id, name]
データ行:
  [0001, Alice     ]
  [0002, Bob       ]
