srcType: fixed

各カラムの幅が決まっている固定長テキストファイルを読み込みます。

読み込み対象

項目内容
src固定長テキストファイル、またはファイルを置いたディレクトリ
テーブル名拡張子を除いたファイル名

固有オプション

項目説明デフォルト
fixedLength（必須）各カラムの幅をカンマ区切りで指定（例: 4,10）。単位は fixedLengthType に従う—
fixedLengthType幅の数え方: char（文字数）/ byte（バイト数）char

入出力例

fixedLengthType=char で読み込む例:

入力 (members.txt):
0001Alice
0002Bob

指定:
  fixedLength     = 4,10
  fixedLengthType = char   (デフォルト)
  headerName      = id,name

カラム:     [id, name]
データ行:
  [0001, Alice     ]
  [0002, Bob       ]

注意

  • 列名は Data Load の headerName で指定してください（必須）
  • マルチバイト文字を含むファイルを byte で読むと、文字の途中で区切られて文字化けすることがあります
