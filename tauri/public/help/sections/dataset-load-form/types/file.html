srcType: file

ディレクトリ配下のファイルの一覧を、パス・サイズ・更新日時などを列に持つテーブルとして読み込みます。

読み込み対象

項目内容
src一覧を作るディレクトリ
テーブル名対象ファイルの拡張子（extension で絞り込んだ場合はその拡張子）
カラムPATH / NAME / DIR / RELATIVE_PATH / SIZE_KB / LAST_MODIFIED

固有オプション

なし。対象は Traversal の extension・recursive・regInclude・regExclude で絞り込みます。

入出力例

拡張子 .txt のファイルを再帰的に読み込む例:

入力 (src = project/):
  project/a.txt         (2KB, 2026-04-01 10:00:00)
  project/sub/b.txt     (5KB, 2026-04-02 11:00:00)
  project/sub/c.log     (1KB, 2026-04-03 09:30:00)

指定:
  srcType   = file
  recursive = true
  extension = .txt

テーブル名: txt
カラム:     [PATH, NAME, DIR, RELATIVE_PATH, SIZE_KB, LAST_MODIFIED]
データ行:
  [/abs/project/a.txt,       a.txt, /abs/project,     a.txt,       2, 2026/04/01 10:00:00]
  [/abs/project/sub/b.txt,   b.txt, /abs/project/sub, sub/b.txt,   5, 2026/04/02 11:00:00]
