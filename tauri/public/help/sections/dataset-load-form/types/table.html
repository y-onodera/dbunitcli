srcType: table

接続先データベースのテーブルを読み込みます。読み込むテーブルの名前は、テーブル名を並べたテキストファイルで指定します。

読み込み対象

項目内容
srcテーブル名を 1 行に 1 つずつ書いたテキストファイル、またはそのファイルを置いたディレクトリ（src はテーブル名ではなく、テーブル名の一覧ファイル）。相対パスは Workspace の resources/table、Dataset Base、Workspace の順に探す（SQL Editor で作ると resources/table に保存される）
テーブル名一覧ファイルに書いたテーブル名
接続先JDBC の設定が必須

固有オプション

項目説明デフォルト
useJdbcMetaDataON にすると、カラムの型と主キーを接続先のスキーマ全体から調べる。型の判定が正確になる一方、スキーマが大きいと読み込みの開始が遅くなる。OFF のときは対象のテーブルだけを調べるOFF

通常は OFF で十分です。データベースの種類によってカラムの型が想定と異なる場合に ON を試してください。

入出力例

一覧ファイル 1 つから 2 つのテーブルを読み込む例:

入力 (tables.txt):
USERS
ORDERS

JDBC 接続先:
  USERS(id INT, name VARCHAR, age INT)
    (1, 'Alice', 30), (2, 'Bob', 25)
  ORDERS(id INT, amount INT)
    (10, 500), (11, 800)

指定:
  srcType = table
  src     = tables.txt

生成テーブル:
  テーブル名: USERS
    カラム:     [id, name, age]
    データ行:   [1, Alice, 30] / [2, Bob, 25]
  テーブル名: ORDERS
    カラム:     [id, amount]
    データ行:   [10, 500] / [11, 800]

注意

  • Data Load の headerName / startRow / addFileInfo は効きません
  • テーブル名の一覧ファイルには、空行やコメントを書かないでください
  • テーブル名の一覧ファイルは SQL Editor で編集できます
