srcType: csv

CSV / TSV など、区切り文字で列を分けたテキストファイルを読み込みます。

読み込み対象

項目内容
srcCSV / TSV ファイル、または CSV を置いたディレクトリ
テーブル名拡張子を除いたファイル名

固有オプション

項目説明デフォルト
delimiter区切り文字（1 文字）。制御文字はエスケープ記法 \b / \t / \n / \r / \f で指定する,
ignoreQuotedON にすると、引用符（"）を特別扱いせず普通の文字として残す。OFF のときは値を囲む " を取り除き、引用符の中の区切り文字を値の一部として扱うOFF

値に区切り文字や改行を含む可能性がある通常の CSV では、ignoreQuoted は OFF のままにしてください。

入出力例

1 行目をヘッダ、2 行目以降をデータとして読み込む例:

入力 (users.csv):
id,name,age
1,Alice,30
2,Bob,25

テーブル名: users  (拡張子を除いたファイル名)
カラム:     [id, name, age]
データ行:
  [1, Alice, 30]
  [2, Bob,   25]

delimiter で TSV を読む例:

入力 (users.tsv):
id	name	age
1	Alice	30
2	Bob	25

指定:
  srcType   = csv
  delimiter = \t     (タブ区切り)

カラム:     [id, name, age]
データ行:
  [1, Alice, 30]
  [2, Bob,   25]

ignoreQuoted の違い:

入力 (multi.csv):
key,column1,column2
1,"a,b",3
2,"あいうえお",5

ignoreQuoted = OFF (デフォルト):
  カラム:     [key, column1, column2]
  データ行:
    [1, a,b,           3]        (外側の " は除去、内側のカンマは値の一部)
    [2, あいうえお,     5]

ignoreQuoted = ON:
  カラム:     [key, column1, column2, (余分な列)]
  データ行:
    [1, "a, b", 3, ...]          (" がそのまま残り、"a,b" は 2 列に分割される)
    [2, "あいうえお", 5]
