srcType: csvq

SQL ファイルを H2 データベース上で実行し、その結果をテーブルとして読み込みます。SQL の中で CSVREAD() 関数を使って CSV ファイルを読むため、複数の CSV を JOIN するといった使い方ができます。

読み込み対象

項目内容
src実行する SQL ファイル。読み込む CSV は SQL の中の CSVREAD() で指定する（src は CSV を置いたディレクトリではない）
テーブル名SQL ファイル名（拡張子を除く）

固有オプション

なし。

入出力例

複数の CSV を JOIN した結果を 1 テーブルとして読み込む例:

入力 CSV (csvquery/csv/header.csv):
KEYCOLUMN,CD1,NAME,VALUE
1,A1,太郎,10000
2,B1,次郎,20000
3,C1,花子,30000

入力 CSV (csvquery/csv/detail.csv):
KEYCOLUMN,DETAILNO,VALUE1,VAL
1,1,100,200
1,2,200,400
2,1,0,0
3,2,1002,2001

SQL (joinQuery.sql):
  SELECT
      table1.*
  FROM
      CSVREAD('csvquery/csv/header.csv', null, 'charset=UTF-8') table1
      INNER JOIN
      CSVREAD('csvquery/csv/detail.csv', null, 'charset=UTF-8') table2
      ON table1.KEYCOLUMN = table2.KEYCOLUMN
  WHERE
      table2.DETAILNO = 2
  ORDER BY
      table1.KEYCOLUMN DESC;

指定:
  srcType = csvq
  src     = joinQuery.sql

テーブル名: joinQuery
カラム:     [KEYCOLUMN, CD1, NAME, VALUE]
データ行:
  [3, C1, 花子, 30000]
  [1, A1, 太郎, 10000]

CSVREAD(fileName, columns, csvOptions) の第 2 引数を null にすると、先頭行がヘッダとして扱われます。第 3 引数では charset・fieldSeparator・fieldDelimiter などの H2 の CSV オプションを指定できます（例: TSV を読む場合は 'charset=UTF-8 fieldSeparator=\t'）。
