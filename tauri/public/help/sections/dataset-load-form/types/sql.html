srcType: sql

SQL ファイルを接続先のデータベースで実行し、結果をテーブルとして読み込みます。

読み込み対象

項目内容
srcSELECT 文を書いた SQL ファイル、またはファイルを置いたディレクトリ
テーブル名SQL ファイル名（拡張子を除く）
接続先JDBC の設定が必須

固有オプション

項目説明デフォルト
useJdbcMetaDataON にすると、カラムの型と主キーを接続先のスキーマ全体から調べる。srcType: table と同じOFF

入出力例

SELECT の結果を読み込む例:

入力 (active_users.sql):
  SELECT id, name FROM USERS WHERE active = 1

JDBC 実行結果:
  id=1 name=Alice
  id=3 name=Carol

テーブル名: active_users
カラム:     [id, name]
データ行:
  [1, Alice]
  [3, Carol]

注意

  • Data Load の headerName / startRow / addFileInfo は効きません
  • SQL の中で -P 値を参照できます（Parameters (-P)）
