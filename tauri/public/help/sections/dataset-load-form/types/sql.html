srcType: sql

SQL ファイルを接続先のデータベースで実行し、結果をテーブルとして読み込みます。

読み込み対象

項目内容
srcSELECT 文を書いた SQL ファイル、またはファイルを置いたディレクトリ。相対パスは Workspace の resources/sql、Dataset Base、Workspace の順に探す（SQL Editor で作ると resources/sql に保存される）
テーブル名SQL ファイル名（拡張子を除く）
接続先JDBC の設定が必須

固有オプション

項目説明デフォルト
useJdbcMetaDataON にすると、カラムの型と主キーを接続先のスキーマ全体から調べる。srcType: table と同じOFF

入出力例

SELECT の結果を読み込む例:

入力 (active_users.sql):
  SELECT id, name FROM USERS WHERE active = 1

JDBC 実行結果:
  id=1 name=Alice
  id=3 name=Carol

テーブル名: active_users
カラム:     [id, name]
データ行:
  [1, Alice]
  [3, Carol]

注意

  • Data Load の headerName を指定すると、取得した列の先頭から順に列名を置き換えます。headerName が取得した列より少ない場合、超えた列は無視されます。多い場合、余った列名の列を追加し値は空文字になります
  • Data Load の addFileInfo を ON にすると、SQL ファイルのパス・ファイル名を各行に追加します（$SHEET_NAME は空文字）
  • Data Load の startRow は効きません
  • SQL の中で -P 値を参照できます（Parameters (-P)）
