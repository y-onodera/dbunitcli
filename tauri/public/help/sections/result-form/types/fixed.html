resultType: fixed

各カラムを決まった幅に揃えた固定長テキストファイルとして出力します。

出力先

項目内容
ファイルテーブルごとに 1 ファイル

共通項目（result / resultPath / exportEmptyTable / exportHeader / parallel）は Result Form を参照してください。

固有オプション

項目説明デフォルト
outputEncoding出力ファイルの文字コードUTF-8
outputExtension出力ファイルの拡張子.txt
fixedColumnDefカラムごとの幅・寄せ方向・埋める文字を定義した JSON ファイル。横の編集ボタンで編集でき、generate ボタンから雛型を作れる（Fixed Column Def Generate）—
fixedLengthType幅の数え方: char（文字数）/ byte（バイト数）char

入出力例

テーブル (members):
  id=1, name=Alice

fixedColumnDef (members.json):
{
  "columns": [
    {"name": "id",   "length": 4,  "align": "left", "pad": " "},
    {"name": "name", "length": 10, "align": "left", "pad": " "}
  ]
}

生成ファイル:
1   Alice

注意

  • 定義にないカラムは出力されません
  • 値が幅より長い場合は、幅の位置で切り捨てられます
