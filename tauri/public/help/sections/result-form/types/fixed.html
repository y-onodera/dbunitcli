resultType: fixed

各カラムを固定長バイト幅でパディングしたテキストファイルとして出力します。

共通項目: result / resultPath / exportEmptyTable / exportHeader は Result Form の共通項目を参照してください。

固有オプション

項目説明
outputEncoding出力ファイルの文字コード（デフォルト: UTF-8）
outputExtension出力ファイルの拡張子（デフォルト: .txt）
fixedColumnDef各カラムの固定長幅定義ファイルのパス。カラムごとのバイト幅をカンマ区切りで記述したファイルを指定
fixedLengthTypeバイト幅の計算方法: char（文字数基準、デフォルト）/ byte（バイト数基準）

テキストボックス横の編集ボタンから列定義を GUI で編集できます。generate ボタンからは、既存データセットのカラム構成をもとに定義の雛型（列名・デフォルト長・アラインメント）を生成できます。

出力例

テーブル:
  id=1, name=Alice

fixedColumnDef: 4,10
fixedLengthType: char

生成ファイル:
1   Alice
