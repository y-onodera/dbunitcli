resultType: table

接続先データベースのテーブルへ書き込みます。result / resultPath / exportEmptyTable / exportHeader は表示されません。

出力先

項目内容
書き込み先入力のテーブル名と同じ名前のテーブル
接続先JDBC の設定が必須

固有オプション

項目説明デフォルト
op書き込み方法（下記「op 一覧」を参照）CLEAN_INSERT
jdbc接続先データベース（JDBC）—
parallel並列に読み込み・書き込むスレッド数（Result Form の「並列読込」を参照）（空）

op 一覧

値説明
CLEAN_INSERT既存の行をすべて削除してから INSERT
INSERT既存の行を残したまま INSERT
UPDATE主キーが一致する行を UPDATE
REFRESH主キーが一致する行は UPDATE、一致しない行は INSERT
DELETE主キーが一致する行を DELETE

注意

  • 並列にすると、書き込み先のテーブルごとに書き込み（CLEAN_INSERT の削除を含む）が同時に進み、並列数まで DB 接続を同時に使います
  • 外部キー制約で親子関係のあるテーブルに書き込む場合は、parallel に 1 を指定して逐次にしてください
