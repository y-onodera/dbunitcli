resultType: format

各行を書式文字列（Java の String.format() の形式）に当てはめて、テキストファイルとして出力します。

出力先

項目内容
ファイルテーブルごとに 1 ファイル

共通項目（result / resultPath / exportEmptyTable / exportHeader / parallel）は Result Form を参照してください。

固有オプション

項目説明デフォルト
format（必須）書式文字列。カラムの値が順に %s に入る（例: %s,%s\n）—
outputEncoding出力ファイルの文字コードUTF-8
outputExtension出力ファイルの拡張子.txt

入出力例

テーブル:
  id=1, name=Alice
  id=2, name=Bob

format = %s:%s\n

生成ファイル:
1:Alice
2:Bob
