Result Type: format

java.lang.String.format() の書式文字列を使い、各行のデータをテキスト出力します。

共通項目: result / resultPath / exportEmptyTable / exportHeader は Result Form の共通項目を参照してください。

固有オプション

項目説明
outputEncoding出力ファイルの文字コード（デフォルト: UTF-8）
format（必須）String.format() 書式文字列。例: %s,%s\n
outputExtension出力ファイルの拡張子（デフォルト: .txt）

出力例

テーブル:
  id=1, name=Alice
  id=2, name=Bob

format = %s:%s\n

生成ファイル:
1:Alice
2:Bob
