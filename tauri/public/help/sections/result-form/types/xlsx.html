resultType: xls / xlsx

テーブルを Excel ファイルとして出力します。xls は Excel 97-2003 形式、xlsx は Excel 2007 以降の形式です。

出力先

項目内容
ファイルexcelTable で決まる（下記を参照）

共通項目（result / resultPath / exportEmptyTable / exportHeader / parallel）は Result Form を参照してください。

固有オプション

項目説明デフォルト
excelTableブックの作り方。SHEET: すべてのテーブルを 1 ブックにまとめ、テーブルごとに 1 シート。BOOK: テーブルごとに 1 ブック。候補から選ぶほか、Env の値などを渡せるよう自由に入力もできるSHEET

注意

  • excelTable が SHEET のときは、並列読込の parallel は表示されません。SHEET かどうかを変えるとフォームの表示が切り替わります
