Result Type: xls / xlsx

テーブルを Excel ファイルとして出力します。xls は Excel 97-2003 形式（.xls）、xlsx は Excel 2007 以降の形式（.xlsx）で出力します。固有オプションは両形式で共通で、excelTable の設定により、テーブルをどのシートに書き込むかを制御します。

共通項目: result / resultPath / exportEmptyTable / exportHeader は Result Form の共通項目を参照してください。

固有オプション

項目説明
excelTableExcel 出力時のブック構成モード（デフォルト: SHEET）。SHEET: 全テーブルを 1 ブック（ファイル）にまとめ、テーブルごとに 1 シート、BOOK: 1 テーブル = 1 ブック（ファイル）
