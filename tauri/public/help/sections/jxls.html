Jxls

Generate で generateType = xlsx または xls を選んだ場合に使用するテンプレートエンジンです。Excel ファイル（.xlsx / .xls）をテンプレートとして、入力データセットの各行を埋め込んで出力します。

テンプレートには jxls のコメント記法（セルのコメントに jx:each 等のディレクティブを記述）を使います。テキスト出力で使う StringTemplate 4 のテンプレートは Template を参照してください。

シンプルな使い方

見出しと 1 行分のセルを書いた Excel をテンプレートにし、セルコメントで繰り返す範囲を指定します。設定項目はデフォルトのままで使えます。

例: テーブル USERS（ID / NAME の 2 行）を、テーブルごとの Excel に書き出します。

テンプレート (users.xlsx):
  A1: ID                     B1: NAME
  A2: ${row.get('ID')}       B2: ${row.get('NAME')}
  A1 のコメント: jx:area(lastCell="B2")
  A2 のコメント: jx:each(items="param.rows" var="row" lastCell="B2")

指定:
  generateType = xlsx
  unit         = table
  template     = users.xlsx
  resultPath   = $param.tableName$.xlsx

結果 (USERS.xlsx):
  1 行目: ID | NAME
  2 行目: 1  | Alice
  3 行目: 2  | Bob
  • jx:area でテンプレートとして処理する範囲を、jx:each で行ごとに繰り返す範囲を指定する
  • items に書くものは unit によって変わる（下記「テンプレートの書き方」）

設定項目

フォームの jxls option から設定します。

項目説明デフォルト
templateParameterAttributeテンプレート内でデータ行にアクセスする属性名。例えば param を指定すると param.rows のように参照する。空にすると rows のように直接参照するparam
formulaProcess（xlsx のみ）数式セルを処理する。false にするとメモリ使用量は減るが、行を追加したときにセル参照が更新されないtrue
evaluateFormulasExcel 数式を評価するかtrue
forceFormulaRecalc出力ファイルを Excel で開いたときに自動再計算させるフラグを立てるfalse
fastFormulaProcess高速な数式プロセッサを使用するfalse
deleteBlankCells数式評価後に空セルを削除するfalse

テンプレートの書き方

Excel のセルコメントに jxls のコマンドを書きます。データは templateParameterAttribute で指定した名前（デフォルト: param）で参照します。param に入る値は Generate の unit によって変わり、generateType: txt と同じです。

unitjx:each の items に書くもの
tableparam.rows（そのテーブルの全行）
datasetparam.dataSet.get('テーブル名').rows（指定したテーブルの全行）

各行はカラム名をキーとする Map なので、セルには ${row.get('カラム名')} のように書きます（row は jx:each の var に指定した名前）。unit=dataset でテーブルごとのシートを持つテンプレートは、Generate Xlsx Template で雛型を作れます。

セルの式では tryToNum・formatDate などの関数も使えます（例: ${tryToNum(row.get('AMOUNT'), 0)}）。関数の一覧は Dataset Setting の「JEXL 式の書き方」を参照してください。
