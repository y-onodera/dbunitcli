Run

SQL ファイル・Ant のビルドファイル・Windows バッチファイルを実行します。実行するファイルは srcData で指定し、種類は scriptType で選びます。

オプション

項目説明デフォルト
scriptType実行するファイルの種類（下記「scriptType 一覧」を参照）sql
parallel同時に実行するファイル数（下記「並列実行」を参照）（空）＝ 逐次
srcData実行するファイル、またはファイルを置いたディレクトリ。拡張子は scriptType に応じて決まる（sql→.sql、ant→.xml、bat→.bat、cmd→.cmd）—
templateOptionSQL をテンプレートとして処理するときの設定（Template）。sql のときだけ使う—
jdbcOption接続先データベース（JDBC）。sql のときだけ使う—
baseDir実行時の作業ディレクトリ。ant / bat / cmd のときだけ使う—
antTarget実行する Ant のターゲット名。ant のときだけ使う（空）＝ デフォルトターゲット

srcData の指定方法は Dataset Load Form を参照してください。

scriptType 一覧

実行時に渡す値（-P 値）の受け取り方は種類ごとに異なります。詳細は各値のページを参照してください。

値説明
sqlSQL ファイルをテンプレートとして処理してから、接続先のデータベースで実行。-P 値はテンプレートの変数として参照する
antAnt のビルドファイルを実行。-P 値は Ant のプロパティとして渡される
bat / cmdWindows バッチファイルを実行。-P 値は環境変数として渡される

並列実行（parallel）

  • 2 以上を指定すると、srcData の各ファイルを指定した数まで同時に実行します。実行順は決まりません
  • 空欄または 1 のときは、見つかった順に 1 ファイルずつ実行します
  • 並列実行中にいずれかが失敗すると、まだ始めていないファイルは実行せず、実行中のファイルが終わるのを待ってからエラーになります

DDL を実行してから DML を実行するなど、実行順に依存するファイルは並列にしないでください。

関連

  • Parameters (-P) — 実行時に SQL やスクリプトへ値を渡す
  • JDBC — 接続先データベースの設定
  • Template — SQL のテンプレート処理の設定
