Run

SQL ファイル・Ant のビルドファイル・Windows バッチファイルを実行します。実行するファイルは src セクションで指定し、種類は scriptType で選びます。

シンプルな使い方

scriptType のデフォルトは sql です。実行する SQL ファイルと接続先を指定するだけで実行できます。

例: テーブルを作り直す SQL を、開発用の DB で実行します。

入力:
  sql/recreate_orders.sql         (DROP TABLE / CREATE TABLE / INSERT を順に書いたもの)
  resources/jdbc/dev.properties   (url= / user= / pass= の 3 行)

指定:
  src セクションの src             = sql/recreate_orders.sql
  jdbc セクションの jdbcProperties = dev.properties

結果:
  recreate_orders.sql の SQL が、書かれた順に dev.properties の接続先で実行される
  • src にディレクトリを指定すると、配下の .sql ファイルを 1 ファイルずつ実行する。parallel が空欄または 1 のときはパスの順（サブディレクトリ内のファイルはそのディレクトリ名の位置）に実行するため、順番が大事な場合は 01_create.sql・02_insert.sql のように名前で順番を付ける。1 ファイルだけ実行するときはファイルのパスを指定する
  • jdbcProperties は Workspace の resources/jdbc/ を基準に探す。ファイルを使わずに jdbcUrl / jdbcUser / jdbcPass を直接入力してもよい（JDBC を参照）

SQL の中の値を実行のたびに変えたい場合は、-P 値を使います（scriptType: sql の設定例を参照）。

変更できる設定

項目説明デフォルト
scriptType実行するファイルの種類（下記「scriptType 一覧」を参照）sql
parallel同時に実行するファイル数（下記「並列実行」を参照）（空）＝ 逐次
src実行するファイル、またはファイルを置いたディレクトリ。拡張子は scriptType に応じて決まる（sql→.sql、ant→.xml、bat→.bat、cmd→.cmd）。ディレクトリの走査条件も変えられる（Dataset Load Form）—
templateSQL をテンプレートとして処理するときの設定（Template）。sql のときだけ使う—
jdbc接続先データベース（JDBC）。sql のときだけ使う—
baseDir実行時の作業ディレクトリ。ant / bat / cmd のときだけ使う—
antTarget実行する Ant のターゲット名。ant のときだけ使う（空）＝ デフォルトターゲット

scriptType 一覧

実行時に渡す値（-P 値）の受け取り方は種類ごとに異なります。詳細は各値のページを参照してください。

値説明
sqlSQL ファイルをテンプレートとして処理してから、接続先のデータベースで実行。-P 値はテンプレートの変数として参照する
antAnt のビルドファイルを実行。-P 値は Ant のプロパティとして渡される
bat / cmdWindows バッチファイルを実行。-P 値は環境変数として渡される

並列実行（parallel）

  • 2 以上を指定すると、src セクションの各ファイルを指定した数まで同時に実行します。実行順は決まりません
  • 空欄または 1 のときは、パスの順に 1 ファイルずつ実行します（文字の順で比べるため、10.sql は 2.sql より先になります）
  • 並列実行中にいずれかが失敗すると、まだ始めていないファイルは実行せず、実行中のファイルが終わるのを待ってからエラーになります

DDL を実行してから DML を実行するなど、実行順に依存するファイルは並列にしないでください。
