Run

SQL やスクリプトを実行します。データソースに対して SQL 文・ANT スクリプト・バッチファイルを実行します。

オプション

オプション説明
scriptType実行するスクリプトの種類。sql / ant / bat / cmd から選択（デフォルト: sql）
parallel同時に実行するスクリプト数。2 以上で srcData の各ファイルを並列に実行する（実行順は不定。いずれかが失敗したら残りを中断する）。空欄または 1 なら見つかった順に 1 ファイルずつ実行（デフォルト: 空欄＝逐次）。DDL→DML のように実行順に依存するスクリプトは並列にしないこと
srcData実行対象ファイルの指定。拡張子は scriptType に応じて自動設定（sql→.sql, ant→.xml, bat→.bat, cmd→.cmd）
templateOptionテンプレートエンジンのオプション（sql のみ有効）
jdbcOptionJDBC 接続設定（sql のみ有効）
baseDirスクリプトの作業ディレクトリ（ant / bat / cmd のみ有効）
antTarget実行する ANT ターゲット名（ant のみ有効）

srcData の入力フォーム詳細は Dataset Load Form を参照してください。

scriptType 一覧

各 scriptType の詳細（固有オプション・設定例）は、種類名のリンク先の個別ページを参照してください。

値説明
sqlSQL ファイルをテンプレートエンジンで加工し、JDBC 接続先のデータベースに対して実行（デフォルト）
antApache ANT の build.xml を実行。パラメータは ANT プロパティとして渡される
bat / cmdWindows バッチファイルを実行。パラメータは環境変数として渡される
