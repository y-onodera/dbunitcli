Target Type: image

PNG 画像ファイルをピクセル単位で比較します。oldData / newData には Source Type = file のディレクトリを指定してください。拡張子は自動的に .png に固定されます。

  • ファイル名が一致するペアを 1 対 1 で突き合わせます
  • 差分の許容度や描画方法は imageOption（Image Option）で調整できます
  • setting は無視されます（比較キーは内部で NAME 固定）

比較結果の形式

targetType=image のとき、COMPARE_RESULT のカラム構成と DIFF の意味が data モードと異なります。テーブルごとの詳細ファイル（$MODIFY / $DELETE / $ADD）は出力されません。

COMPARE_RESULT のカラム

OLD_VALUE・NEW_VALUE・COLUMN_INDEX・DIFF_ROWS は含まれません。TARGET_NAME → DIFF の順にソートされます。

カラム説明
OLD_PATH旧データのソースディレクトリパス
NEW_PATH新データのソースディレクトリパス
TARGET_NAME対象ファイル名（pdf は「ファイル名 page{ページ番号}」形式）
DIFF差分の内容（下表参照）

DIFF の値（image モード）

一致した場合（MATCH）は COMPARE_RESULT に行が出力されません。差分がある場合のみ記録されます。

値意味
File Delete旧データにあるファイルが新データに存在しない
File Add新データにあるファイルが旧データに存在しない
[x1,y1,x2,y2]...ピクセル差分あり。差分矩形の座標リスト（左上・右下のピクセル座標を [x1,y1,x2,y2] 形式で連結）

ピクセル差分があるファイルは、差分を強調描画した PNG 画像が convertResult の出力先に {ファイル名}.png として保存されます。
