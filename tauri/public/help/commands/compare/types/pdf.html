targetType: pdf

PDF ファイルをページ画像として比較します。oldData / newData には srcType = file のディレクトリを指定してください。拡張子は自動的に .pdf に固定されます。

  • ファイル名が一致するペアを 1 対 1 で突き合わせます
  • setting は使いません

固有オプション

項目説明
imageOption差分とみなすしきい値・比較から除外する領域・差分の描画方法（Image Option）

比較結果の形式

COMPARE_RESULT のカラム構成と DIFF の意味は targetType: data と異なります。テーブルごとの詳細ファイル（$MODIFY / $DELETE / $ADD）は出力されません。

COMPARE_RESULT のカラム

OLD_VALUE・NEW_VALUE・COLUMN_INDEX・DIFF_ROWS は含まれません。TARGET_NAME → DIFF の順にソートされます。

カラム説明
OLD_PATH旧データのソースディレクトリパス
NEW_PATH新データのソースディレクトリパス
TARGET_NAME対象のファイル名とページ（「ファイル名 page{ページ番号}」形式）
DIFF差分の内容（下表参照）

DIFF の値

値意味
File Delete旧データにあるファイルが新データに存在しない
File Add新データにあるファイルが旧データに存在しない
Page Number Change[new:{新},old:{旧}]ページ数が異なる（例: Page Number Change[new:5,old:4]）。ページ数が異なる場合はページ内容の比較を行いません
[x1,y1,x2,y2]...ページ画像のピクセル差分あり。差分矩形の座標リスト。TARGET_NAME は {ファイル名} page{ページ番号} 形式（例: report.pdf page01）

ページ差分がある場合、差分画像が convertResult の出力先に {ファイル名}{ページ番号}.png（ゼロパディングあり）として保存されます。
