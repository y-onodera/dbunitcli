Compare

旧データ（oldData）と新データ（newData）を突き合わせ、差分を convertResult に出力します。比較の対象は表形式のデータセット・PNG 画像・PDF から targetType で選びます。

シンプルな使い方

旧データと新データの src、比較結果の出力先を指定するだけで比較できます。targetType のデフォルトは data（表形式のデータセット）、入力の srcType と出力の resultType のデフォルトは csv です。

例: 修正前と修正後の CSV を比較します。

入力:
  data/old/ORDERS.csv
  data/new/ORDERS.csv   (2 行目の PRICE だけが違う)

指定:
  oldData の src          = data/old
  newData の src          = data/new
  convertResult の result = out/compare

結果:
  out/compare/COMPARE_RESULT.csv   (全テーブルの差分サマリ。DIFF=MODIFY_VALUE の行が出る)
  out/compare/ORDERS$MODIFY.csv    (値が違う行の旧値・新値)
  • 同じ名前のテーブル（CSV ではファイル名）同士を比較する
  • setting を指定しないと、主キーを使わずに行の順番どおりに突き合わせる
  • 差分がなければ COMPARE_RESULT.csv だけが出力され、中身は空になる

比較結果のファイルの見方は targetType: data を参照してください。行の並びが違うデータは、次の setting で主キーを指定すると正しく突き合わせられます。

変更できる設定

項目説明デフォルト
targetType比較対象の種類（下記「targetType 一覧」を参照）data
setting比較の設定ファイル（Dataset Settings 形式）。主キー・比較から除くカラム・並び順などをテーブルごとに指定する。data のときだけ使う（空）
settingEncodingsetting の文字コードシステムデフォルト
oldData比較元（旧）のデータセット。入力の形式（Excel・DB テーブルなど）や文字コードを変えられる—
newData比較先（新）のデータセット—
expectData期待値のデータセット。省略すると期待値との検証をしない（下記「expectData による検証」を参照）（空）
createPatchSql旧データを新データへ補正するパッチ SQL を出力する。data のときだけ使うOFF
imageOption画像比較のしきい値・除外領域など（Image Option）。image / pdf のときだけ表示—
convertResult比較結果の出力形式と出力先。Excel や DB テーブルへの出力に変えられる（Result Form）—

oldData / newData / expectData の指定方法は Dataset Load Form を参照してください。

targetType 一覧

setting の効き方と比較結果の形式は targetType ごとに異なります。詳細は各値のページを参照してください。

値説明
dataCSV・Excel・DB テーブルなど表形式のデータセットを比較。setting で主キーや比較対象のカラムを指定でき、行単位の差分ファイルとパッチ SQL を出力できる
imagePNG 画像ファイルをピクセル単位で比較し、差分を描画した画像を出力
pdfPDF ファイルをページごとの画像として比較し、差分を描画した画像を出力

expectData による検証

expectData に期待値のデータセットを指定すると、convertResult に出力した比較結果を期待値と突き合わせて検証します。期待値と一致しない差分は、convertResult の出力先の expectedDiff/ ディレクトリに同じ形式で出力されます。
