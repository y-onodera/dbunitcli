Compare

旧データ（oldData）と新データ（newData）を突き合わせ、差分を convertResult に出力します。比較の対象は表形式のデータセット・PNG 画像・PDF から targetType で選びます。

シンプルな使い方

旧データと新データの src、比較結果の出力先を指定するだけで比較できます。targetType のデフォルトは data（表形式のデータセット）、入力の srcType と出力の resultType のデフォルトは csv です。

例: 修正前と修正後の CSV を比較します。

入力:
  data/old/ORDERS.csv
  data/new/ORDERS.csv   (2 行目の PRICE だけが違う)

指定:
  oldData の src          = data/old
  newData の src          = data/new
  convertResult の result = out/compare

結果:
  out/compare/COMPARE_RESULT.csv   (全テーブルの差分サマリ。DIFF=MODIFY_VALUE の行が出る)
  out/compare/ORDERS$MODIFY.csv    (値が違う行の旧値・新値)
  • 同じ名前のテーブル（CSV ではファイル名）同士を比較する
  • setting を指定しないと、主キーを使わずに行の順番どおりに突き合わせる
  • 差分がなければ COMPARE_RESULT.csv だけが出力され、中身は空になる

比較結果のファイルの見方は、下記「比較結果の形式」を参照してください。行の並びが違うデータは、次の setting で主キーを指定すると正しく突き合わせられます。

比較結果の形式

targetType=data の比較結果は convertResult で指定した出力先ディレクトリに、以下の 2 種類のファイルとして書き出されます。

  1. COMPARE_RESULT — 全テーブルの差分サマリ（常に出力）
  2. テーブルごとの詳細ファイル — 行レベルの差分詳細（差分がある場合のみ出力）

COMPARE_RESULT（差分サマリ）

すべてのテーブル・ファイルの差分を 1 テーブルにまとめた集計結果です。TARGET_NAME → DIFF → COLUMN_INDEX の順にソートされます。

カラム説明
OLD_PATH旧データのソースパス（ディレクトリまたは DB 接続先）
NEW_PATH新データのソースパス
TARGET_NAME差分が検出されたテーブル名（image / pdf ではファイル名）
DIFF差分の種類（下表参照）
OLD_VALUE旧データ側の値・件数・カラム名
NEW_VALUE新データ側の値・件数・カラム名
COLUMN_INDEX差分が発生したカラムの位置（0 始まり。カラム差分以外は 0）
DIFF_ROWS差分行数（MODIFY_VALUE は差分値が検出された行数、KEY_DELETE/KEY_ADD/ROWS_COUNT は行数差）

DIFF の値一覧

値意味OLD_VALUENEW_VALUE
TABLE_COUNTテーブル数が異なる旧テーブル数新テーブル数
TABLE_DELETE旧データにあるテーブルが新データに存在しないテーブル名（空）
TABLE_ADD新データに追加されたテーブルが旧データに存在しない（空）テーブル名
COLUMNS_COUNTカラム数が異なる旧カラム数新カラム数
COLUMNS_MODIFY同位置のカラム名が異なる旧カラム名新カラム名
COLUMNS_DELETE旧データにあるカラムが新データに存在しない旧カラム名（空）
COLUMNS_ADD新データに追加されたカラムが旧データに存在しない（空）新カラム名
ROWS_COUNT行数が異なる旧行数新行数
KEY_DELETE旧データにある主キー行が新データに存在しない削除行数0
KEY_ADD新データに追加された主キー行が旧データに存在しない0追加行数
MODIFY_VALUE同一キーの行でカラム値が異なる旧カラム名新カラム名

テーブルごとの詳細ファイル

行レベルの差分がある場合、convertResult の出力先に以下 3 種類のテーブルが追加で書き出されます。テーブル名はすべて元テーブル名に接尾辞を付けた形式です。

{テーブル名}$MODIFY — 値が変化した行

主キーが一致するが値が異なる行について、旧値（OLD）と新値（NEW）を 2 行ペアで記録します。$ROW_AFTER_SORT → $MODIFY の順でソートされます。

カラム説明
$MODIFYOLD（旧データ行）または NEW（新データ行）
$ROW_AFTER_SORTソート後の行番号（0 始まり）。OLD と NEW で同じ値になるため、ペアの識別に使用
$ROW_ORIGINALソート前の元の行番号（0 始まり）
$DIFF_COLUMN_INDEXES値が異なるカラムの名前とインデックスの一覧（例: price[2],qty[3]）
（元テーブルの全カラム）元テーブルのすべてのカラム値

{テーブル名}$DELETE — 削除された行（旧データにあり、新データにない）

$ROW_INDEX の昇順でソートされます。

カラム説明
$ROW_INDEX旧データでの行番号（0 始まり）
（元テーブルの全カラム）旧データ側の行の全カラム値

{テーブル名}$ADD — 追加された行（新データにあり、旧データにない）

$ROW_INDEX の昇順でソートされます。

カラム説明
$ROW_INDEX新データでの行番号（0 始まり）
（元テーブルの全カラム）新データ側の行の全カラム値

createPatchSql によるパッチ SQL の出力

createPatchSql を ON にすると、行レベルの差分が検出されたテーブルごとに、旧データを新データへ補正するパッチ SQL 文が {テーブル名}$PATCH.sql（UTF-8）として convertResult の出力先に書き出されます。主キー（setting の keys）が設定されていないテーブルは対象外です。

  • MODIFY_VALUE（値が変化した行）→ UPDATE 文（主キー以外の全カラムを新データの値に更新）
  • KEY_DELETE（旧データにのみ存在する行）→ DELETE 文
  • KEY_ADD（新データにのみ存在する行）→ INSERT 文

比較の結果が既に一致している行、およびテーブル・カラムの差分（TABLE_ADD 等）は SQL 生成の対象外です。

oldData / newData / expectData の指定方法は Dataset Load Form を参照してください。

targetType 一覧

setting を適用するかどうか（data だけで適用し、image / pdf では使わない）と比較結果の形式は、targetType ごとに異なります。data の比較結果は上記「比較結果の形式」、image / pdf の比較結果は各値のページを参照してください。

値説明
dataCSV・Excel・DB テーブルなど表形式のデータセットを比較。setting で主キーや比較対象のカラムを指定でき、行単位の差分ファイルとパッチ SQL を出力できる
imagePNG 画像ファイルをピクセル単位で比較し、差分を描画した画像を出力
pdfPDF ファイルをページごとの画像として比較し、差分を描画した画像を出力

expectData による検証

expectData に期待値のデータセットを指定すると、convertResult に出力した比較結果を期待値と突き合わせて検証します。期待値と一致しない差分は、convertResult の出力先の expectedDiff/ ディレクトリに同じ形式で出力されます。
