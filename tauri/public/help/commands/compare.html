Compare

データセットを比較して差分を検出します。旧データと新データを突き合わせ、差分があれば出力します。

オプション

オプション説明
targetType比較対象の種類（下記参照）
setting比較設定ファイル（data モード時のみ有効。Dataset Settings 形式）
settingEncoding設定ファイルのエンコーディング（デフォルト: システム既定）
oldData比較元（旧）データセット
newData比較対象となる新データセット
expectData期待値データセット（省略時はスキップ）
createPatchSql行レベルの差分（MODIFY_VALUE / KEY_DELETE / KEY_ADD）を旧データから新データへ補正するパッチ SQL を生成する（data モードのみ有効。デフォルト: 無効）
imageOption画像比較のオプション（image / pdf モード時のみ表示）
convertResult出力形式と出力先の設定

oldData / newData / expectData の入力フォーム詳細は Dataset Load Form を参照してください。

targetType ごとの比較方法

targetType には data・image・pdf の 3 種類があります。各形式の比較方法の詳細は、形式名のリンク先の個別ページを参照してください。

値説明
dataCSV・Excel・DB テーブルなど表形式のデータセットを比較（デフォルト）
imagePNG 画像ファイルをピクセル単位で比較
pdfPDF ファイルをページ画像として比較

setting・比較結果の形式

setting による比較内容の変更と比較結果（convertResult の出力）の形式は targetType ごとに異なります。各 targetType のページを参照してください。

  • data — setting による比較内容の変更、COMPARE_RESULT・DIFF の値・テーブルごとの詳細ファイル・パッチ SQL
  • image — COMPARE_RESULT のカラム・DIFF の値
  • pdf — COMPARE_RESULT のカラム・DIFF の値

expectData を指定した場合（共通）

expectData に期待値データセットを指定すると、convertResult の出力結果と期待値を再度突き合わせて検証します。期待値と一致しない差分は convertResult 配下の expectedDiff/ ディレクトリに同形式で出力されます。
