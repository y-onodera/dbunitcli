Generate

テンプレートまたは組み込み定義からファイルを生成します。入力データ（srcData）は Dataset Load Form で指定します。generateType は大きく 2 系統に分かれます。

  • テンプレート指定タイプ（txt / xlsx / xls）: template オプションで指定した任意のテンプレートファイルにデータを埋め込みます。出力内容はテンプレート次第で自由に設計できます。
  • 固定成果物タイプ（settings / sql / ddl / xlsxTemplate / xlsxSchema / javaBean / fixedColumnDef）: テーブルのカラム情報等から、決まった形式の成果物ファイルを自動生成します。template は使用しません。組み込みテンプレート以外の出力形式にしたい場合は、generateType=txt と unitSetting を組み合わせて同等の内容を再現してください。

unit

生成の単位を指定します。デフォルトは record です。
settings / xlsxTemplate は dataset、sql / ddl / xlsxSchema / javaBean / fixedColumnDef は table に固定されます。

値説明
record行ごとに 1 ファイルを出力
tableテーブルごとに 1 ファイルを出力
datasetデータセット全体から 1 ファイルを出力

unitSetting

unit=table でテンプレート指定タイプ（txt など。xlsx / xls を除く）を使うときに表示されます。テンプレートに渡す前に、1 つのテーブルから条件別のサブテーブルを作ったり、列の値を整形したりするための設定ファイルです。固定成果物タイプでは組み込み設定が使われ、指定できません。

並列処理（parallel）

parallel は、src の srcType が file / dir 以外のときだけ表示されます。指定したスレッド数は次の両方に使われます。

  • src の読み込み: Convert の 並列読込 と同じ条件・方法で、ソースごとに別スレッドで読み込みます
  • unit=table の出力: テーブルごとに別スレッドで出力します（txt / xlsx / xls と、unit=table 固定の固定成果物タイプ）。ddl / javaBean / xlsxSchema / fixedColumnDef は、カラム情報の取得（src が table / sql なら DB のメタデータ照会）をテーブルごとの出力の中で行うため、その部分も並列になります。txt と、lazyLoad を ON にした xlsx / xls では、テーブルごとの読み込みから出力までを並列に行います。lazyLoad が OFF の xlsx / xls は、全件を読み込んでから出力だけを並列にします

テーブルごとの出力ファイルは並列に書かれるため、書き込まれる順番は不定です（各ファイルの内容は逐次処理と同じです）。表示されていても、次の場合は unit=table の出力を逐次処理します。

  • 出力するテーブルが 1 つだけ
  • 複数のテーブルが同じファイルへ出力される（resultPath にテーブル名などが含まれていない）。この場合は逐次処理と同じく最後のテーブルの内容が残ります
  • src の設定ファイルで join または件数分割（split）を使っている（lazyLoad が OFF の xlsx / xls を除く）

1 つのソースから複数のテーブルを作る場合（サブテーブルへの分割など）、それらのテーブルは同じスレッドで元の順に処理します。src の srcType が table / sql の場合は、スレッドごとに DB 接続を張って読み込みます（接続数は最大で並列数）。テーブルごとの出力を並列にすると、同時に読み込む・保持するテーブルの数だけメモリ使用量も増えます。
