Parameterize

パラメータでバッチ処理します。パラメータデータセットの各行を入力として、対象コマンドを繰り返し実行します。

オプション

オプション説明
unitテンプレートへのパラメータ受け渡し単位（行・テーブル・データセット）
parameterizecmdParam をパラメータで展開するテンプレートとして扱うかどうか
ignoreFailcompare で想定外の差分が出た場合も他のコマンドを続行する
parallel同時に実行するコマンド数。2 以上でパラメータ（unit の単位）ごとのコマンドを並列に実行する（実行順は不定）。空欄または 1 なら 1 件ずつ順に実行（デフォルト: 空欄＝逐次）。詳細は下記「並列実行」を参照
cmd（必須）データ駆動で実行する対象コマンド（Compare / Convert / Generate など）
cmdParamコマンド用パラメータファイル。ファイル名はパラメータデータセットから動的に決定
templateデフォルトのテンプレートファイル。cmdParam とは同時に指定できない（両方指定すると実行時にエラー）
paramDataパラメータデータセットのソース
templateOptionテンプレートエンジンのオプション

paramData の入力フォーム詳細は Dataset Load Form を参照してください。

並列実行（parallel）

  • テーブル作成→データ投入のように実行順に依存するコマンドは並列にしないこと。
  • ignoreFail が false のときは、1 件失敗すると未着手のコマンドは始めず、実行中のコマンドが終わるのを待ってから失敗します（実行中のコマンドは途中で止めません）。true のときは全件を実行し、最後に失敗件数があれば失敗します。
  • 並列実行中のコマンドの中では、compare / convert / generate の並列数（generate は -parallel、compare / convert は -result.parallel）が空欄なら逐次になります（CPU コア数で並列化せず、parameterize の並列数と掛け合わせた数のスレッドが動かないようにする）。値を書いた場合はその並列数で動きます。
  • 複数のパラメータが同じ出力先へ書くテンプレートでは、最後に残る内容は不定です。

unit の動作

unit はテンプレートへのパラメータ受け渡し単位を指定します。

値説明
rowparamData の行ごとに 1 回コマンドを実行。列の値のほか、tableName（行の属するテーブル名）と rowNumber（テーブルごとに 0 始まりの行番号）を参照できます（Generate の unit=record と同じ）
tableparamData のテーブルごとに 1 回コマンドを実行
datasetparamData 全体を 1 つとして 1 回コマンドを実行

具体例

Compare をパラメータ駆動で繰り返す

比較対象のディレクトリパスをパラメータ CSV で管理し、複数の比較を一括実行する例です。

paramData に読み込む CSV（例: params/compare_params.csv）:

OLD_DIR,NEW_DIR,SETTING
data/old/orders,data/new/orders,settings/orders.json
data/old/products,data/new/products,settings/products.json

template に指定する Compare パラメータファイルのテンプレート（例: templates/compare_param.txt）:

-oldData.src=$param.OLD_DIR$
-oldData.srcType=file
-newData.src=$param.NEW_DIR$
-newData.srcType=file
-setting=$param.SETTING$
-convertResult.resultType=csv
-convertResult.result=result/compare
設定項目値の例
unitrow
parameterizefalse
ignoreFailtrue（差分があっても次の行を処理する）
cmdcompare
templatetemplates/compare_param.txt
paramData.srcparams/compare_params.csv

paramData の各行（OLD_DIR・NEW_DIR・SETTING）が $param.列名$ としてテンプレートに展開され、行数分だけ Compare が実行されます。

cmdParam でパラメータファイルを動的に切り替える

パラメータ CSV の列値でコマンドパラメータファイルのパスを動的に決定する例です。parameterize を ON にすると cmdParam の文字列もテンプレートとして展開されます。

paramData に読み込む CSV（例: params/targets.csv）:

TARGET
orders
products
customers
設定項目値の例
unitrow
parameterizetrue
cmdconvert
cmdParamparams/$param.TARGET$.txt
paramData.srcparams/targets.csv

1 行目では cmdParam が params/orders.txt に展開され Convert が実行されます。2 行目では params/products.txt、3 行目では params/customers.txt が使われます。各 .txt ファイルはコマンドライン引数を記述したパラメータファイルです。

Generate をパラメータ駆動で繰り返す

データソースとテーブル名の一覧から SQL ファイルを一括生成する例です。

paramData に読み込む CSV（例: params/tables.csv）:

SRC,SRC_TYPE,RESULT
data/orders,csv,result/orders
data/products,csv,result/products

template に指定する Generate パラメータファイルのテンプレート（例: templates/generate_param.txt）:

-generateType=sql
-srcData.src=$param.SRC$
-srcData.srcType=$param.SRC_TYPE$
-result=$param.RESULT$
設定項目値の例
unitrow
parameterizefalse
cmdgenerate
templatetemplates/generate_param.txt
paramData.srcparams/tables.csv

各行の SRC・SRC_TYPE・RESULT がテンプレートに渡され、テーブルごとに Generate が実行されます。
