Parameterize

パラメータデータ（param セクション）の行ごとに、対象のコマンド（cmd）を繰り返し実行します。コマンドに渡すオプションはテンプレートに書き、パラメータデータの値を埋め込みます。

シンプルな使い方

実行するコマンド、オプションを書いたテンプレート、パラメータデータの src を指定します。unit のデフォルトは record（パラメータデータの 1 行ごとに 1 回実行）、param セクションの srcType のデフォルトは csv です。

例: 月ごとのディレクトリにある CSV を、月ごとに Excel へ変換します。

パラメータデータ (params/months.csv):
  MONTH
  202609
  202610

テンプレート (convert_monthly.txt):
  -src=data/$param.MONTH$
  -resultType=xlsx
  -result=out/$param.MONTH$

指定:
  cmd                    = convert
  template               = convert_monthly.txt
  param セクションの src = params/months.csv

結果:
  1 行目: src セクションの src = data/202609、result セクションの result = out/202609 で Convert を実行
  2 行目: src セクションの src = data/202610、result セクションの result = out/202610 で Convert を実行

テンプレートの $param.列名$ が行ごとの値に置き換わり、行数分だけコマンドが実行されます。

テンプレートとパラメータデータは手で書かなくても作れます。元にするコマンドを Save し、サイドバーの ⋮ から Parameterize を選んでパラメータにするオプションを選ぶと、その今の値を 1 行だけ入れたパラメータデータと、残りのオプションを保存値のまま書いたテンプレートが作られます（基本的な使い方 の「6. Parameterize で繰り返し実行する」を参照）。

unit 一覧

値説明
recordパラメータデータの行ごとに 1 回実行。列の値のほか、tableName（行の属するテーブル名）と rowNumber（テーブルごとに 0 始まりの行番号）を参照できる（Generate の unit=record と同じ）

並列実行（parallel）

  • 2 以上を指定すると、unit の単位ごとのコマンドを指定した数まで同時に実行します。実行順は決まりません
  • 空欄または 1 のときは、1 件ずつ順に実行します
  • ignoreFail が OFF のときは、1 件失敗すると未着手のコマンドは始めず、実行中のコマンドが終わるのを待ってからエラーになります。ON のときは全件を実行し、最後に失敗件数があればエラーになります
  • 並列実行中のコマンドでは、Compare / Convert / Generate の並列数（Generate は parallel、Compare / Convert は result セクションの parallel）が空欄なら逐次になります。値を書いた場合はその並列数で動きます

テーブルの作成とデータの投入のように実行順に依存するコマンドは、並列にしないでください。複数の行が同じ出力先へ書く場合、最後に残る内容は決まりません。

応用例

差分があっても Compare を続ける（ignoreFail）

比較するディレクトリの組をパラメータデータで管理し、まとめて比較します。ignoreFail を ON にすると、途中の行で差分が出ても残りの行を比較します。

パラメータデータ (params/compare_params.csv):
NAME,OLD_DIR,NEW_DIR,SETTING
orders,data/old/orders,data/new/orders,settings/orders.json
products,data/old/products,data/new/products,settings/products.json

テンプレート (compare_param.txt):
-old.src=$param.OLD_DIR$
-new.src=$param.NEW_DIR$
-setting=$param.SETTING$
-result=result/compare/$param.NAME$

指定:
  ignoreFail             = ON
  cmd                    = compare
  template               = compare_param.txt
  param セクションの src = params/compare_params.csv

結果:
  result/compare/orders/COMPARE_RESULT.csv     (1 行目の比較結果)
  result/compare/products/COMPARE_RESULT.csv   (2 行目の比較結果)

出力先に行ごとの値（ここでは NAME）を入れて、行ごとに出力を分けます。全行で同じ出力先にすると、後の行の比較結果で前の行の結果が上書きされます。

cmdParam でオプションファイルを切り替える

パラメータデータの値で、使うオプションファイルを行ごとに切り替えます。テンプレートを書かずに、既存のオプションファイルをそのまま使えます。

パラメータデータ (params/targets.csv):
TARGET
orders
products
customers

指定:
  cmd                    = convert
  cmdParam               = params/$param.TARGET$.txt
  param セクションの src = params/targets.csv

1 行目では params/orders.txt、2 行目では params/products.txt、3 行目では params/customers.txt に書かれたオプションで Convert が実行されます。

複数のソースを 1 つにまとめる（append）

形式や置き場所が違うソースを、Convert で 1 つの Excel ブックに追記していきます。1 行目だけ append を OFF にして前回の出力を作り直すので、何度実行しても前回の分と重なりません。ソースが同じ形式で 1 つのディレクトリの下にあるなら、Parameterize を使わずに 1 回の Convert でまとめられます（Convert の「応用例」を参照）。

入力:
  data/tokyo/orders.xlsx  (シート ORDERS: 1001,pen / 1002,note)
  data/osaka/ORDERS.csv   (2001,ink)
  data/osaka/ITEMS.csv    (9)

パラメータデータ (params/sources.csv):
  SRC,TYPE,APPEND
  data/tokyo/orders.xlsx,xlsx,false
  data/osaka,csv,true

テンプレート (merge_orders.txt):
  -src=$param.SRC$
  -srcType=$param.TYPE$
  -result=merged
  -resultType=xlsx
  -resultPath=orders_all
  -append=$param.APPEND$

指定:
  parallel               = 1
  cmd                    = convert
  template               = merge_orders.txt
  param セクションの src = params/sources.csv

結果:
  merged/orders_all.xlsx  (シート ORDERS: 1001,pen / 1002,note / 2001,ink、シート ITEMS: 9)
  • parallel は 1（または空欄）にして、行の順に実行する。並列にすると、append が OFF の行が後から実行されて、先に追記した分を消すことがある
  • 追記はヘッダ行を確かめずに行うため、同じテーブル名のソースは列の並びをそろえる
  • resultType を csv にするとテーブルごとの CSV に追記されるが、1 行目で作り直されるのは 1 行目のソースにあるテーブルのファイルだけになる。regTableInclude（Data Load）で 1 回に読むテーブルを 1 つに絞り、テーブルごとに最初の行だけ append を OFF にする
  • regTableInclude は一部一致なので ^ORDERS$ のように前後を固定し、$ がテンプレートの区切り文字と重ならないよう正規表現はパラメータデータの列に書く。setting と settingTargetOnly で絞ってもよい（Dataset Load Form）

複数のコマンドを続けて実行する

cmd と cmdParam をパラメータデータの列で切り替えると、行ごとに別のコマンドを順に実行できます。上の例の Parameterize でブックにまとめ、続けて Generate でそのブックから INSERT 文を作ります。どちらも Save した保存済みオプションを使います。

パラメータデータ (params/steps.csv):
  CMD,OPTION
  parameterize,option/parameterize/merge_orders.txt
  generate,option/generate/orders_insert.txt

指定:
  parallel               = 1
  cmd                    = $param.CMD$
  cmdParam               = $param.OPTION$
  param セクションの src = params/steps.csv

結果:
  1 行目: 保存済みオプション merge_orders の Parameterize で merged/orders_all.xlsx を作る
  2 行目: 保存済みオプション orders_insert の Generate で merged/orders_all.xlsx から ORDERS.sql / ITEMS.sql を作る
  • 前の行の出力を次の行で使うため、parallel は 1（または空欄）にして行の順に実行する
  • ignoreFail が OFF なら、途中の行が失敗した時点で残りの行は実行しない
