Parameterize

パラメータデータ（paramData）の行ごとに、対象のコマンド（cmd）を繰り返し実行します。コマンドに渡すオプションはテンプレートに書き、パラメータデータの値を埋め込みます。

シンプルな使い方

実行するコマンド、オプションを書いたテンプレート、パラメータデータの src を指定します。unit のデフォルトは record（パラメータデータの 1 行ごとに 1 回実行）、paramData の srcType のデフォルトは csv です。

例: 月ごとのディレクトリにある CSV を、月ごとに Excel へ変換します。

パラメータデータ (params/months.csv):
  MONTH
  202609
  202610

テンプレート (convert_monthly.txt):
  -srcData.src=data/$param.MONTH$
  -convertResult.resultType=xlsx
  -convertResult.result=out/$param.MONTH$

指定:
  cmd              = convert
  template         = convert_monthly.txt
  paramData の src = params/months.csv

結果:
  1 行目: srcData の src = data/202609、result = out/202609 で Convert を実行
  2 行目: srcData の src = data/202610、result = out/202610 で Convert を実行

テンプレートの $param.列名$ が行ごとの値に置き換わり、行数分だけコマンドが実行されます。

テンプレートとパラメータデータは手で書かなくても作れます。元にするコマンドを Save し、サイドバーの ⚙ から Parameterize を選ぶと、今の値を 1 行だけ入れたパラメータデータとテンプレートが作られます（基本的な使い方 の「6. Parameterize で繰り返し実行する」を参照）。

変更できる設定

項目説明デフォルト
unitコマンドを 1 回実行する単位（下記「unit 一覧」を参照）record
parameterizeON のとき、template / cmdParam のファイルの中身をテンプレートとして展開する。OFF のときは書かれたまま使うON
ignoreFailON のとき、コマンドが失敗しても（Compare で想定外の差分が出た場合を含む）残りを続けて実行し、最後に失敗件数があればエラーにするOFF
parallel同時に実行するコマンド数（下記「並列実行」を参照）（空）＝ 逐次
cmd（必須）実行するコマンド（Compare / Convert / Generate / Run）。$param.列名$ で行ごとに切り替えることもできる—
cmdParamコマンドのオプションを書いたファイルのパス。パスに $param.列名$ を書くと行ごとに別のファイルを使える（下記「応用例」を参照）。template と同時には指定できない（空）
templateコマンドのオプションを書いたテンプレートファイル（Edit Parameterize Template で編集）。option/parameterize/template のファイルを候補から選べ、横のメニューから削除もできる。cmdParam と同時には指定できない（空）
paramDataパラメータデータ。Excel や DB テーブルなど、CSV 以外の形式にも変えられる（Dataset Load Form）—
templateOptionテンプレート処理の設定。変数の区切り文字などを変えられる（Template）—

unit 一覧

値説明
recordパラメータデータの行ごとに 1 回実行。列の値のほか、tableName（行の属するテーブル名）と rowNumber（テーブルごとに 0 始まりの行番号）を参照できる（Generate の unit=record と同じ）
tableパラメータデータのテーブルごとに 1 回実行
datasetパラメータデータ全体で 1 回実行

並列実行（parallel）

  • 2 以上を指定すると、unit の単位ごとのコマンドを指定した数まで同時に実行します。実行順は決まりません
  • 空欄または 1 のときは、1 件ずつ順に実行します
  • ignoreFail が OFF のときは、1 件失敗すると未着手のコマンドは始めず、実行中のコマンドが終わるのを待ってからエラーになります。ON のときは全件を実行し、最後に失敗件数があればエラーになります
  • 並列実行中のコマンドでは、Compare / Convert / Generate の並列数（Generate は parallel、Compare / Convert は convertResult の parallel）が空欄なら逐次になります。値を書いた場合はその並列数で動きます

テーブルの作成とデータの投入のように実行順に依存するコマンドは、並列にしないでください。複数の行が同じ出力先へ書く場合、最後に残る内容は決まりません。

応用例

差分があっても Compare を続ける（ignoreFail）

比較するディレクトリの組をパラメータデータで管理し、まとめて比較します。ignoreFail を ON にすると、途中の行で差分が出ても残りの行を比較します。

パラメータデータ (params/compare_params.csv):
NAME,OLD_DIR,NEW_DIR,SETTING
orders,data/old/orders,data/new/orders,settings/orders.json
products,data/old/products,data/new/products,settings/products.json

テンプレート (compare_param.txt):
-oldData.src=$param.OLD_DIR$
-newData.src=$param.NEW_DIR$
-setting=$param.SETTING$
-convertResult.result=result/compare/$param.NAME$

指定:
  ignoreFail       = ON
  cmd              = compare
  template         = compare_param.txt
  paramData の src = params/compare_params.csv

結果:
  result/compare/orders/COMPARE_RESULT.csv     (1 行目の比較結果)
  result/compare/products/COMPARE_RESULT.csv   (2 行目の比較結果)

出力先に行ごとの値（ここでは NAME）を入れて、行ごとに出力を分けます。全行で同じ出力先にすると、後の行の比較結果で前の行の結果が上書きされます。

cmdParam でオプションファイルを切り替える

パラメータデータの値で、使うオプションファイルを行ごとに切り替えます。テンプレートを書かずに、既存のオプションファイルをそのまま使えます。

パラメータデータ (params/targets.csv):
TARGET
orders
products
customers

指定:
  cmd              = convert
  cmdParam         = params/$param.TARGET$.txt
  paramData の src = params/targets.csv

1 行目では params/orders.txt、2 行目では params/products.txt、3 行目では params/customers.txt に書かれたオプションで Convert が実行されます。
