scriptType: sql

SQL ファイルをテンプレートとして処理してから、接続先のデータベースで実行します。srcData にディレクトリを指定した場合は、配下の .sql ファイルを 1 ファイルずつ実行します。

固有オプション

項目説明
templateOptionSQL をテンプレートとして処理するときの設定（Template）
jdbcOption接続先データベース（JDBC）

設定例

実行のたびに対象日を変えて、注文データを削除する例です。

SQL ファイル (sql/delete_orders.sql):
  DELETE FROM ORDERS WHERE ORDER_DATE = '$param.orderDate$';

指定:
  scriptType        = sql
  srcData の src    = sql/delete_orders.sql
  jdbcOption        = 接続先の .properties ファイル
  -P 値             = orderDate=2026-10-01

実行される SQL:
  DELETE FROM ORDERS WHERE ORDER_DATE = '2026-10-01';

-P 値は $param.キー$ で参照します（Template の templateParameterAttribute がデフォルトの param の場合）。参照の書き方は Parameters (-P) を参照してください。

関連

  • Parameters (-P) — 実行時に SQL へ値を渡す
  • StringTemplate 4 書式リファレンス — 条件分岐などテンプレートの書き方
