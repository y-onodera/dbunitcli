scriptType: ant

Apache Ant のビルドファイル（.xml）を実行します。srcData にディレクトリを指定した場合は、配下の .xml ファイルを 1 ファイルずつ実行します。

固有オプション

項目説明デフォルト
baseDirAnt の basedir（実行時の作業ディレクトリ）—
antTarget実行するターゲット名（空）＝ ビルドファイルのデフォルトターゲット

設定例

ビルドファイル (scripts/build.xml):
  <project default="deploy">
    <target name="deploy">
      <echo message="deploy to ${stage}"/>
    </target>
  </project>

指定:
  scriptType      = ant
  srcData の src  = scripts/build.xml
  baseDir         = work/
  antTarget       = deploy
  -P 値           = stage=staging

出力:
  [echo] deploy to staging

-P 値は Ant のプロパティとして渡され、ビルドファイルの中から ${キー} で参照できます。
