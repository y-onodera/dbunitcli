scriptType: bat / cmd

Windows バッチファイルを実行します。bat と cmd の違いは対象の拡張子（.bat / .cmd）だけです。srcData にディレクトリを指定した場合は、配下のファイルを 1 ファイルずつ実行します。

固有オプション

項目説明
baseDirバッチファイルを実行するときの作業ディレクトリ

設定例

バッチファイル (scripts/backup.bat):
  @echo off
  copy data\%TARGET%.csv backup\

指定:
  scriptType      = bat
  srcData の src  = scripts/backup.bat
  baseDir         = work/
  -P 値           = TARGET=orders

実行される処理:
  work\data\orders.csv を work\backup\ にコピー

-P 値は環境変数として渡され、バッチファイルの中から %キー% で参照できます。バッチファイルの標準出力はアプリのログに出力されます。
