generateType: ddl

入力データのカラム情報から、テーブルごとに CREATE TABLE の DDL ファイルを生成します。unit は table 固定で、template は使いません。ファイル名は {sqlFilePrefix}{テーブル名}{sqlFileSuffix}.sql です。

固有オプション

項目説明デフォルト
sqlFilePrefixファイル名の先頭に付ける文字列（空）
sqlFileSuffixファイル名の末尾（拡張子の前）に付ける文字列（空）

出力例

カラムサイズ・コメントなどをすべて与えた場合の出力です（ファイル名: EMPLOYEE.sql）。

CREATE TABLE EMPLOYEE (
    EMPLOYEE_ID INTEGER(10) NOT NULL,
    EMPLOYEE_NAME VARCHAR(100),
    SALARY DECIMAL(10,2)
    ,CONSTRAINT PK_EMPLOYEE PRIMARY KEY (EMPLOYEE_ID)
);
COMMENT ON TABLE EMPLOYEE IS '社員マスタ';

COMMENT ON COLUMN EMPLOYEE.EMPLOYEE_ID IS '社員ID';
COMMENT ON COLUMN EMPLOYEE.EMPLOYEE_NAME IS '氏名';
COMMENT ON COLUMN EMPLOYEE.SALARY IS '給与';

注意

  • カラムの型・主キー・NULL 制約は入力データから取得します。値が入るのは、srcType が table / sql で useJdbcMetaData を ON にした場合です。CSV など型情報のない入力では、カラム名だけになります
  • カラムサイズ・コメントなど入力データにない情報を含めたい場合は、Scaffold で書き出した記述子データセットを編集し、generateType=txt で生成してください
