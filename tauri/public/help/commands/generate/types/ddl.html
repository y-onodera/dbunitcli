generateType: ddl

データソースのメタデータ（テーブルのカラム情報）から CREATE TABLE 用の DDL ファイルを自動生成します。unit は table に固定です。template は使用しません（組み込み DDL テンプレートのみ使用されます）。ファイル名は {sqlFilePrefix}{テーブル名}{sqlFileSuffix}.sql になります。カラムの型・PK・NULL制約はソースのメタデータから取得します（JDBC ソースで useJdbcMetaData を有効にした場合に実値が入ります。CSV 等メタデータの無いソースではカラム名のみになります）。カラムサイズ・コメント・パッケージ名などメタデータに存在しない情報を含む完全な DDL を生成したい場合は、Scaffold（scaffold コマンド）で書き出した記述子データセットを編集し、generateType=txt と unitSetting（既定は sql/ddlSettings.json）で生成してください。

項目説明デフォルト
sqlFilePrefix生成 DDL ファイル名のプレフィックス（空）
sqlFileSuffix生成 DDL ファイル名のサフィックス（空）

生成イメージ（カラムサイズ・コメント等をすべて与えた場合。ファイル名: EMPLOYEE.sql）:

CREATE TABLE EMPLOYEE (
    EMPLOYEE_ID INTEGER(10) NOT NULL,
    EMPLOYEE_NAME VARCHAR(100),
    SALARY DECIMAL(10,2)
    ,CONSTRAINT PK_EMPLOYEE PRIMARY KEY (EMPLOYEE_ID)
);
COMMENT ON TABLE EMPLOYEE IS '社員マスタ';

COMMENT ON COLUMN EMPLOYEE.EMPLOYEE_ID IS '社員ID';
COMMENT ON COLUMN EMPLOYEE.EMPLOYEE_NAME IS '氏名';
COMMENT ON COLUMN EMPLOYEE.SALARY IS '給与';
