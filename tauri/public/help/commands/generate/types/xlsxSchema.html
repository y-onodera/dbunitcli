generateType: xlsxSchema

入力データのカラム情報から、Xlsx Schema ファイルの雛型（JSON）をテーブルごとに生成します。unit は table 固定で、template は使いません。ファイル名は {テーブル名}.json です。

出力例

{
  "rows": [
    {
      "sheetName": "Test1"
     ,"tableName": "Test1"
     ,"header": ["Key","Column1","Column2","Column3"]
     ,"dataStart": 1
     ,"columnIndex": [0,1,2,3]
     ,"breakKey": ["Key"]
    }
  ]
 ,"cells": [
    {
      "sheetName": "Test1"
     ,"tableName": "Test1"
     ,"header": ["Key","Column1","Column2","Column3"]
     ,"rows": [{"cellAddress": ["A2","B2","C2","D2"]}]
    }
  ]
}

注意

  • sheetName にはテーブル名が入ります。実際のシート名やセル位置に合わせて編集してください
  • シート名やセル位置を生成時に変えたい場合は、Scaffold で書き出した記述子データセットを編集し、generateType=txt と unitSetting（デフォルトは xlsxschema/xlsxSchemaSettings.json）で生成してください
