generateType: xlsxSchema

データセットのカラム情報から Xlsx Schema 設定ファイルのひな型を JSON 形式で生成します。unit は table に固定で、テーブルごとに {テーブル名}.json を出力します。template は使用しません（組み込みテンプレートのみ使用されます）。組み込みの unitSetting（既定は xlsxschema/xlsxSchemaSettings.json）が PK / CELLS サブテーブルへの分割を担います。シート名やセル位置などを調整したい場合は、Txt Template Generate（scaffold コマンド）で書き出した記述子データセットを編集し、generateType=txt と unitSetting（既定と同じファイル）で生成してください。

生成イメージ:

{
  "rows": [
    {
      "sheetName": "Test1"
     ,"tableName": "Test1"
     ,"header": ["Key","Column1","Column2","Column3"]
     ,"dataStart": 1
     ,"columnIndex": [0,1,2,3]
     ,"breakKey": ["Key"]
    }
  ]
 ,"cells": [
    {
      "sheetName": "Test1"
     ,"tableName": "Test1"
     ,"header": ["Key","Column1","Column2","Column3"]
     ,"rows": [{"cellAddress": ["A2","B2","C2","D2"]}]
    }
  ]
}
