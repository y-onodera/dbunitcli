generateType: javaBean

データソースのメタデータ（テーブルのカラム情報）から JavaBean の .java ソースファイルを自動生成します。unit は table に固定です。template は使用しません（組み込み JavaBean テンプレートのみ使用されます）。ファイル名はテーブル名をアッパーキャメルケースに変換したものになります（例: EMPLOYEE → Employee.java）。カラムの型（javaType 変換元）や PK・NULL制約はソースのメタデータから取得します（JDBC ソースで useJdbcMetaData を有効にした場合に実値が入ります。CSV 等メタデータの無いソースではカラム名のみになります）。コメントやパッケージ名などメタデータに存在しない情報を含む完全なソースを生成したい場合は、Scaffold（scaffold コマンド）で書き出した記述子データセットを編集し、generateType=txt と unitSetting（既定は javabean/javaBeanSettings.json）で生成してください。

生成イメージ（コメント等をすべて与えた場合。ファイル名: Employee.java）:

/** 社員マスタ */
public class Employee {
    /** 社員ID */
    private Integer employeeId;
    /** 氏名 */
    private String employeeName;
    /** 給与 */
    private java.math.BigDecimal salary;

    public Integer getEmployeeId() {
        return this.employeeId;
    }

    public void setEmployeeId(Integer employeeId) {
        this.employeeId = employeeId;
    }
    public String getEmployeeName() {
        return this.employeeName;
    }

    public void setEmployeeName(String employeeName) {
        this.employeeName = employeeName;
    }
    public java.math.BigDecimal getSalary() {
        return this.salary;
    }

    public void setSalary(java.math.BigDecimal salary) {
        this.salary = salary;
    }
}
