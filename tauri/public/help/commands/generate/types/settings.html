generateType: settings

入力データのテーブル・カラム情報から、Dataset Settings ファイルの雛型（JSON）を生成します。unit は dataset 固定で、template は使いません。

固有オプション

項目説明デフォルト
includeAllColumnsON にすると、すべてのカラムを include / string などの項目として含める。OFF のときは主キーの keys だけOFF

出力例

includeAllColumns が OFF の場合の出力です。

{
  "settings": [
    {
      "name" : "Test1"
     ,"keys":["Key"]
    }
  , {
      "name" : "Test2"
     ,"keys":["PrimaryKey"]
    }
  ]
}
