generateType: sql

入力データの行から、テーブルごとに INSERT / UPDATE / DELETE などの SQL ファイルを生成します。unit は table 固定で、template は使いません。ファイル名は {sqlFilePrefix}{テーブル名}{sqlFileSuffix}.sql です。

固有オプション

項目説明デフォルト
op（必須）生成する SQL の種類: INSERT / UPDATE / DELETE / REFRESH / CLEAN_INSERT—
commitSQL の末尾に commit; を付けるON
sqlFilePrefixファイル名の先頭に付ける文字列（空）
sqlFileSuffixファイル名の末尾（拡張子の前）に付ける文字列（空）

出力例

op=INSERT の場合（ファイル名: Test1.sql）:

insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('1' ,'ああ' ,10000 ,'false' );
insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('15' ,'テスト' ,null ,'true' );
commit;

op=CLEAN_INSERT の場合:

delete from Test1;

insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('1' ,'ああ' ,10000 ,'false' );
commit;
