generateType: sql

テーブルのカラム情報から SQL ファイルを自動生成します。unit は table に固定です。template は使用しません。ファイル名は {sqlFilePrefix}{テーブル名}{sqlFileSuffix}.sql になります。

項目説明デフォルト
commit生成した SQL の末尾に commit; を付与するかどうかfalse
op生成する SQL の種別: INSERT / UPDATE / DELETE / REFRESH / CLEAN_INSERT（未指定）
sqlFilePrefix生成 SQL ファイル名のプレフィックス（空）
sqlFileSuffix生成 SQL ファイル名のサフィックス（空）

生成イメージ（op=INSERT, ファイル名: Test1.sql）:

insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('1' ,'ああ' ,10000 ,'false' );
insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('15' ,'テスト' ,null ,'true' );
commit;

生成イメージ（op=CLEAN_INSERT）:

delete from Test1;

insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('1' ,'ああ' ,10000 ,'false' );
commit;
