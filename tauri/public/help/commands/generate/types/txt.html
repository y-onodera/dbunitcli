generateType: txt（テキストファイル生成）

StringTemplate 4 テンプレートファイルを使い、テキストファイルを生成します。template オプションでテンプレートファイルを指定します。テンプレートエンジンの詳細設定は template option の展開ボタンから設定します（Template 参照）。SQL・CSV・任意フォーマットのテキストなど、テンプレート次第で自由な成果物を作成できます。

Scaffold ボタン

generateType=txt を選択すると Scaffold ボタンが表示されます。固定成果物タイプ（ddl / javaBean / xlsxSchema / fixedColumnDef）の組み込みテンプレートをカスタマイズ生成の出発点として書き出し、その結果をこのフォームへ反映するためのダイアログを開きます。

項目説明デフォルト
target雛型の生成対象（ddl / javaBean / xlsxSchema / fixedColumnDef）ddl
template書き出すテンプレートのファイル名（必須。resources/template/{名前}.stg と {名前}.txt をワークスペースへ出力）—
unitSetting書き出すサンプル unitSetting のファイル名（省略可。resources/setting/{名前}.json をワークスペースへ出力）—
datasetType記述子データセットの出力形式（csv / xls / xlsx / table / fixed）csv
datasetEncoding記述子データセットの出力文字コード（csv / fixed のみ）UTF-8
fixedLength / defaultLength / aligntarget が fixedColumnDef の場合のみ表示。記述子データセットに書き出す桁数・デフォルト桁数・寄せ方向— / 10 / left
dataset記述子データセットの元になるデータソース。ダイアログを開いた時点の src セクションの内容が初期値として引き継がれます。指定するとテーブルごとの記述子データセット（1 カラム = 1 行）をワークスペースの src へ出力します—

Execute を押すと雛型ファイルがワークスペースへ生成され、生成された雛型で駆動する設定（generateType=txt・unit=table・template・template.templateGroup・unitSetting・resultPath・src）がこのフォームへ反映されます。書き出された記述子データセットを編集してからそのまま Exec で生成できます。反映内容の保存は通常どおり Save ボタンで行ってください。
