generateType: fixedColumnDef

固定長出力（resultType: fixed）で使うカラム幅定義ファイル（JSON）を、テーブルごとに生成します。unit は table 固定です。ファイル名は {テーブル名}.json です。

固有オプション

項目説明デフォルト
fixedLength各カラムの幅をカンマ区切りで指定（例: 4,10,20）。カラム数より少ない場合、残りのカラムは defaultLength になる（空）
defaultLengthfixedLength で幅を指定しなかったカラムの幅10
align寄せ方向: left（右側を埋める）/ right（左側を埋める）left

出力例

fixedLength=5,10、align=left の場合（ファイル名: Test1.json）:

{
  "columns": [
    {"name": "key", "length": 5, "align": "left", "pad": " "},
    {"name": "value", "length": 10, "align": "left", "pad": " "}
  ]
}
