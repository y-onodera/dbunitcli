generateType: xlsx / xls

jxls の Excel テンプレート（template）にデータを埋め込み、Excel ファイルを生成します。xlsx は Excel 2007 以降の形式、xls は Excel 97-2003 形式で出力します。jxls の設定は jxls option から行います（Jxls）。

固有オプション

項目説明デフォルト
template（必須）Excel テンプレートファイルのパス—
lazyLoadデータを少しずつ読み込みながら出力する。OFF にすると全件を読み込んでから出力するON

template の横のメニューの generate ボタンから、データセットのカラム情報をもとにテンプレートの雛型を作れます（Xlsx Template Generate）。
