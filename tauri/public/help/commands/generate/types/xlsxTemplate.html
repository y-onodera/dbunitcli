generateType: xlsxTemplate

jxls の Excel テンプレートの雛型（.xlsx）を生成します。unit は dataset 固定で、template は使いません。テーブルごとに 1 シートを作り、1 行目にカラム名、2 行目に jxls の埋め込み式を置き、繰り返し範囲をセルコメントで設定します。生成したファイルは、そのまま generateType: xlsx / xls の template に使えます。

出力例

テーブル Test1（カラム Key, Column1, Column2, Column3）の場合:

シート "Test1"
  A1: Key                 B1: Column1             C1: Column2             D1: Column3
      （A1セルコメント: jx:area(lastCell="D2")）
  A2: ${row.get('Key')}   B2: ${row.get('Column1')}  C2: ${row.get('Column2')}  D2: ${row.get('Column3')}
      （A2セルコメント: jx:each(items="param.dataSet.get('Test1').rows" var="row" varIndex="index" lastCell="D2")）
