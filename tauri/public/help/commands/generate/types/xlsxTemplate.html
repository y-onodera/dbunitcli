generateType: xlsxTemplate

jxls の Excel テンプレートの雛型（.xlsx）を生成します。unit は dataset 固定で、template は使いません。templateType で、テーブルごとのシートを作るか、2 テーブルを比べるシートを作るかを選びます。生成したファイルは、そのまま generateType: xlsx / xls の template に使えます。

固有オプション

項目説明デフォルト
templateType（必須）作るテンプレートの形（下表）table
値説明
tablesrc のテーブルごとに 1 シートを作り、1 行目にカラム名、2 行目に jxls の埋め込み式を置き、繰り返し範囲をセルコメントで設定する
comparesrc のテーブルから 2 つを選び、それぞれのシートと、キーで行を突き合わせて値を比べるシートを作る。比べるテーブルと列は compare セクションで指定する（compare）

出力例

templateType = table、テーブル Test1（カラム Key, Column1, Column2, Column3）の場合:

シート "Test1"
  A1: Key                 B1: Column1             C1: Column2             D1: Column3
      （A1セルコメント: jx:area(lastCell="D2")）
  A2: ${row.get('Key')}   B2: ${row.get('Column1')}  C2: ${row.get('Column2')}  D2: ${row.get('Column3')}
      （A2セルコメント: jx:each(items="param.dataSet.get('Test1').rows" var="row" varIndex="index" lastCell="D2")）

templateType = compare の出力例は compare を参照してください。
