Convert

データセットを読み込み、指定した出力形式（CSV・Excel・DB テーブルなど）で書き出します。

シンプルな使い方

入力元の src と、出力形式・出力先を指定するだけで変換できます。入力の srcType と出力の resultType はどちらもデフォルトが csv なので、CSV を読み込む場合は srcType を選ぶ必要はありません。

例: CSV ファイルを置いたディレクトリを、1 つの Excel ブックにまとめます（保存済みオプションの名前は orders_export）。

入力:
  data/orders/ORDERS.csv
  data/orders/ITEMS.csv

指定:
  srcData の src              = data/orders
  convertResult の resultType = xlsx
  convertResult の result     = out

結果:
  out/orders_export.xlsx  (シート ORDERS / ITEMS)
  • CSV ファイル 1 つが 1 テーブルになり、ファイル名（拡張子なし）がテーブル名になる
  • src と result の相対パスは、それぞれ Dataset Base・Result Base からの相対（Workspace を参照）
  • ブックのファイル名は、resultPath を空にすると保存済みオプションの名前になる

resultType を変えずに csv のまま実行すると、out/ORDERS.csv / out/ITEMS.csv のようにテーブルごとのファイルに書き出されます（文字コードや区切り文字の変換に使えます）。

変更できる設定

項目説明
srcData変換元のデータセット。入力の形式（Excel・DB テーブル・SQL の結果など）、文字コード、ディレクトリの走査条件、テーブルごとの主キー・フィルタなどを変えられる（Dataset Load Form）
convertResult出力形式と出力先。DB テーブルへの書き込み、ブックの作り方（excelTable）、ファイル名（resultPath）、ヘッダ行の有無、並列読込などを変えられる（Result Form）

関連

  • Dataset Load Form — 変換元のデータセットの指定
  • Result Form — 出力形式と出力先、並列読込
