Generate

テンプレートまたは組み込み定義からファイルを生成します。generateType は大きく 2 系統に分かれます。

  • テンプレート指定タイプ（txt / xlsx / xls）: template オプションで指定した任意のテンプレートファイルにデータを埋め込みます。出力内容はテンプレート次第で自由に設計できます。
  • 固定成果物タイプ（settings / sql / ddl / xlsxTemplate / xlsxSchema / javaBean / fixedColumnDef）: テーブルのカラム情報等から、決まった形式の成果物ファイルを自動生成します。template は使用しません。組み込みテンプレート以外の出力形式にしたい場合は、generateType=txt と unitSetting を組み合わせて同等の内容を再現してください。

unit

生成の単位を指定します。デフォルトは record です。
settings / xlsxSchema / xlsxTemplate は dataset、sql / ddl / javaBean / fixedColumnDef は table に固定されます。

値説明
record行ごとに 1 ファイルを出力
tableテーブルごとに 1 ファイルを出力
datasetデータセット全体から 1 ファイルを出力

unitSetting

unit が table かつ Excel 系（xlsx / xls）以外のタイプで表示されます。テーブル単位のテンプレート生成時に、テーブルの区切り方を定義する設定ファイルを指定します（未指定時は種類ごとの組み込み設定を使用）。

項目説明デフォルト
unitSettingテーブル区切り設定ファイルのパス（空、組み込み設定を使用）
unitSettingEncodingunitSetting ファイルの文字コードシステムデフォルト

テンプレート指定タイプ

template オプションで指定した任意のテンプレートファイルに、ソースデータを埋め込んで出力します。出力されるファイルの内容はテンプレートの記述次第です。

txt（テキストファイル生成）

StringTemplate 4 テンプレートファイルを使い、テキストファイルを生成します。template オプションでテンプレートファイルを指定します。テンプレートエンジンの詳細設定は template option の展開ボタンから設定します（Template 参照）。SQL・CSV・任意フォーマットのテキストなど、テンプレート次第で自由な成果物を作成できます。

テンプレート変数

unit の選択によってテンプレート内で使用できる変数が異なります。

変数名説明recordtabledataset
rowNumber行 / テーブルのインデックス（0 始まり、dataset は常に 0）○○○
tableNameテーブル名○○—
columnsカラムの配列（各要素に columnName・dataType）○○—
primaryKeys主キーカラムの配列（各要素に columnName・dataType）○○—
columnsExcludeKey主キー以外のカラムの配列（各要素に columnName・dataType）○○—

xlsx / xls（Excelファイル生成）

jxls テンプレートファイルを使い、Excel ファイルを生成します。template オプションでテンプレートファイルを指定します。jxls 固有の設定は jxls option の展開ボタンから設定します（Jxls 参照）。xlsx は Excel 2007 以降形式、xls は Excel 97-2003 形式で出力します。

項目説明デフォルト
lazyLoadExcel データを遅延ロードする（大規模データセット向け）false

固定成果物タイプ

テーブルのカラム情報等から、決まった形式の成果物ファイルを組み込みロジック・組み込みテンプレートで自動生成します。template は使用しません。生成されるファイル形式ごとに以下へ分けています。

テキスト / JSON 成果物

settings

データセットのカラム情報から Dataset Settings ファイルのひな型を JSON 形式で生成します。unit は dataset に固定です。template は使用しません。

項目説明デフォルト
includeAllColumns設定生成時にすべてのカラムを include / string 等の詳細ブロックとして含める（false の場合は主キーの keys のみ）false

生成イメージ（includeAllColumns=false）:

{
  "settings": [
    {
      "name" : "Test1"
     ,"keys":["Key"]
    }
  , {
      "name" : "Test2"
     ,"keys":["PrimaryKey"]
    }
  ]
}

sql

テーブルのカラム情報から SQL ファイルを自動生成します。unit は table に固定です。template は使用しません。ファイル名は {sqlFilePrefix}{テーブル名}{sqlFileSuffix}.sql になります。

項目説明デフォルト
commit生成した SQL の末尾に commit; を付与するかどうかfalse
op生成する SQL の種別: INSERT / UPDATE / DELETE / REFRESH / CLEAN_INSERT（未指定）
sqlFilePrefix生成 SQL ファイル名のプレフィックス（空）
sqlFileSuffix生成 SQL ファイル名のサフィックス（空）

生成イメージ（op=INSERT, ファイル名: Test1.sql）:

insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('1' ,'ああ' ,10000 ,'false' );
insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('15' ,'テスト' ,null ,'true' );
commit;

生成イメージ（op=CLEAN_INSERT）:

delete from Test1;

insert into Test1 (Key ,Column1 ,Column2 ,Column3 ) values ('1' ,'ああ' ,10000 ,'false' );
commit;

ddl

データソースのメタデータ（テーブルのカラム情報）から CREATE TABLE 用の DDL ファイルを自動生成します。unit は table に固定です。template は使用しません（組み込み DDL テンプレートのみ使用されます）。ファイル名は {sqlFilePrefix}{テーブル名}{sqlFileSuffix}.sql になります。カラムの型・PK・NULL制約はソースのメタデータから取得します（JDBC ソースで useJdbcMetaData を有効にした場合に実値が入ります。CSV 等メタデータの無いソースではカラム名のみになります）。カラムサイズ・コメント・パッケージ名などメタデータに存在しない情報を含む完全な DDL を生成したい場合は、scaffold コマンドで書き出した記述子データセットを編集し、generateType=txt と unitSetting（既定は sql/ddlSettings.json）で生成してください。

項目説明デフォルト
sqlFilePrefix生成 DDL ファイル名のプレフィックス（空）
sqlFileSuffix生成 DDL ファイル名のサフィックス（空）

生成イメージ（カラムサイズ・コメント等をすべて与えた場合。ファイル名: EMPLOYEE.sql）:

CREATE TABLE EMPLOYEE (
    EMPLOYEE_ID INTEGER(10) NOT NULL,
    EMPLOYEE_NAME VARCHAR(100),
    SALARY DECIMAL(10,2)
    ,CONSTRAINT PK_EMPLOYEE PRIMARY KEY (EMPLOYEE_ID)
);
COMMENT ON TABLE EMPLOYEE IS '社員マスタ';

COMMENT ON COLUMN EMPLOYEE.EMPLOYEE_ID IS '社員ID';
COMMENT ON COLUMN EMPLOYEE.EMPLOYEE_NAME IS '氏名';
COMMENT ON COLUMN EMPLOYEE.SALARY IS '給与';

xlsxSchema

データセットのカラム情報から Xlsx Schema 設定ファイルのひな型を JSON 形式で生成します。unit は dataset に固定です。template は使用しません。

生成イメージ:

{
  "rows": [
    {
      "sheetName": "Test1"
     ,"tableName": "Test1"
     ,"header": ["Key","Column1","Column2","Column3"]
     ,"dataStart": 1
     ,"columnIndex": [0,1,2,3]
     ,"breakKey": ["Key"]
    }
  ]
 ,"cells": [
    {
      "sheetName": "Test1"
     ,"tableName": "Test1"
     ,"header": ["Key","Column1","Column2","Column3"]
     ,"rows": [{"cellAddress": ["A2","B2","C2","D2"]}]
    }
  ]
}

javaBean

データソースのメタデータ（テーブルのカラム情報）から JavaBean の .java ソースファイルを自動生成します。unit は table に固定です。template は使用しません（組み込み JavaBean テンプレートのみ使用されます）。ファイル名はテーブル名をアッパーキャメルケースに変換したものになります（例: EMPLOYEE → Employee.java）。カラムの型（javaType 変換元）や PK・NULL制約はソースのメタデータから取得します（JDBC ソースで useJdbcMetaData を有効にした場合に実値が入ります。CSV 等メタデータの無いソースではカラム名のみになります）。コメントやパッケージ名などメタデータに存在しない情報を含む完全なソースを生成したい場合は、scaffold コマンドで書き出した記述子データセットを編集し、generateType=txt と unitSetting（既定は javabean/javaBeanSettings.json）で生成してください。

生成イメージ（コメント等をすべて与えた場合。ファイル名: Employee.java）:

/** 社員マスタ */
public class Employee {
    /** 社員ID */
    private Integer employeeId;
    /** 氏名 */
    private String employeeName;
    /** 給与 */
    private java.math.BigDecimal salary;

    public Integer getEmployeeId() {
        return this.employeeId;
    }

    public void setEmployeeId(Integer employeeId) {
        this.employeeId = employeeId;
    }
    public String getEmployeeName() {
        return this.employeeName;
    }

    public void setEmployeeName(String employeeName) {
        this.employeeName = employeeName;
    }
    public java.math.BigDecimal getSalary() {
        return this.salary;
    }

    public void setSalary(java.math.BigDecimal salary) {
        this.salary = salary;
    }
}

fixedColumnDef

固定長出力（Result Form の fixed 形式）で使用するカラム幅定義ファイルを JSON 形式で生成します。unit は table に固定です。ファイル名は {テーブル名}.json になります。

項目説明
fixedLength各カラムの幅をカンマ区切りで指定（例: 4,10,20）。カラム数より少ない場合、残りのカラムには defaultLength が使われる
defaultLengthfixedLength で幅が指定されなかったカラムに適用するデフォルト幅（数値）
alignパディングの方向: left（右余白）/ right（左余白）

生成イメージ（fixedLength=5,10, align=left, ファイル名: Test1.json）:

{
  "columns": [
    {"name": "key", "length": 5, "align": "left", "pad": " "},
    {"name": "value", "length": 10, "align": "left", "pad": " "}
  ]
}

Excel 成果物

xlsxTemplate

jxls テンプレートのひな型となる .xlsx ファイルを生成します。unit は dataset に固定です。template は使用しません。テーブルごとに 1 シートを作成し、1 行目にヘッダー（カラム名）、2 行目に jxls の埋め込み式を配置したうえで、jxls の繰り返し範囲をセルコメントとして付与します。生成された .xlsx はそのまま xlsx / xls タイプの template として利用できます。

生成イメージ（テーブル Test1、カラム Key, Column1, Column2, Column3）:

シート "Test1"
  A1: Key                 B1: Column1             C1: Column2             D1: Column3
      （A1セルコメント: jx:area(lastCell="D2")）
  A2: ${row.get('Key')}   B2: ${row.get('Column1')}  C2: ${row.get('Column2')}  D2: ${row.get('Column3')}
      （A2セルコメント: jx:each(items="param.dataSet.get('Test1').rows" var="row" varIndex="index" lastCell="D2")）
