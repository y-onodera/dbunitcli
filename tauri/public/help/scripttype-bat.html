Script Type: bat / cmd

Windows バッチファイル（.bat / .cmd）を実行します。srcData で指定したファイル一覧が対象となり、各ファイルを baseDir を作業ディレクトリとして順に実行します。パラメータは環境変数として渡されます。bat と cmd は動作が同様で、srcData の拡張子のみ異なります（bat→.bat, cmd→.cmd）。

固有オプション

オプション説明
srcData実行対象ファイル（拡張子は scriptType に応じて .bat / .cmd に自動設定）
baseDirスクリプトの作業ディレクトリ

srcData の入力フォーム詳細は Dataset Load Form を参照してください。

設定例

設定項目値の例
scriptTypebat
srcData.srcscripts/（.bat ファイルを格納したディレクトリ）
baseDirwork/（バッチ実行時の作業ディレクトリ）

srcData で渡したデータセットの各行は環境変数としてバッチファイル内から %COLUMN_NAME% の形式で参照できます。
