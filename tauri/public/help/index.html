DBUnit CLI ヘルプ

初めて使う場合は「基本的な使い方」から読んでください。各画面のヘルプボタンからは、その画面のページが直接開きます。

基本的な使い方

  • 基本的な使い方
    Workspace を選んでから、実行・保存・繰り返し実行・別環境での再利用までの流れ

コマンド

  • Convert
    データ形式を変換する
  • Compare
    データセットを比較して差分を検出する
    targetType: dataimagepdf
  • Generate
    テンプレートからファイルを生成する
    generateType: txtxlsx / xlssettingssqlddlxlsxSchemajavaBeanfixedColumnDefxlsxTemplate ／ unitSetting
  • Run
    SQL やスクリプトを実行する
    scriptType: sqlantbat / cmd
  • Parameterize
    パラメータデータの行ごとにコマンドを繰り返し実行する

画面・設定の詳細

Workspace と実行時の値

  • Workspace
    ChangeWorkspace の入力項目、ディレクトリ構成、サイドバー・フッターの操作、環境変数（Env）
  • Parameters (-P)
    SQL やテンプレートに実行時の値を渡す

データの入力

  • Dataset Load Form
    各コマンド共通の入力データセットの指定
    srcType: nonecsvfixedregxls / xlsxtablesqlcsvqfiledir
  • Traversal
    ディレクトリを読み込むときの走査条件
  • Data Load
    ヘッダ行・開始行・ファイル情報カラムなど、読み込み時の挙動
  • JDBC
    データベースへの接続設定
  • SQL Editor
    SQL ファイル・テーブル名リストの編集
  • Xlsx Schema
    Excel のシート・セルからテーブルを読み込む定義
    Xlsx Row SettingXlsx Cell SettingXlsx Schema Generate

テーブルごとの設定（Dataset Settings）

  • Dataset Settings
    主キー・カラム選択・フィルタなどを定義する設定ファイルの書式
  • Dataset Setting
    テーブルごとの設定の編集と JEXL 式の書き方
  • Dataset Setting Generate
    既存データセットから Dataset Settings の雛型を生成

データの出力

  • Result Form
    各コマンド共通の出力先と出力形式の指定
    resultType: csvxls / xlsxtableformatfixed
  • Fixed Column Def Generate
    固定長出力のカラム幅定義の雛型を生成

テンプレート

  • Template
    StringTemplate 4 によるテンプレート処理の設定
  • StringTemplate 4 書式リファレンス
    テンプレートの構文と書式指定子
  • Template File Edit
    Generate 用テンプレートの編集
  • Scaffold
    組み込みテンプレートを書き出してカスタマイズの出発点にする
  • Edit Parameterize Template
    Parameterize 用テンプレートの編集
  • Jxls
    Excel テンプレート（xlsx / xls 出力）の設定
  • Xlsx Template Generate
    既存データセットから jxls テンプレートの雛型を生成

比較

  • Image Option
    画像・PDF 比較のしきい値・除外領域・描画の設定
