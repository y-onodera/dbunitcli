DBUnit CLI ヘルプ

初めて使う場合は「基本的な使い方」から読んでください。アプリのサイドバー下部の Help → Getting Started からも開けます。各画面のヘルプボタンからは、その画面のページが直接開きます。

基本的な使い方

  • 基本的な使い方
    Workspace を選んでから、実行・保存・繰り返し実行・別環境での再利用までの流れ

コマンド

  • Convert
    データ形式を変換する
  • Compare
    データセットを比較して差分を検出する
    targetType: dataimagepdf
  • Generate
    テンプレートからファイルを生成する
    generateType: txtxlsx / xlssettingssqlddlxlsxSchemajavaBeanfixedColumnDefxlsxTemplate ／ unitSetting
  • Run
    SQL やスクリプトを実行する
    scriptType: sqlantbat / cmd
  • Parameterize
    パラメータデータの行ごとにコマンドを繰り返し実行する

画面・設定の詳細

画面の要素ごとのページです。全コマンド共通の画面 → 複数のコマンドで使う入力フォームのセクション → 特定のコマンドにだけあるセクション、の順に並べています。各ページには、次の印を付けています。

  • セクションコマンドのフォームの中で、枠で囲まれた項目のまとまり
  • ダイアログボタンから開く専用の編集画面。セクションの項目から開くものは、そのセクションの下に字下げして並べています
  • リファレンス書式・構文や、画面共通の操作の説明

全コマンド共通の画面

  • Workspaceダイアログ
    ヘッダの ChangeWorkspace ボタンから開く。入力項目、ディレクトリ構成、サイドバー・フッターの操作、環境変数（Env）
  • Parameters (-P)ダイアログ
    フッターの Edit Parameters (-P) ボタンから開く。SQL やテンプレートに実行時の値を渡す
  • 画面共通の操作リファレンス
    フォーム・ダイアログに共通の部品のリファレンス。入力欄（×・候補・⋮ メニュー）、ファイル選択と基準ディレクトリ、ダイアログ（フッターのボタン・name 欄・複数値の入力欄・設定一覧表・Help・最大化）

共通の入力フォームのセクション

複数のコマンドのフォームに共通して表示されるセクションです。

  • Dataset Load Formセクション
    入力データセットの指定。Convert / Compare / Generate / Parameterize で使う（Run は src・Traversal・Template の部分だけ）
    srcType: nonecsvfixedregxls / xlsxtablesqlcsvqfiledir
    • Edit SQL / Edit Table Definitionダイアログ
      srcType が sql / table / csvq のとき、src の ⋮ メニューの edit から開く。SQL ファイル・テーブル名リストの編集
    • Xlsx Schemaダイアログ
      srcType が xls / xlsx のとき、xlsxSchema の ⋮ メニューの edit から開く。Excel のシート・セルからテーブルを読み込む定義
      • Xlsx Row Settingダイアログ
        Xlsx Schema の Rows Mapping Tables の行の edit から開く。行方向に並んだデータの抽出設定
      • Xlsx Cell Settingダイアログ
        Xlsx Schema の Random Cell Mapping Tables の行の edit から開く。任意のセル位置から値を拾う設定
    • Generate Xlsx Schemaダイアログ
      xlsxSchema の ⋮ メニューの generate から開く。既存データセットから Xlsx Schema の雛型を生成
    • Traversalセクション
      traversal option。ディレクトリを読み込むときの走査条件
    • Data Loadセクション
      data load option。ヘッダ行・開始行・ファイル情報カラムなど、読み込み時の挙動
    • Dataset Settingsダイアログ
      setting の ⋮ メニューの edit から開く。主キー・カラム選択・フィルタなど、テーブルごとの設定ファイルの書式
      • Dataset Settingダイアログ
        Dataset Settings の行の edit から開く。テーブルごとの設定の編集と JEXL 式の書き方
    • Generate Dataset Settingダイアログ
      setting の ⋮ メニューの generate から開く。既存データセットから Dataset Settings の雛型を生成
  • Result Formセクション
    出力先と出力形式の指定。Convert / Compare で使う
    resultType: csvxls / xlsxtableformatfixed
    • Fixed Column Defダイアログ
      resultType が fixed のとき、fixedColumnDef の ⋮ メニューの edit から開く。固定長出力のカラムごとの幅・寄せ方向・埋める文字の編集
    • Generate Fixed Column Defダイアログ
      resultType が fixed のとき、fixedColumnDef の ⋮ メニューの generate から開く。固定長出力のカラム幅定義の雛型を生成
  • JDBCセクション
    データベースへの接続設定。Dataset Load Form・Result Form・Run で、DB を読み書きするときに表示される
  • Templateセクション
    template option。StringTemplate 4 によるテンプレート処理の設定
    • Template File Editダイアログ
      テンプレートの欄の ⋮ メニューの edit から開く。Generate の template などに指定するテンプレートの編集
    • StringTemplate 4 書式リファレンスリファレンス
      テンプレートの構文と書式指定子

特定のコマンドにだけあるセクション・ダイアログ

Generate

  • Scaffoldダイアログ
    generateType が txt のとき、unit の上の Scaffold ボタンから開く。組み込みテンプレートを書き出してカスタマイズの出発点にする
  • Jxlsセクション
    generateType が xlsx / xls のときに表示される。Excel テンプレートの設定
    • Generate Xlsx Templateダイアログ
      template の ⋮ メニューの generate から開く。既存データセットから jxls テンプレートの雛型を生成

Compare

  • Compare Key Settingsダイアログ
    targetType が data のとき、compare の setting の ⋮ メニューの edit（generate）から開く。テーブルごとの比較キーの編集
  • Image Optionセクション
    targetType が image / pdf のときに表示される。画像・PDF 比較のしきい値・除外領域・描画の設定

Parameterize

  • Edit Parameterize Templateダイアログ
    template の ⋮ メニューの edit から開く。繰り返し実行するコマンドのオプションを書くテンプレートの編集
