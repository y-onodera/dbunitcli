generateType: settings

データセットのカラム情報から Dataset Settings ファイルのひな型を JSON 形式で生成します。unit は dataset に固定です。template は使用しません。

項目説明デフォルト
includeAllColumns設定生成時にすべてのカラムを include / string 等の詳細ブロックとして含める（false の場合は主キーの keys のみ）false

生成イメージ（includeAllColumns=false）:

{
  "settings": [
    {
      "name" : "Test1"
     ,"keys":["Key"]
    }
  , {
      "name" : "Test2"
     ,"keys":["PrimaryKey"]
    }
  ]
}
