Xlsx Schema Generate

既存データセット（CSV / Excel / DB など）のテーブル・カラム構成から、Xlsx Schema の雛型を自動生成します。xlsxSchema テキストボックス横のメニューの generate ボタンから開きます。

できること

  • テーブルごとに、Rows Mapping（行形式）と Random Cell Mapping（セル指定形式）の設定を一括で作成する。
  • カラム名・カラムの並び順・主キー（breakKey）・先頭データ行・セル位置を、元データセットから引き継ぐ。
  • 生成結果を Xlsx Schema の編集ダイアログで確認・修正し、名前を付けて保存する。

一から手入力する代わりに、生成した雛型を実際の Xlsx に合わせて手直しする使い方を想定しています（特に sheetName はテーブル名が入るため、実際のシート名への修正が必要です）。

入力

雛型の元にするデータセットを、共通の Dataset Load Form で指定します。ソースタイプの選択に応じて入力項目が切り替わります（CSV / Excel / テーブル / SQL など）。各ソースタイプの詳細は Dataset Load Form のページを参照してください。

項目説明
srcData雛型の元にするデータセット。ソースタイプ・パス・エンコーディング・ヘッダ指定などを Dataset Load Form と同じ要領で指定します。

操作の流れ

  1. 元にするデータセットを指定します。
  2. Execute を押すと、テーブルごとのカラム構成から Rows Mapping / Random Cell Mapping の設定が生成されます。
  3. 生成結果は Xlsx Schema の編集ダイアログに反映された状態で開きます。内容を確認・編集してください。
  4. ファイル名を指定して保存すると、その名前が xlsxSchema テキストボックスに設定されます。

生成例

たとえば USERS テーブル（カラム ID / NAME / EMAIL、主キーは ID）を含むデータセットを指定して Execute すると、次のようなスキーマが生成されます。

{
  "rows": [
    {
      "sheetName": "USERS"
     ,"tableName": "USERS"
     ,"header": ["ID","NAME","EMAIL"]
     ,"dataStart": 1
     ,"columnIndex": [0,1,2]
     ,"breakKey": ["ID"]
    }
  ]
 ,"cells": [
    {
      "sheetName": "USERS"
     ,"tableName": "USERS"
     ,"header": ["ID","NAME","EMAIL"]
     ,"rows": [{"cellAddress": ["A2","B2","C2"]}]
    }
  ]
}

生成ルール

項目生成される値
sheetNameテーブル名と同じ値。実際の Xlsx のシート名に合わせて編集してください。
tableName元データセットのテーブル名。
header元テーブルのカラム名を並び順どおりに設定。
dataStart常に 1（ヘッダ行の次の行から、0 始まり）。
columnIndexカラムの並び順に 0 から連番。
breakKey主キーのカラム名。主キーが無い場合は先頭カラムのみ。
cellAddressdataStart 行の各カラムのセル位置（上の例では A2, B2, C2）。

テーブルごとに Xlsx Schema の Rows Mapping Tables と Random Cell Mapping Tables の両方に 1 件ずつ生成されます。不要な側の行は編集ダイアログで削除してください。

対象となる Excel のイメージ

上の生成例のスキーマは、次のようなシートを持つ Excel ファイルを読み込むための定義です。シート名は sheetName の値（この例では USERS）で、1 行目にカラム名、2 行目以降にデータが並ぶ一般的な表形式を想定しています。

シート: USERSABC
1IDNAMEEMAIL
21Alicealice@example.com
32Bobbob@example.com
43Carolcarol@example.com
  • Rows Mapping（rows）: dataStart の 2 行目から、columnIndex で指定した A〜C 列を 1 行 1 レコードとして読み込みます。カラム名は header の定義が使われます。上の表なら 3 レコードの USERS テーブルになります。
  • Random Cell Mapping（cells）: cellAddress に指定した A2・B2・C2 のセルだけを拾い、1 レコードの USERS テーブルにします。帳票のように、決まったセル位置に値が入っているシート向けの定義です。

実際のシートの行・列の位置が生成結果と異なる場合は、Xlsx Schema の編集ダイアログで sheetName・dataStart・columnIndex・cellAddress を修正してください。

注意

  • Execute が失敗した場合は、ダイアログ内にエラーメッセージが表示されます。入力内容を見直して再度実行してください。
  • Close を押すと、生成せずにダイアログを閉じます（xlsxSchema テキストボックスは変更されません）。
